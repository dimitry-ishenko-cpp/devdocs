polars.Expr.list.contains

Expr.list.contains(
    item: IntoExpr,
    *,
    nulls_equal: bool = True,
) → Expr

Check if sub-lists contain the given item.

engine:In MemoryStreamingDistributed
Parameters:
item

Item that will be checked for membership

nulls_equalbool, default True

If True, treat null as a distinct value. Null values will not propagate. Note that Expr.is_in() defaults to False.

Returns:
Expr

Expression of data type Boolean.

Notes

For supported dtype pairs, lossy conversions do not create matches. Values that would overflow or require rounding match nothing. Cast explicitly to compare integers and floats.

Examples

>>> df = pl.DataFrame({"a": [[3, 2, 1], [], [1, 2]]})
>>> df.with_columns(contains=pl.col("a").list.contains(1))
shape: (3, 2)
