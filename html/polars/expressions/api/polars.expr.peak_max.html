polars.Expr.peak_max

Expr.peak_max() → Expr

Get a boolean mask of the local maximum peaks.

Examples

>>> df = pl.DataFrame({"a": [1, 2, 3, 4, 5]})
>>> df.select(pl.col("a").peak_max())
shape: (5, 1)

│ ---   │
│ bool  │

│ false │
│ false │
│ false │
│ true  │
