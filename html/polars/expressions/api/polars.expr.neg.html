polars.Expr.neg

Expr.neg() → Expr

Method equivalent of unary minus operator -expr.

engine:In MemoryStreamingDistributed

Examples

>>> df = pl.DataFrame({"a": [-1, 0, 2, None]})
>>> df.with_columns(pl.col("a").neg())
