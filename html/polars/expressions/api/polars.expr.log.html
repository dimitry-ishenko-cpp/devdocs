polars.Expr.log

Expr.log(
    base: float | IntoExpr = 2.718281828459045,
) → Expr

Compute the logarithm to a given base.

Parameters:
base

Given base, defaults to e

Examples

>>> df = pl.DataFrame({"a": [1, 2, 3]})
>>> df.select(pl.col("a").log(base=2))
shape: (3, 1)
