polars.Expr.sqrt

Expr.sqrt() → Expr

Compute the square root of the elements.

Examples

>>> df = pl.DataFrame({"values": [1.0, 2.0, 4.0]})
>>> df.select(pl.col("values").sqrt())
shape: (3, 1)

│ ---      │
│ f64      │

│ 1.0      │

│ 2.0      │
└──────────┘
