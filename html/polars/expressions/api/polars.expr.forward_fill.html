polars.Expr.forward_fill

Expr.forward_fill(
    limit: int | None = None,
) → Expr

Fill missing values with the last non-null value.

This is an alias of .fill_null(strategy="forward").

Parameters:
limit

The number of consecutive null values to forward fill.

backward_fill
fill_null
