polars.Expr.erfc

Expr.erfc() → Expr

Compute the complementary error function, element-wise.

See Wikipedia.

engine:In MemoryStreamingDistributed

Examples

>>> df = pl.DataFrame({"a": [-1, 0, 1]})
>>> df.select(pl.col("a").erfc())
shape: (3, 1)
