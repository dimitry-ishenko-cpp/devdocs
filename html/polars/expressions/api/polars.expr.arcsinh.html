polars.Expr.arcsinh

Expr.arcsinh() → Expr

Compute the element-wise value for the inverse hyperbolic sine.

engine:In MemoryStreamingDistributed
Returns:
Expr

Expression of data type Float64.

Examples

>>> df = pl.DataFrame({"a": [1.0]})
>>> df.select(pl.col("a").arcsinh())
shape: (1, 1)
┌──────────┐
│ a        │
│ ---      │
│ f64      │
╞══════════╡
│ 0.881374 │
└──────────┘
