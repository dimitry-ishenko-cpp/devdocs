polars.Expr.cosh

Expr.cosh() → Expr

Compute the element-wise value for the hyperbolic cosine.

engine:In MemoryStreamingDistributed
Returns:
Expr

Expression of data type Float64.

Examples

>>> df = pl.DataFrame({"a": [1.0]})
>>> df.select(pl.col("a").cosh())
shape: (1, 1)
