polars.quantile

polars.quantile(
    column: str,
    quantile: float | Expr,
    interpolation: QuantileMethod = 'nearest',
) → Expr

Syntactic sugar for pl.col("foo").quantile(..).

Parameters:
column

Column name.

quantile

Quantile between 0.0 and 1.0.

interpolation{‘nearest’, ‘higher’, ‘lower’, ‘midpoint’, ‘linear’, ‘equiprobable’}

Interpolation method.
