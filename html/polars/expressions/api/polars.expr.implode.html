polars.Expr.implode

Expr.implode(
    *,
    maintain_order: bool = True,
) → Expr

Aggregate values into a list.

The returned list itself is a scalar value of list dtype.

Parameters:
maintain_order

Whether to preserve the order of elements in the list. Setting this to False can improve performance, especially within group_by.

Examples

>>> df = pl.DataFrame(
...     {
...         "a": [1, 2, 3],
...         "b": [4, 5, 6],
...     }
... )
>>> df.select(pl.all().implode())
shape: (1, 2)
┌───────────┬───────────┐
│ a         ┆ b         │
│ ---       ┆ ---       │
│ list[i64] ┆ list[i64] │
╞═══════════╪═══════════╡
│ [1, 2, 3] ┆ [4, 5, 6] │
└───────────┴───────────┘
