polars.Expr.log10

Expr.log10() → Expr

Compute the base 10 logarithm of the input array, element-wise.

engine:In MemoryStreamingDistributed

Examples

>>> df = pl.DataFrame({"values": [1.0, 2.0, 4.0]})
>>> df.select(pl.col("values").log10())
shape: (3, 1)
┌─────────┐
│ values  │
│ ---     │
│ f64     │
╞═════════╡
│ 0.0     │
│ 0.30103 │
│ 0.60206 │
└─────────┘
