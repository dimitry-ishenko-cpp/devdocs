polars.Expr.floor

Expr.floor() → Expr

Rounds down to the nearest integer value.

Only works on floating point Series.

See also

ceil

Round up to the nearest integer value.

round

Round to the nearest integer.

Examples

>>> df = pl.DataFrame({"a": [0.3, 0.5, 1.0, 1.1]})
>>> df.select(pl.col("a").floor())
shape: (4, 1)
