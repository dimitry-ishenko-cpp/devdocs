polars.Config.set_tbl_hide_dataframe_shape

classmethod Config.set_tbl_hide_dataframe_shape(
    active: bool | None = True,
) → type[Config]

Hide the DataFrame shape information when displaying tables.

Examples

>>> df = pl.DataFrame({"abc": [1.0, 2.5, 5.0], "xyz": [True, False, True]})
>>> pl.Config.set_tbl_hide_dataframe_shape(True)  
# ...
# shape: (3, 2)        ┌─────┬───────┐
# ┌─────┬───────┐      │ abc ┆ xyz   │
# │ abc ┆ xyz   │      │ --- ┆ ---   │
# │ --- ┆ ---   │      │ f64 ┆ bool  │
# │ f64 ┆ bool  │      ╞═════╪═══════╡
# ╞═════╪═══════╡      │ 1.0 ┆ true  │
# │ 1.0 ┆ true  │  >>  │ 2.5 ┆ false │
# │ 2.5 ┆ false │      │ 5.0 ┆ true  │
# │ 5.0 ┆ true  │      └─────┴───────┘
# └─────┴───────┘
