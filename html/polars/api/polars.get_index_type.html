polars.get_index_type

polars.get_index_type() → PolarsIntegerType

Return the data type used for Polars indexing.

Returns:
PolarsIntegerType

UInt32 in regular Polars, UInt64 in bigidx Polars.

Examples

>>> pl.get_index_type()
UInt32
