polars.build_info

polars.build_info() → dict[str, Any]

Return detailed Polars build information.

The dictionary with build information contains the following keys:

  • "compiler"
  • "time"
  • "dependencies"
  • "features"
  • "host"
  • "target"
  • "git"
  • "version"

If Polars was compiled without the build_info feature flag, only the "version" key is included.
