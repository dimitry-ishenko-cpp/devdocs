polars.datatypes.Array

class polars.datatypes.Array(
    inner: PolarsDataType | PythonDataType,
    shape: int | tuple[int,
    ...] | None = None,
    *,
    width: int | None = None,
)

Fixed length list type.

Parameters:
inner

The DataType of the values within each array.

shape

The shape of the arrays.

width

The length of the arrays.

Deprecated since version 0.20.31: The width parameter for Array is deprecated. Use shape instead.

Examples

>>> s = pl.Series("a", [[1, 2], [4, 3]], dtype=pl.Array(pl.Int64, 2))
>>> s
shape: (2,)
Series: 'a' [array[i64, 2]]
[
        [1, 2]
        [4, 3]
]
