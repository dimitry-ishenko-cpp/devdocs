polars.Config.set_tbl_hide_dtype_separator

classmethod Config.set_tbl_hide_dtype_separator(
    active: bool | None = True,
) → type[Config]

Hide the ‘—’ separator displayed between the column names and column types.

See also

set_tbl_column_data_type_inline

Display the data type inline with the colname.

Examples

>>> df = pl.DataFrame({"abc": [1.0, 2.5, 5.0], "xyz": [True, False, True]})
>>> pl.Config.set_tbl_hide_dtype_separator(True)  
# ...
# shape: (3, 2)        shape: (3, 2)
# ┌─────┬───────┐      ┌─────┬───────┐
# │ abc ┆ xyz   │      │ abc ┆ xyz   │
# │ --- ┆ ---   │      │ f64 ┆ bool  │
# │ f64 ┆ bool  │      ╞═════╪═══════╡
# ╞═════╪═══════╡      │ 1.0 ┆ true  │
# │ 1.0 ┆ true  │  >>  │ 2.5 ┆ false │
# │ 2.5 ┆ false │      │ 5.0 ┆ true  │
# │ 5.0 ┆ true  │      └─────┴───────┘
# └─────┴───────┘
