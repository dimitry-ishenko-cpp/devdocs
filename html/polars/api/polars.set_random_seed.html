polars.set_random_seed

polars.set_random_seed(
    seed: int,
) → None

Set the global random seed for Polars.

This random seed is used to determine things such as shuffle ordering.

Parameters:
seed

A non-negative integer < 264 used to seed the internal global random number generator.
