polars.exceptions.ColumnNotFoundError

exception polars.exceptions.ColumnNotFoundError

Exception raised when a specified column is not found.

Examples

>>> df = pl.DataFrame({"a": [1, 2, 3]})
>>> df.select("b")
polars.exceptions.ColumnNotFoundError: b
