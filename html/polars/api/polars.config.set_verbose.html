polars.Config.set_verbose

classmethod Config.set_verbose(
    active: bool | None = True,
) → type[Config]

Enable additional verbose/debug logging.

Examples

>>> pl.Config.set_verbose(True)  
>>> with pl.Config(verbose=True):  
...     do_polars_operations()
