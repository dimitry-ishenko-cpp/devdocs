polars.Series.degrees

Series.degrees() → Series

Convert from radians to degrees.

Examples

>>> import math
>>> s = pl.Series("a", [x * math.pi for x in range(-4, 5)])
>>> s.degrees()
shape: (9,)
Series: 'a' [f64]
[
    -720.0
    -540.0
    -360.0
    -180.0
    0.0
    180.0
    360.0
    540.0
    720.0
]
