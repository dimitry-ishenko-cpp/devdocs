polars.Series.is_finite

Series.is_finite() → Series

Returns a boolean Series indicating which values are finite.

Returns:
Series

Series of data type Boolean.

Examples

>>> import numpy as np
>>> s = pl.Series("a", [1.0, 2.0, np.inf])
>>> s.is_finite()
shape: (3,)
Series: 'a' [bool]
[
    true
    true
    false
]
