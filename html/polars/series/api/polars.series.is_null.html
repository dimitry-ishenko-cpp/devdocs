polars.Series.is_null

Series.is_null() → Series

Returns a boolean Series indicating which values are null.

Returns:
Series

Series of data type Boolean.

Examples

>>> s = pl.Series("a", [1.0, 2.0, 3.0, None])
>>> s.is_null()
shape: (4,)
Series: 'a' [bool]
[
    false
    false
    false
    true
]
