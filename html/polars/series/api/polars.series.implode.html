polars.Series.implode

Series.implode() → Self

Aggregate values into a list.

The returned list itself is a scalar value of list dtype.

Examples

>>> s = pl.Series("a", [1, 2, 3])
>>> s.implode()
shape: (1,)
Series: 'a' [list[i64]]
[
    [1, 2, 3]
]
