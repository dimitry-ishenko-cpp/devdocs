polars.Series.erfc

Series.erfc() → Series

Compute the complementary error function, element-wise.

See Wikipedia.

Examples

>>> s = pl.Series([-1, 0, 1])
>>> s.erfc()
shape: (3,)
Series: '' [f64]
[
    1.842701
    1.0
    0.157299
]
