polars.Series.peak_max

Series.peak_max() → Self

Get a boolean mask of the local maximum peaks.

Examples

>>> s = pl.Series("a", [1, 2, 3, 4, 5])
>>> s.peak_max()
shape: (5,)
Series: 'a' [bool]
[
    false
    false
    false
    false
    true
]
