polars.Series.not_

Series.not_() → Series

Negate a boolean Series.

Returns:
Series

Series of data type Boolean.

Examples

>>> s = pl.Series("a", [True, False, False])
>>> s.not_()
shape: (3,)
Series: 'a' [bool]
[
    false
    true
    true
]
