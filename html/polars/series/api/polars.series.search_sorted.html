polars.Series.search_sorted

Series.search_sorted(
    element: IntoExpr | np.ndarray[Any,
    Any] | None,
    side: SearchSortedSide = 'any',
    *,
    descending: bool = False,
) → int | Series

Find indices where elements should be inserted to maintain order.

a[i−1]<v<=a[i]a[i-1] < v <= a[i]
Parameters:
element

Expression or scalar value.

side{‘any’, ‘left’, ‘right’}

If ‘any’, the index of the first suitable location found is given. If ‘left’, the index of the leftmost suitable location found is given. If ‘right’, return the rightmost suitable location found is given.

descending

Boolean indicating whether the values are descending or not (they are required to be sorted either way).

Examples

>>> s = pl.Series("set", [1, 2, 3, 4, 4, 5, 6, 7])
>>> s.search_sorted(4)
3
>>> s.search_sorted(4, "left")
3
>>> s.search_sorted(4, "right")
5
>>> s.search_sorted(pl.Series([1, 4, 5]))
shape: (3,)
Series: 'set' [u32]
[
    0
    3
    5
]
>>> s.search_sorted(pl.Series([1, 4, 5]), "left")
shape: (3,)
Series: 'set' [u32]
[
    0
    3
    5
]
>>> # To search for a list of values in a series, of lists, use pl.lit():
>>> list_s = pl.Series("lists", [[0, 1], [0, 2], [1, 4]])
>>> list_s.search_sorted(pl.lit([0, 2]), "left")
shape: (1,)
Series: 'lists' [u32]
[
    1
]
