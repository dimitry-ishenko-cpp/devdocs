polars.Series.log

Series.log(
    base: float | Series = 2.718281828459045,
) → Series

Compute the logarithm to a given base.

Examples

>>> s = pl.Series([1, 2, 3])
>>> s.log()
shape: (3,)
Series: '' [f64]
[
    0.0
    0.693147
    1.098612
]
