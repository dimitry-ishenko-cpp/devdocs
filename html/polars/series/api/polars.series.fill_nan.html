polars.Series.fill_nan

Series.fill_nan(
    value: int | float | Expr | None,
) → Series

Fill floating point NaN value with a fill value.

Parameters:
value

Value used to fill NaN values.

See also

fill_null

Notes

A NaN value is not the same as a null value. To fill null values, use fill_null().

Examples

>>> s = pl.Series("a", [1.0, 2.0, 3.0, float("nan")])
>>> s.fill_nan(0)
shape: (4,)
Series: 'a' [f64]
[
    1.0
    2.0
    3.0
    0.0
]
