polars.Series.is_unique

Series.is_unique() → Series

Get mask of all unique values.

Returns:
Series

Series of data type Boolean.

Examples

>>> s = pl.Series("a", [1, 2, 2, 3])
>>> s.is_unique()
shape: (4,)
Series: 'a' [bool]
[
    true
    false
    false
    true
]
