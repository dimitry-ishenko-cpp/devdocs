polars.Series.mode

Series.mode(
    *,
    maintain_order: bool = False,
) → Series

Compute the most occurring value(s).

Can return multiple Values.

Parameters:
maintain_order

Maintain order of data. This requires more work.

Examples

>>> s = pl.Series("a", [1, 2, 2, 3])
>>> s.mode()
shape: (1,)
Series: 'a' [i64]
[
    2
]
