polars.Series.erf

Series.erf() → Series

Compute the error function, element-wise.

See Wikipedia.

Examples

>>> s = pl.Series([-1, 0, 1])
>>> s.erf()
shape: (3,)
Series: '' [f64]
[
    -0.842701
    0.0
    0.842701
]
