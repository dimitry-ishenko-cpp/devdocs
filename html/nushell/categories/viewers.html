Viewers

Command Description
explore Explore acts as a table pager, just like `less` does for text.
explore config Launch a TUI to view and edit the nushell configuration interactively.
explore regex Launch a TUI to create and explore regular expressions interactively.
grid Renders the output to a textual terminal grid.
table Render the table.
