polars selector numeric for expression

Select all numeric columns.

Signature

> polars selector numeric {flags}

Input/output types:

input output
any polars_selector

Examples

Select all numeric columns

> {
        "foo": ["x", "y"],
        "bar": [123, 456],
        "baz": [2.0, 5.5],
        "zap": [0, 0],
    } |
    polars into-df --as-columns |
    polars select (polars selector numeric) |
    polars sort-by bar baz zap |
    polars collect
╭───┬─────┬──────┬─────╮
│ # │ bar │ baz  │ zap │
├───┼─────┼──────┼─────┤
│ 0 │ 123 │ 2.00 │   0 │
│ 1 │ 456 │ 5.50 │   0 │
╰───┴─────┴──────┴─────╯
