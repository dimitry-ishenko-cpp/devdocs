date list-timezone for date

List supported time zones.

Signature

> date list-timezone {flags}

Input/output types:

input output
nothing table

Examples

Show time zone(s) that contains 'Shanghai'.

> date list-timezone | where timezone =~ Shanghai
╭───┬───────────────╮
│ # │   timezone    │
├───┼───────────────┤
│ 0 │ Asia/Shanghai │
╰───┴───────────────╯
