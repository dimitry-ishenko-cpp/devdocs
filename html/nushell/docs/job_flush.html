job flush for experimental

Clear this job's mailbox.

Signature

> job flush {flags}

Flags

  • --tag {int}: Clear messages with this tag.

Input/output types:

input output
nothing nothing

Examples

Clear the mailbox of the current job.

> job flush

Notes

This command removes all messages in the mailbox of the current job. If a message is received while this command is executing, it may also be discarded.
