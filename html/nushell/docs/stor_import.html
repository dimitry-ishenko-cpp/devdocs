stor import for database

Import a sqlite database file into the in-memory sqlite database.

Signature

> stor import {flags}

Flags

  • --file-name, -f {string}: File name to import the sqlite in-memory database from.

Input/output types:

input output
nothing table

Examples

Import a sqlite database file into the in-memory sqlite database

> stor import --file-name nudb.sqlite
