math sqrt for math

Returns the square root of the input number.

Signature

> math sqrt {flags}

Input/output types:

input output
number float
list<number> list<float>
range list<number>

Examples

Compute the square root of each number in a list.

> [9 16] | math sqrt
╭───┬──────╮
│ 0 │ 3.00 │
│ 1 │ 4.00 │
╰───┴──────╯
