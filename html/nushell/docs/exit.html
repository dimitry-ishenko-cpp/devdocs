exit for shells

Exit Nu.

Signature

> exit {flags} (exit_code)

Flags

  • --abort: Exit by abort.

Parameters

  • exit_code: Exit code to return immediately with.

Input/output types:

input output
nothing nothing

Examples

Exit the current shell

> exit
