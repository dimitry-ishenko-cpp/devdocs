polars into-schema for dataframe

Convert a value to a polars schema object

Signature

> polars into-schema {flags}

Input/output types:

input output
any polars_schema

Examples

Convert a record into a schema and back to a nu object

> {a: str, b: u8} | polars into-schema | polars into-nu
╭───┬─────╮
│ a │ str │
│ b │ u8  │
╰───┴─────╯
