from url for formats

Parse url-encoded string as a record.

Signature

> from url {flags}

Input/output types:

input output
string record

Examples

Convert url encoded string into a record

> 'bread=baguette&cheese=comt%C3%A9&meat=ham&fat=butter' | from url
╭────────┬──────────╮
│ bread  │ baguette │
│ cheese │ comté    │
│ meat   │ ham      │
│ fat    │ butter   │
╰────────┴──────────╯
