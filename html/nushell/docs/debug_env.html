debug env for debug

Show environment variables as external commands would get it.

Signature

> debug env {flags}

Input/output types:

input output
nothing record

Examples

Get PATH variable that externals see.

> debug env | get PATH!

Create a .env file.

> debug env | transpose key value | each {$"($in.key)=($in.value | to json)"} | save .env
