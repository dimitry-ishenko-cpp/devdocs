port for network

Get a free TCP port from system.

Signature

> port {flags} (start) (end)

Parameters

  • start: The start port to scan (inclusive).
  • end: The end port to scan (inclusive).

Input/output types:

input output
nothing int

Examples

get a free port between 3121 and 4000

> port 3121 4000
3121

get a free port from system

> port
