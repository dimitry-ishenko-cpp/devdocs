attr complete external for core

Attribute for enabling use of the external completer for internal commands.

Signature

> attr complete external {flags}

Input/output types:

input output
nothing nothing

Examples

Use the external completer for a wrapper command.

> @complete external
def --wrapped jc [...args] {
    ^jc ...$args | from json
}
