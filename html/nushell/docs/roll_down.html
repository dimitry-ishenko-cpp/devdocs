roll down for filters

Roll table rows down.

Signature

> roll down {flags}

Flags

  • --by, -b {int}: Number of rows to roll.

Input/output types:

input output
table table

Examples

Rolls rows down of a table

> [[a b]; [1 2] [3 4] [5 6]] | roll down
╭───┬───┬───╮
│ # │ a │ b │
├───┼───┼───┤
│ 0 │ 5 │ 6 │
│ 1 │ 1 │ 2 │
│ 2 │ 3 │ 4 │
╰───┴───┴───╯
