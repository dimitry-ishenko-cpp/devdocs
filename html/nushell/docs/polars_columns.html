polars columns for dataframe

Show dataframe columns.

Signature

> polars columns {flags}

Input/output types:

input output
polars_dataframe polars_dataframe
polars_lazyframe polars_lazyframe

Examples

Dataframe columns

> [[a b]; [1 2] [3 4]] | polars into-df | polars columns
╭───┬───╮
│ 0 │ a │
│ 1 │ b │
╰───┴───╯
