random binary for random

Generate random bytes.

Signature

> random binary {flags} (length)

Parameters

  • length: Length of the output binary.

Input/output types:

input output
nothing binary

Examples

Generate 16 random bytes.

> random binary 16

Generate 1 random kilobyte.

> random binary 1kb
