commandline set-cursor for core

Set the current cursor position.

Signature

> commandline set-cursor {flags} (pos)

Flags

  • --end, -e: Set the current cursor position to the end of the buffer.

Parameters

  • pos: Cursor position to be set.

Input/output types:

input output
nothing nothing
