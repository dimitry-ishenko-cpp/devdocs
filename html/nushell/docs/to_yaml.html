to yaml for formats

Convert table into .yaml/.yml text.

Signature

> to yaml {flags}

Flags

  • --serialize, -s: Serialize nushell types that cannot be deserialized.

Input/output types:

input output
any string

Examples

Outputs a YAML string representing the contents of this table.

> [[foo bar]; ["1" "2"]] | to yaml
- foo: '1'
  bar: '2'
