class Net::HTTPInsufficientStorage

Parent:
Net::HTTPServerError

Response class for Insufficient Storage (WebDAV) responses (status code 507).

The server is unable to store the representation needed to complete the request.

This class also includes (indirectly) module Net::HTTPHeader, which gives access to its methods for getting headers.
