class Net::HTTP::Move

Parent:
Net::HTTPRequest

Class for representing WebDAV method MOVE:

require 'net/http'
uri = URI('http://example.com')
hostname = uri.hostname # => "example.com"
req = Net::HTTP::Move.new(uri) # => #<Net::HTTP::Move MOVE>
res = Net::HTTP.start(hostname) do |http|
  http.request(req)
end

See Request Headers.
