runAsync

A function that returns a Future object, which is an eventual result of an asynchronous operation

runAsync(function() {}) → returns any

  • CF2018+
  • Lucee5.3.0+
  • BL 1.0.0+

    • Argument Reference

    callback function

    Closure function that returns a result to be resolved.

    timeout numeric
    Default: 1000

    Timeout for the asynchronous process in milliseconds

    Links more information about runAsync

    • Asynchronous programming - ColdFusion introduces asynchronous programming with Future object

    Examples
    Sample code invoking the runAsync function

    Run a function asynchronously and get the result 

    future = runAsync(function(){
	return "Hello World!";
});
writeOutput(future.get());

    Expected Result: Hello World!

    Run a function after the asynchronous function and use a five milliseconds timeout when calling get() 

    future = runAsync(function(){
	return 5;
}).then(function(input){
	return input + 2;
});
result = future.get(3); // 3 is timeout(in ms)
writeOutput(result);

    Expected Result: 5

    Run a function asynchronously with then() and error() 

    future = runAsync(function(){
	return 5;
}).then(function(input){
	return input + 2;
}).error(function(){
	return "Error occurred.";
});
writeOutput(future.get());

    Expected Result: 7
