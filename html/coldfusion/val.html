val

Converts numeric characters that occur at the beginning of a string to a number. If conversion fails, returns zero.

val(String) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: isNumeric isNull

    Argument Reference

    String string
    Required

    A string or a variable that contains one

    Examples
    Sample code invoking the val function

    Numeric characters at beginning and middle of a string 

    val("120test12sstring");

    Expected Result: 120

    Numeric characters only at the end of a string 

    val("string98");

    Expected Result: 0
