spreadsheetNew

Creates a ColdFusion spreadsheet object, which represents a single sheet of an Excel document.

spreadsheetNew([sheetname] [, xmlFormat]) → returns any

  • CF9+
    • See Also: spreadsheetAddRow spreadsheetRead spreadsheetformatCell spreadsheetWrite

    Argument Reference

    sheetname string

    String value to be used as the sheet name.

    xmlFormat boolean
    Default: false

    Boolean value to indicate the use of Excels xlsx format.
    Values:
    • true
    • false

    Examples
    Sample code invoking the spreadsheetNew function

    Create xlsx sheet

    xlsx files with and with out sheet name

    xlsxSheet1 = spreadsheetNew("xlsx sheet",true);
xlsxSheet2 = spreadsheetNew(true);
writeDump(xlsxSheet1);
writeDump(xlsxSheet2);

    Create xls sheet

    xls files with and with out sheet name

    xlsSheet1 = spreadsheetNew("xls sheet");
xlsSheet2 = spreadsheetNew();
writeDump(xlsSheet1);
writeDump(xlsSheet2);
