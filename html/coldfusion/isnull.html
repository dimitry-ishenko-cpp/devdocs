isNull

Returns true if the specified object is null.

isNull(object) → returns boolean

  • CF9+
  • Lucee
  • BL 1.0.0+
    • See Also: javacast

    Argument Reference

    object variableName
    Required

    Examples
    Sample code invoking the isNull function

    isNull Example

    Returns true if the given object is null or the given expressions evaluates to null; Returns false is otherwise. 

    isNull( javaCast("null", "") )

    Expected Result: true
