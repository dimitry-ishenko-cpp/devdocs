isIPV6

Checks if given IP is of IPV6 format

isIPV6(value) → returns boolean

  • CF9+
  • Lucee
  • BL 1.0.0+
    • See Also: isIPInRange getLocalhostIP

    Argument Reference

    value string
    Required

    IP address to check

    Examples
    Sample code invoking the isIPV6 function

    isIPV6 Example 

    isIPV6("127.0.0.1");

    Expected Result: true
