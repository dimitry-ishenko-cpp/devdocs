getProfileSections

Gets all the sections of an initialization file.Returns a struct whose format is as follows:- Each initialization file section name is a key in the struct- Each list of entries in a section of an initialization file is a value in the struct

getProfileSections(path [,encoding]) → returns struct

  • CF6+
  • Lucee
  • BL 1.0.0+

    • Argument Reference

    path string
    Required

    Absolute path of initialization file

    encoding string

    CF 11+ Encoding of the initialization (ini) file
    Values:
    • utf-8
    • iso-8859-1
    • windows-1252
    • us-ascii
    • shift_jis
    • iso-2022-jp
    • euc-jp
    • euc-kr
    • big5
    • euc-cn
    • utf-16

    Compatibility

    BoxLang:

    Version 1.0.0+ Requires the bx-ini module.
