stringSort

Sorts an input string.

stringSort(inputString) → returns string

Member Function Syntax

inputString.sort()

  • CF2021+
  • BL 1.0.0+
    • See Also: structSort listSort querySort

    Argument Reference

    inputString string
    Required

    The string to sort.
