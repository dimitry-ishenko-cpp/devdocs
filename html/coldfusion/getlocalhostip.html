getLocalhostIP

Returns the localhost IP address, which is 127.0.0.1 for IPv4 and ::1 for IPv6 addresses.

getLocalhostIP() → returns string

  • CF7.0.1+
  • Lucee
    • See Also: isIPInRange isIPV6
