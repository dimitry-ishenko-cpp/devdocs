stringLen

Get the length of a string.

stringLen(string) → returns numeric

Member Function Syntax

string.len()

  • Lucee
  • BL 1.0.0+
    • See Also: len arrayLen

    Argument Reference

    string string
    Required

    Examples
    Sample code invoking the stringLen function

    StringLen() example

    Output the length of the string "Hello World".

    StringLen("Hello World")

    Expected Result: 11

    StringLen() using as a member function

    Output the length of the string "Hello World".

    "Hello World".len()

    Expected Result: 11
