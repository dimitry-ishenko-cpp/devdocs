charsetDecode

Converts a string to a binary representation.

charsetDecode(string, encoding) → returns binary

  • CF7+
  • Lucee
  • BL 1.0.0+
    • See Also: charsetEncode

    Argument Reference

    string string
    Required

    A string containing data to encode in binary format.

    encoding string
    Required

    A string specifying encoding of the input data.
    Values:
    • utf-8
    • iso-8859-1
    • windows-1252
    • us-ascii
    • shift_jis
    • iso-2022-jp
    • euc-jp
    • euc-kr
    • big5
    • euc-cn
    • utf-16

    Examples
    Sample code invoking the charsetDecode function

    Decode a string using utf-8 back into binary encoding of the string

    Use charsetDecode to decode with utf-8

    charsetDecode('string','utf-8');

    Expected Result: [BINARY]

    Decode a string using us-ascii back into binary encoding of the string

    Use charsetDecode to decode with us-ascii

    charsetDecode('string','us-ascii');

    Expected Result: [BINARY]
