inputBaseN

Converts string, using the base specified by radix, to an integer.

inputBaseN(String, radix) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: int parseNumber toNumeric

    Argument Reference

    String string
    Required

    radix string
    Required

    Examples
    Sample code invoking the inputBaseN function

    Binary string to decimal 

    inputBaseN("1010",2)

    Expected Result: 10

    Hexadecimal string to decimal 

    inputBaseN("3FF",16)

    Expected Result: 1023

    Decimal string to decimal 

    inputBaseN("125",10)

    Expected Result: 125

    Binary number to decimal 

    inputBaseN(1010,2)

    Expected Result: 10
