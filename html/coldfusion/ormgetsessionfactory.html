ormGetSessionFactory

Returns ORM session factory instance

ormGetSessionFactory([datasource]) → returns any

  • CF9+
  • Lucee
  • BL 1.0.0+

    • Argument Reference

    datasource string

    Name of the data source used for the session. If not defined, the default datasource defined in Application.cfc/cfapplication is used.

    Examples
    Sample code invoking the ormGetSessionFactory function

    Gets the Hibernate session factory object associated with the datasource from the application.

    Returns the Factory object for the Hibernate session so you can perform operations on it.

    ormGetSessionFactory();
