getGatewayHelper

Gets a Java GatewayHelper object that provides methods and properties for use with a ColdFusion event gateway.

getGatewayHelper(gatewayID) → returns any

This function requires Adobe ColdFusion 7 and up. Not supported on Lucee, etc.
  • CF7+

    • Argument Reference

    gatewayID string
    Required

    Identifier of the gateway that provides the GatewayHelper object.
