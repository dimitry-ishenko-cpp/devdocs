quotedValueList

Gets the values of each record returned from an executed query. CFML does not evaluate the arguments

quotedValueList(column [, delimiter]) → returns string

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: ValueList

    Argument Reference

    column query
    Required

    Name of an executed query and column. Separate query name and column name with a period.

    delimiter string
    Default: ,

    Compatibility

    BoxLang:

    Version 1.0.0+ Transpiled to queryColumnData().map().toList( delimiter ) in BoxLang

    Examples
    Sample code invoking the quotedValueList function

    Tag Example 

    <cfquery name = "GetCourseList" datasource = "cfdocexamples"> 
 SELECT * 
 FROM CourseList 
 WHERE Dept_ID IN ('#GetDepartments.Dept_ID#') 
 </cfquery> 
 <cfoutput> 
 #quotedValueList(GetCourseList.CorNumber,";")# 
 </cfoutput>
