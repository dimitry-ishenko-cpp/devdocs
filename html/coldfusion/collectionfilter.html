collectionFilter

Filters items from a collection passing the filter condition

collectionFilter(collection, filter [, parallel] [, maxThreads]) → returns any

This function requires Lucee. Not supported on Adobe ColdFusion, etc.
  • Lucee
    • See Also: collectionEvery collectionEach collectionMap collectionReduce collectionSome

    Argument Reference

    collection any
    Required

    filter function
    Required

    parallel boolean

    maxThreads numeric
    Default: 20

    Examples
    Sample code invoking the collectionFilter function

    Return only items of type mail 

    coll = [{
    id: 0,
    type: 'mail'
},{
    id: 1,
    type: 'mail'
},{
    id: 2,
    type: 'comment'
}];
onlyMails = collectionFilter(coll,function(item) {
    return item.type is 'mail';
});
for(mail in onlyMails) {
    writeOutput(mail.id&', ');
}
