bitShrn

Performs a bitwise shift-right, no-rotation operation.

bitShrn(number, count) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: bitShln

    Argument Reference

    number numeric
    Required

    Integer

    count numeric
    Required

    Number of bits to shift to the right (Integer in the range 0-31, inclusive)
