lCase

Converts the alphabetic characters in a string to lowercase.

lCase(String) → returns string

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: uCase

    Argument Reference

    String string
    Required

    Examples
    Sample code invoking the lCase function

    lowercase CFDocs Rock 

    lCase('CFDocs Rock')

    Expected Result: cfdocs rock
