createTime

Creates a time variable.

createTime(hour, minute, second) → returns date

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: createODBCTime createDateTime

    Argument Reference

    hour numeric
    Required

    Hour of the day in 24-hour notation (0-23)

    minute numeric
    Required
    Default: 0

    Minute within the hour

    second numeric
    Required
    Default: 0

    Second within the minute

    millisecond numeric
    Default: 0

    timezone numeric

    Examples
    Sample code invoking the createTime function

    Tag Syntax 

    <cfset yourTime = createTime("5", "24", "56")>  
 <cfdump var="#yourTime#" />
