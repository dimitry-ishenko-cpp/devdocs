transactionCommit

Commit a pending transaction

transactionCommit() → returns void

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: cftry cfcatch cftransaction transactionrollback transactionsetsavepoint

    Examples
    Sample code invoking the transactionCommit function

    Script Syntax

    In this code, transactionCommit() will commit the pending transaction, which is any database queries run in the transaction block.

    
transaction { 
 try { 
 // code to run 
 transaction action="commit"; 
 } 
 catch(any e) { 
  transaction action="rollback"; 
  } 
 }
