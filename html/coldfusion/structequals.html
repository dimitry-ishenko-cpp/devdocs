structEquals

Performs a deep comparison of two structures to see if they represent the same values

structEquals(struct1, struct2) → returns boolean

Member Function Syntax

struct1.equals(struct2)

  • BL 1.0.0+

    • Argument Reference

    struct1 struct
    Required

    A structure to compare

    struct2 struct
    Required

    A structure to compare

    Examples
    Sample code invoking the structEquals function

    Append options to config struct (without overwrite flag) 

    config1 = {a:0, b:0};
config2 = {a:0, b:1};
writeOutput( structEquals(config1, config2) );

    Expected Result: false

    Member function comparison of two structs 

    config1 = {a:0, b:0};
config2 = {a:0, b:1};
writeOutput( config1.equals(config2) );

    Expected Result: false
