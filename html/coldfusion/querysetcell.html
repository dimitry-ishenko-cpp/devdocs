querySetCell

Sets a cell to a value. If no row number is specified, the cell on the last row is set.

querySetCell(query, column, value [, row]) → returns boolean

Member Function Syntax

query.setCell(column, value [, row])

  • CF3+
  • Lucee
  • BL 1.0.0+
    • See Also: QueryAddColumn QueryAddRow QueryNew

    Argument Reference

    query query
    Required

    column string
    Required

    value any
    Required

    row numeric

    Examples
    Sample code invoking the querySetCell function

    Tag Example 

    <!--- start by making a query ---> 
 <cfquery name = "GetCourses" datasource = "cfdocexamples"> 
 SELECT Course_ID, Descript 
 FROM Courses 
 </cfquery> 
<cfset temp = queryAddRow(GetCourses)> 
<cfset Temp = querySetCell(GetCourses, "Number", 100*CountVar)>

    Script member function example 

    <cfscript>
	q = queryNew( "id,name");
	q.addRow();
	q.setCell("id", 1, 1);
	q.setCell("name", "one", 1);
	writeDump(q);
</cfscript>
