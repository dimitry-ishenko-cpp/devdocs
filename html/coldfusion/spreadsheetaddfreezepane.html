spreadsheetAddFreezePane

Adds freeze pane (non-scrollable columns/rows) to spreadsheet

spreadsheetAddFreezePane(spreadsheetObj, column, row [, endColumn] [, endRow]) → returns void

  • CF

    • Argument Reference

    spreadsheetObj variableName
    Required

    Spreadsheet variable name

    freezeColumn numeric
    Required

    Amount of columns from left which should be freeze

    freezeRow numeric
    Required

    Amount of rows from top which should be freeze

    hideColumn numeric

    Amount of columns which should be hidden under/behind freeze columns (Scrolls left to first unhidden column).

    hideRow numeric

    Amount of rows which should be hidden under/behind freeze rows (Scrolls down to first unhidden row).
