getVariable

Retrieves value of a variable

getVariable(name) → returns any

  • Lucee
  • BL 1.0.0+
    • See Also: setVariable

    Argument Reference

    name string
    Required

    Examples
    Sample code invoking the getVariable function

    Retrieve value of a variable 

    a=1;
writeOutput(getVariable('a'));

    Expected Result: 1
