parseNumber

Converts string to number in numeral system

parseNumber(number [, radix]) → returns numeric

  • Lucee
  • BL 1.0.0+
    • See Also: lsparseNumber toNumeric parseNumber

    Argument Reference

    number string
    Required

    radix string

    Values:
    • bin
    • oct
    • dec
    • hex

    Examples
    Sample code invoking the parseNumber function

    Convert decimal number to binary 

    parseNumber(1010,"bin")

    Expected Result: 10

    Convert decimal number to hex 

    parseNumber(1010,"hex")

    Expected Result: 4112
