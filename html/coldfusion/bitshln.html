bitShln

Performs a bitwise shift-left, no-rotation operation.

bitShln(number, count) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: bitShrn

    Argument Reference

    number numeric
    Required

    Integer

    count numeric
    Required

    Number of bits to shift to the left (Integer in the range 0-31, inclusive)
