isNumeric

Determines whether a string can be converted to a numeric value. Supports numbers in U.S. number format. For other number support use LSIsNumeric.

isNumeric(String) → returns boolean

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: isValid

    Argument Reference

    String string
    Required

    Examples
    Sample code invoking the isNumeric function

    Integer isNumeric 

    isNumeric(23)

    Expected Result: YES

    String isNumeric 

    isNumeric("twenty")

    Expected Result: NO

    Scientific Notation

    The number 5e2 is scientific notation for 5 x 10^2 aka 500

    isNumeric(5e2)

    Expected Result: YES
