cacheGetProperties

Gets the cache properties for the object cache, the page cache, or both. The information is application-specific.

cacheGetProperties(region) → returns array

  • CF9+
  • Lucee
    • See Also: cacheSetProperties

    Argument Reference

    region string

    Lucee 4.5+ CF 10+ Properties to get information for"" or not set - information to all default cachesobject - information to "Default Object" Cachetemplate - information to "Default Template" Cachequery - information to "Default Query" Cacheresource - information to "Default Resource" Cache{cache name} - information to a specific cache
    Values:
    • object
    • template
    • resource
    • query
