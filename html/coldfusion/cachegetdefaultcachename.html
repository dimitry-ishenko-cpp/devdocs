cacheGetDefaultCacheName

Returns the default cache name for the specified type.

cacheGetDefaultCacheName(type) → returns string

This function requires Lucee. Not supported on Adobe ColdFusion, etc.
  • Lucee

    • Argument Reference

    type string
    Required

    Cache type
    Values:
    • object
    • resource
    • template
    • query
