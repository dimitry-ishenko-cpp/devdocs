arrayMedian

Calculates the Median value of items in an array. All elements in the array must contain values that can be converted to numeric.

arrayMedian(array) → returns numeric

Member Function Syntax

array.median()

  • Lucee
  • BL 1.0.0+
    • See Also: arrayMid

    array array
    Required
