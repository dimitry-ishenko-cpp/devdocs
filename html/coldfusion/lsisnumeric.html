lsIsNumeric

Determines whether a string is a valid representation of a number in the current locale.

lsIsNumeric(String) → returns boolean

  • CF
  • Lucee
  • BL 1.0.0+

    • Argument Reference

    String string
    Required

    Examples
    Sample code invoking the lsIsNumeric function

    Simple Lsisnumeric Example

    Check whether the string is number or not in locale

    lsIsNumeric('Ten')

    Expected Result: NO

    Simple Lsisnumeric Example

    Check whether the string is number or not in locale

    lsIsNumeric('4678')

    Expected Result: YES
