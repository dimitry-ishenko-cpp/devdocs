cfobjectcache

Flushes the query cache.

<cfobjectcache action="clear">

cfobjectcache(action="clear");

  • CF6+
  • Lucee
    • See Also: cfobject

    Attribute Reference

    action string
    Required
    Default: clear

    clear: Clears queries from the cache in the Application scope
    Values:
    • clear
