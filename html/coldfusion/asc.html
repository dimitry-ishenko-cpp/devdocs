asc

Determines the ASCII value of a character.

asc(string) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: chr ascii

    Argument Reference

    string string
    Required

    Compatibility

    BoxLang:

    Version 1.0.0+ asc is transpiled to ascii in CFML files

    Examples
    Sample code invoking the asc function

    character and value of Korean currency symbol ( unicode number 8361 ) 

    x = chr( 8361 ); 
 writeoutput( 'character: #x#' ); 
 x = asc( x ); 
 writeoutput( '<br>Unicode value: #x#');
