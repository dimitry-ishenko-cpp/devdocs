verifySignedJWT

Verify a signed JWT (JSON Web Signature - JWS)

verifySignedJWT(token, signOptions, config) → returns struct

This function requires Adobe ColdFusion 2023 and up. Not supported on Lucee, etc.
  • CF2023+
    • See Also: createSignedJWT

    Argument Reference

    token string
    Required

    A signed JWT

    signOptions struct
    Required

    The signature uses the key information from the given struct

    config struct
    Required

    A struct with the following values:- clockSkew : time in seconds to account for difference between the systems generating and processing the JWT- returntype : plaintext/struct
