getMetricData

Gets server performance metrics [mode - quickly]

getMetricData(mode) → returns any

  • CF4.5+
  • Lucee

    • Argument Reference

    mode string
    Required

    perf_monitor - Returns internal data, in a structure. simple_load - Returns an integer value that is computed from the state of the server's internal queues. Indicates the overall server load. prev_req_time - Returns the time, in milliseconds, that it took the server to process the previous request. avg_req_time - Returns the average time, in milliseconds, that it takes the server to process a request.
    Values:
    • perf_monitor
    • simple_load
    • prev_req_time
    • avg_req_time

    Compatibility

    Lucee:

    DEPRECATED since version 4

    Railo:

    DEPRECATED since version 0
