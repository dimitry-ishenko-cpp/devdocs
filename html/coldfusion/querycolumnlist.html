queryColumnList

Returns the column names of a query as a list.

queryColumnList(query [, delimiter]) → returns string

Member Function Syntax

query.columnList([delimiter])

  • Lucee
  • BL 1.0.0+
    • See Also: queryColumnList queryColumnCount queryColumnExists valueArray

    Argument Reference

    query query
    Required

    delimiter string
    Default: ,

    Examples
    Sample code invoking the queryColumnList function

    Create a query and output the column list 

    myQuery = queryNew( 'ID,name,age' );
writeOutput( queryColumnList( myQuery ) );

    Expected Result: ID,name,age

    Using a member function 

    myQuery = queryNew( 'ID,name,age' );
writeOutput( myQuery.columnList() );

    Expected Result: ID,name,age
