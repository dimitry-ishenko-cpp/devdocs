cfprocresult

Associates a query object with a result set returned by a stored procedure. Other CFML tags, such as cfoutput and cftable, use this query object to access the result set. This tag is nested within a cfstoredproc tag.

<cfprocresult name="">

cfprocresult(name="");

  • CF4+
  • Lucee
  • BL 1.0.0+
    • See Also: cfstoredproc cfprocparam

    Attribute Reference

    name string
    Required

    Name for the query result set.

    resultset numeric

    Names one result set, if stored procedure returns more than one.

    maxrows numeric

    Maximum number of rows returned in result set.

    Compatibility

    BoxLang:

    Version 1.0.0+ <bx:procresult> in BoxLang
