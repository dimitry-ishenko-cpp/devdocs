floor

Returns the integer less than or equal to the input. This function is equivalent to the int function.

floor(number) → returns numeric

  • CF2016+
  • Lucee5.1+
  • BL 1.0.0+
    • See Also: int ceiling round

    Argument Reference

    number numeric
    Required

    A numeric value

    Examples
    Sample code invoking the floor function

    Floor Value of 4.0
