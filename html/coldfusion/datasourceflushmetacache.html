datasourceFlushMetacache

Flush the meta data stored for a certain datasource used for stored procedures. NOTE: This is only supported for Oracle datasources.

datasourceFlushMetacache([datasourceName]) → returns boolean

  • Lucee

    • Argument Reference

    datasourceName string

    Name of the datasource to flush. When not defined all caches are flushed.
