spreadsheetRead

Create a new spreadsheet variable from specified file

spreadsheetRead(fileName, spreadsheetObj) → returns void

  • CF

    • Argument Reference

    fileName string
    Required

    Path to spreadsheet file

    spreadsheetObj variableName
    Required

    Spreadsheet name or number

    Examples
    Sample code invoking the spreadsheetRead function

    Script Example 

    <cfscript> 
 a = SpreadSheetRead('C:\Files\Report.xls',"Annual Report") 
 </cfscript>
