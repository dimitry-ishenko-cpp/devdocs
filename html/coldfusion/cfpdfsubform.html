cfpdfsubform

Populates a subform within the cfpdfform tag. The cfpdfsubform tag can be a child tag of the cfpdfform tag or nested in another cfpdfsubform tag.

<cfpdfsubform name="">

cfpdfsubform(name="");

This tag requires Adobe ColdFusion 8 and up. Not supported on Lucee, etc.
  • CF8+
    • See Also: cfpdf cfpdfform cfpdfformparam

    Attribute Reference

    index numeric

    Index associated with the field name. If multiple fields have the same name, ColdFusion uses the index value is to locate one of them. (optional, default=1)

    name string
    Required

    Name of the subform corresponding to subform name in the PDF form. (required)
