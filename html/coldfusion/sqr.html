sqr

Calculates the square root of a number.

sqr(number) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+

    • Argument Reference

    number numeric
    Required

    A positive integer or a variable that contains one. Number whose square root to get.

    Examples
    Sample code invoking the sqr function

    Square Root of 144 

    sqr(144)

    Expected Result: 12
