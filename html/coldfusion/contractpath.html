contractPath

Opposite of expandpath.Tries to match a given absolute path to mappings in the environment and will return a path that is contracted by the shortest matched mapping. If there are no matches, Lucee returns the absolute path it was given.

contractPath(path [, placeholder]) → returns string

  • Lucee
  • BL 1.0.0+
    • See Also: expandPath

    Argument Reference

    path_absolute string
    Required

    The absolute path

    placeholder boolean
    Default: false

    A boolean indicating whether Lucee placeholder names should be prefixed to the path.
