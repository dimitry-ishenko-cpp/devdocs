cfadmin

Used internally by Lucee (and Railo) in the administrator to apply settings. This tag is considered undocumented / subject to change.

<cfadmin>

cfadmin();

This tag requires Lucee. Not supported on Adobe ColdFusion, etc.
  • Lucee

    • Attribute Reference

    action string
    Required

    The administrative action to perform.

    type string
    Required

    The admin context: web or server
    Values:
    • web
    • server

    password string
    Required

    The admin password.

    Links more information about cfadmin

    • Lucee Documentation - Lucee documentation for cfadmin tag.
    • Old Railo CFAdmin Reference - Railo documentation for cfadmin tag.
