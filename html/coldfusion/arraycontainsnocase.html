arrayContainsNoCase

Used to determine if a value is in the given array, case insensitive.

arrayContainsNoCase(array, value) → returns boolean

Member Function Syntax

someArray.containsNoCase(value)

  • CF2016+
  • Lucee
  • BL 1.0.0+
    • See Also: arrayContains arrayFind arrayFindNoCase arrayFindAll arrayFindAllNoCase

    Argument Reference

    array array
    Required

    value any
    Required

    Compatibility

    Lucee:

    Returns index of first occurrence

    ColdFusion:

    Version 2016+ Member function only available in CF2021+

    Examples
    Sample code invoking the arrayContainsNoCase function

    Basic example

    CF 2016+

    writeOutput(arrayContainsNoCase(["first", "SECOND"], "First"));

    Member function syntax

    Lucee 4+ CF 2021+

    arrayWithStrings = ["first", "SECOND"];
writeOutput(arrayWithStrings.containsNoCase("FIrst"));
