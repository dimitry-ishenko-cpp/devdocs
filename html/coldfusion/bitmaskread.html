bitMaskRead

Performs a bitwise mask read operation. Returns an integer representation of the corresponding bits specified in the mask.

bitMaskRead(number, start, length) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: bitMaskClear bitMaskSet

    Argument Reference

    number numeric
    Required

    Integer

    start numeric
    Required

    Start bit for the read mask (Integer in the range 0-31, inclusive)

    length numeric
    Required

    Length of bits in the read mask (Integer in the range 0-31, inclusive)
