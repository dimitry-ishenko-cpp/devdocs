isCustomFunction

Determines if a variable is a user defined function

isCustomFunction(Object) → returns boolean

  • CF5+
  • Lucee
  • BL 1.0.0+
    • See Also: isClosure

    Argument Reference

    Object any
    Required

    The variable to test

    Examples
    Sample code invoking the isCustomFunction function

    isCustomFunction Example

    Here we've example to check the given variable is user defined function or not.

    function myfunc() {

return 1;

}

 writeDump( isCustomFunction(myfunc) );

    Expected Result: YES

    isCustomFunction Example

    Here we've example to check the given variable is user defined function or not.

    myfunc ="2";

 writeDump( isCustomFunction(myfunc) );

    Expected Result: NO
