threadJoin

Waits for the given thread object to finish running

threadJoin() → returns void

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: cfthread threadTerminate

    Argument Reference

    threadName string

    Thread to joinIf no threadName is specified, all running threads will be affected.You can pass a threadname as string or multiple threads as comma-separated list

    timeout numeric
    Default: 0

    The number of milliseconds for which to suspend thread processing
