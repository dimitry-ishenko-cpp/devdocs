listCompact

Remove empty elements from start and end of the list

listCompact(list [, delimiters] [, multiCharacterDelimiter]) → returns string

Member Function Syntax

list.listCompact([delimiters] [, multiCharacterDelimiter])

  • Lucee
  • BL 1.0.0+
    • See Also: listRemoveDuplicates

    Argument Reference

    list string
    Required

    delimiters string
    Default: ,

    multiCharacterDelimiter boolean
    Default: false

    Examples
    Sample code invoking the listCompact function

    Trims first and last comma from list string 

    listCompact(",eggs,milk,bread,flour,")

    Expected Result: eggs,milk,bread,flour
