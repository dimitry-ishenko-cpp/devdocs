round

Rounds a number to the closest integer.

round(number) → returns numeric

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: ceiling floor

    Argument Reference

    number numeric
    Required

    Examples
    Sample code invoking the round function

    Round 1.56 

    round(1.56)

    Expected Result: 2

    Round 1.49 

    round(1.49)

    Expected Result: 1

    Round -0.9 

    round(-0.9)

    Expected Result: -1
