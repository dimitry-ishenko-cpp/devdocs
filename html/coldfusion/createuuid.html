createUUID

Creates a Universally Unique Identifier (UUID). A UUID is a 35-character string representation of a unique 128-bit integer xxxxxxxx-xxxx-xxxx-xxxxxxxxxxxxxxxx : x is a hexadecimal digit (8-4-4-16). SQL Server UUIDs are similar but have a format of 8-4-4-4-12.

createUUID() → returns uuid
