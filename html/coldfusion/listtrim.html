listTrim

trims leading and trailing spaces from each list element

listTrim(list [, delimiters]) → returns string

  • Lucee
  • BL 1.0.0+
    • See Also: listCompact listItemTrim trim

    Argument Reference

    list string
    Required

    a string list

    delimiters string
    Default: ,

    characters that separate list elements

    Compatibility

    Lucee:
