urlEncodedFormat

Generates a URL-encoded string. For example, it replaces spaces with %20, and non-alphanumeric characters with equivalent hexadecimal escape sequences. Passes arbitrary strings within a URL.

urlEncodedFormat(String [, charset]) → returns string

Discouraged: The continued use of this function is discouraged. It is recommended that you use EncodeForURL for all new applications.

    Argument Reference

    String string
    Required

    A string or a variable that contains one

    charset string

    The character encoding in which the string is encoded.
    Values:
    • utf-8
    • iso-8859-1
    • windows-1252
    • us-ascii
    • shift_jis
    • iso-2022-jp
    • euc-jp
    • euc-kr
    • big5
    • euc-cn
    • utf-16
