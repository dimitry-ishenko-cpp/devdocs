formatBaseN

Converts number to a string, in the base specified by radix.

formatBaseN(number, radix) → returns string

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: parseNumber inputBaseN toString

    Argument Reference

    number numeric
    Required

    The number to convert

    radix numeric
    Required

    The base radix to use

    Examples
    Sample code invoking the formatBaseN function

    Format 10 as dual number 

    formatBaseN(10,2)

    Expected Result: 1010

    Format 1024 as hexadecimal number 

    formatBaseN(1024,16)

    Expected Result: 400

    Format 125 as decimal number 

    formatBaseN(125,10)

    Expected Result: 125

    Format a float

    Floors float to integer then formats with radix given

    formatBaseN(10.75,2)

    Expected Result: 1010
