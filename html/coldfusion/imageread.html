imageRead

Reads the source pathname or URL and creates a ColdFusion image.

imageRead(path) → returns any

  • CF8+
  • Lucee4.5+
  • BL 1.0.0+
    • See Also: cfimage ImageNew ImageReadBase64 ImageWrite IsImageFile

    Argument Reference

    path string
    Required

    On-disk or in-memory pathname or URL of the source image.

    Compatibility

    BoxLang:

    Version 1.0.0+ Requires the bx-image module.

    Links more information about imageRead

    • Reading And Writing Images - This Tutorial illustrate Image function

    Examples
    Sample code invoking the imageRead function

    Using script syntax

    Read an image from URL and output

    imgObj = imageRead("http://cfdocs.org/apple-touch-icon.png");
cfimage(action="writeToBrowser", source=imgObj);
