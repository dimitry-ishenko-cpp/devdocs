cfassociate

Allows subtag data to be saved with a base tag. Applies only to custom tags.

<cfassociate basetag="">

cfassociate(basetag="");

  • CF4+
  • Lucee
  • BL 1.0.0+
    • See Also: cfmodule

    Attribute Reference

    basetag string
    Required

    Base tag name

    datacollection string

    Structure in which base tag stores subtag data

    Compatibility

    BoxLang:
