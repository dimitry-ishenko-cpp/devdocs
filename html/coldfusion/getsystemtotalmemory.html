getSystemTotalMemory

Gets details of the memory that is available for the operating system, in bytes.

getSystemTotalMemory(); → returns numeric

  • CF10+
  • Lucee
  • BL 1.0.0+
    • See Also: getSystemFreeMemory getMemoryUsage getCpuUsage

    Argument Reference

    region string

    Indicates the cache region from which to remove the stored objects. If no value is specified, default cache region is considered by default.

    Compatibility

    BoxLang:

    Version 1.0.0+ Requires the bx-ini module.

    Examples
    Sample code invoking the getSystemTotalMemory function

    The in-memory file system memory set in cfadmin 

    #NumberFormat(getSystemTotalMemory() / 1000 / 1000,"0.00")# MB
