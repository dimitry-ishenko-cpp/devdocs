ormIndex

Performs offline indexing - using this function without specifying parameters, all persistent entities of a given application are indexed.

ormIndex(); ormIndex('entity_name'); ormIndex('entity_list'); ormIndex('entityObject'); → returns void

This function requires Adobe ColdFusion 10 and up. Not supported on Lucee, etc.
