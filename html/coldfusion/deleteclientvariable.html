deleteClientVariable

Deletes a client variable. Returns true if variable was successfully deleted; false if it was not deleted.NOTE: To test for the existence of a variable, use IsDefined or structKeyExists.)

deleteClientVariable(name) → returns boolean

  • CF
  • Lucee
  • BL 1.0.0+
    • See Also: getClientVariablesList

    Argument Reference

    name string
    Required

    The name of a client variable to delete, surrounded by double-quotation marks.

    Compatibility

    ColdFusion:

    ColdFusion MX: Changed behavior: if the variable is not present, this function now returns False. (In earlier releases, it threw an error.)
