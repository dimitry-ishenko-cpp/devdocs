dayOfWeekShortAsString

Returns the first three letters of the day of the week passed to the function

dayOfWeekShortAsString(day_of_week [, locale]) → returns string

  • Lucee
  • BL 1.0.0+
    • See Also: dayOfWeekAsString

    Argument Reference

    day_of_week numeric
    Required

    Only values from 1 to 7 are valid.Week starting with 1 for Sunday and ends with 7 for Saturday.
    Values:
    • 1
    • 2
    • 3
    • 4
    • 5
    • 6
    • 7

    locale string

    Examples
    Sample code invoking the dayOfWeekShortAsString function

    Get Sunday 

    dayOfWeekShortAsString(1)

    Expected Result: Sun

    Get Sunday with french locale 

    dayOfWeekShortAsString(1,"fr")

    Expected Result: dim.
