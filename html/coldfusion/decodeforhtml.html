decodeForHTML

Decodes an HTML encoded string.

decodeForHTML(string); → returns string

  • CF10+
  • Lucee
  • BL 1.0.0+
    • See Also: EncodeForHTML EncodeForHTMLAttribute EncodeForJavaScript EncodeForCSS EncodeForURL

    Argument Reference

    string string
    Required

    The encoded string to decode.

    Compatibility

    BoxLang:

    Version 1.0.0+ Requires the bx-esapi module
