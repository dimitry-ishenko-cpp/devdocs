verifyEncryptedJWT

Verify an encrypted JWT (JSON Web Encryption - JWE)

verifyEncryptedJWT(token, encryptOptions, config) → returns struct

This function requires Adobe ColdFusion 2023 and up. Not supported on Lucee, etc.
  • CF2023+
    • See Also: createEncryptedJWT

    Argument Reference

    token string
    Required

    An encrypted JWT

    encryptOptions struct
    Required

    The encryption uses the key information from the given struct

    config struct
    Required

    A struct with the following values:- clockSkew : time in seconds to account for difference between the systems generating and processing the JWT- returntype : plaintext/struct
