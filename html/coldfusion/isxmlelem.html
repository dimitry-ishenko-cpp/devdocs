isXMLElem

Determines whether a function parameter is an Extended Markup language (XML) document object element.

isXMLElem(value) → returns boolean

  • CF6+
  • Lucee
  • BL 1.0.0+
    • See Also: isXMLDoc isXML

    Argument Reference

    value any
    Required

    XML Element

    Examples
    Sample code invoking the isXMLElem function

    Check if given path is an XML element 

    <cfxml variable="example">
	<coldfusionengines>
		<engine>
			<name>Adobe ColdFusion</name>
		</engine>
		<engine>
			<name>Lucee</name>
		</engine>
		<engine>
			<name>Railo</name>
		</engine>
		<engine>
			<name>Open BlueDragon</name>
		</engine>
	</coldfusionengines>
</cfxml>
<cfscript>
	writeOutput(isXMLElem(example.coldfusionengines));
</cfscript>

    Expected Result: YES
