getPrinterInfo

Determines which print attributes are supported by a selected printer.

getPrinterInfo([printer]) → returns struct

This function requires Adobe ColdFusion 8 and up. Not supported on Lucee, etc.
  • CF8+
    • See Also: getPrinterList cfprint

    Argument Reference

    printer string

    Name of the printer

    Examples
    Sample code invoking the getPrinterInfo function

    Output printer info if exists 

    try {
	writeDump(getPrinterInfo());
}
catch (Application e) {
	writeOutput(e.message & "<br />" & e.detail);
}
catch (any e) {
	rethrow;
}
