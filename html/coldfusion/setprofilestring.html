setProfileString

Sets the value of a profile entry in an initialization file.

setProfileString(inipath, section, entry, value) → returns string

  • CF4+
  • Lucee
  • BL 1.0.0+
    • See Also: getProfileString

    Argument Reference

    inipath string
    Required

    Absolute path of initialization file

    section string
    Required

    Section of the initialization file in which the entry is to be set

    entry string
    Required

    Name of the entry to set

    value string
    Required

    Value to which to set the entry

    Compatibility

    BoxLang:

    Version 1.0.0+ Requires the bx-ini module.
