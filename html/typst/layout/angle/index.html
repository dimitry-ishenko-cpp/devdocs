angle

An angle describing a rotation.

Typst supports the following angular units:

  • Degrees: 180deg
  • Radians: 3.14rad

Example

#rotate(10deg)[Hello there!]

Definitions

rad

Converts this angle to radians.

self.rad() → float

deg

Converts this angle to degrees.

self.deg() → float
