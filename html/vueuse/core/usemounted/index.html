useMounted

Category Component
Export Size 120 B
Last Changed last year

Mounted state in ref.

Usage 

import { useMounted } from '@vueuse/core'

const isMounted = useMounted()

Which is essentially a shorthand of:

const isMounted = ref(false)

onMounted(() => {
  isMounted.value = true
})
'use strict'
const isMounted = ref(false)
onMounted(() => {
  isMounted.value = true
})
