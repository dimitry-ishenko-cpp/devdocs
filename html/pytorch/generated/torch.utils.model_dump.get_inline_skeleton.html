torch.utils.model_dump.get_inline_skeleton

torch.utils.model_dump.get_inline_skeleton() [source]

Get a fully-inlined skeleton of the frontend.

The returned HTML page has no external network dependencies for code. It can load model_info.json over HTTP, or be passed to burn_in_info.
