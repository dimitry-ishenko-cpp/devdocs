torch.mtia.set_rng_state

torch.mtia.set_rng_state(new_state, device='mtia') [source][source]

Sets the random number generator state.

Parameters
  • new_state (torch.ByteTensor) – The desired state
  • device (torch.device or int, optional) – The device to set the RNG state. Default: 'mtia' (i.e., torch.device('mtia'), the current mtia device).
