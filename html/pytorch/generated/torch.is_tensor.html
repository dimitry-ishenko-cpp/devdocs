torch.is_tensor

torch.is_tensor(obj, /) [source]

Returns True if obj is a PyTorch tensor.

Parameters:

obj (object) – Object to test

Return type:

TypeIs[Tensor]

Example:

>>> x = torch.tensor([1, 2, 3])
>>> torch.is_tensor(x)
True
