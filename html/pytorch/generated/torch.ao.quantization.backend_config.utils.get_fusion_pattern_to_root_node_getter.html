get_fusion_pattern_to_root_node_getter

class torch.ao.quantization.backend_config.utils.get_fusion_pattern_to_root_node_getter(backend_config) [source]

Get a map from fusion pattern to a function that returns the root node from the fusion pattern, e.g. the most common one is:

def get_root_node(node_pattern):
    while not isinstance(node_pattern[-1], Node):
        node_pattern = node_pattern[-1]
    return node_pattern[-1]

This can work for all patterns whose root node is the “last node” in the pattern, e.g. (torch.add, MatchAllNode, (torch.ReLU, torch.Conv2d)).

Return type:

dict[Pattern, Callable]
