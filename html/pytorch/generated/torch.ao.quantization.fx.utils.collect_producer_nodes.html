collect_producer_nodes

class torch.ao.quantization.fx.utils.collect_producer_nodes(node) [source]

Starting from a target node, trace back until we hit input or getattr node. This is used to extract the chain of operators starting from getattr to the target node, for example:

def forward(self, x):
    observed = self.observer(self.weight)
    return F.linear(x, observed)

collect_producer_nodes(observed) will either return a list of nodes that produces the observed node or None if we can’t extract a self contained graph without free variables(inputs of the forward function).

Return type:

list[Node] | None
