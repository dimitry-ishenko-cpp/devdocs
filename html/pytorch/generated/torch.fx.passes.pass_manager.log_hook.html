torch.fx.passes.pass_manager.log_hook

torch.fx.passes.pass_manager.log_hook(fn, level=20) [source]

Logs callable output.

This is useful for logging output of passes. Note inplace_wrapper replaces the pass output with the modified object. If we want to log the original output, apply this wrapper before inplace_wrapper.

Example:

def my_pass(d: Dict) -> bool:
    changed = False
    if "foo" in d:
        d["foo"] = "bar"
        changed = True
    return changed


pm = PassManager(passes=[inplace_wrapper(log_hook(my_pass))])

  • level (int) – logging level (e.g. logging.INFO)
