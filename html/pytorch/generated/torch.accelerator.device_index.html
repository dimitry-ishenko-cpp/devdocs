device_index

class torch.accelerator.device_index(device, /) [source]

Context manager to set the current device index for the current accelerator. Temporarily changes the current device index to the specified value for the duration of the context, and automatically restores the previous device index when exiting the context.

Parameters

device (Optional[int]) – a given device index to temporarily set. If None, no device index switching occurs.

Examples

>>> # Set device 0 as the current device temporarily
>>> with torch.accelerator.device_index(0):
...     # Code here runs with device 0 as the current device
...     pass
>>> # Original device is now restored
>>> # No-op when None is passed
>>> with torch.accelerator.device_index(None):
...     # No device switching occurs
...     pass
