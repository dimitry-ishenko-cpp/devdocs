torch.mtia.manual_seed

torch.mtia.manual_seed(seed) [source]

Sets the seed for generating random numbers for the current MTIA device. It’s safe to call this function if MTIA is not available; in that case, it is silently ignored.

Parameters:

seed (int) – The desired seed.

Warning

If you are working with a multi-GPU model, this function is insufficient to get determinism. To seed all GPUs, use manual_seed_all().
