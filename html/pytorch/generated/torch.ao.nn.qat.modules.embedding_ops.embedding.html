Embedding

class torch.ao.nn.qat.modules.embedding_ops.Embedding(num_embeddings, embedding_dim, padding_idx=None, max_norm=None, norm_type=2.0, scale_grad_by_freq=False, sparse=False, _weight=None, device=None, dtype=None, qconfig=None) [source]

An embedding bag module attached with FakeQuantize modules for weight, used for quantization aware training.

We adopt the same interface as torch.nn.Embedding, please see https://pytorch.org/docs/stable/generated/torch.nn.Embedding.html#torch.nn.Embedding for documentation.

Similar to torch.nn.Embedding, with FakeQuantize modules initialized to default.
