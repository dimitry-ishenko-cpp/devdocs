torch.mps.get_rng_state

torch.mps.get_rng_state(device='mps') [source][source]

Returns the random number generator state as a ByteTensor.

Parameters

device (torch.device or int, optional) – The device to return the RNG state of. Default: 'mps' (i.e., torch.device('mps'), the current MPS device).

Return type

Tensor
