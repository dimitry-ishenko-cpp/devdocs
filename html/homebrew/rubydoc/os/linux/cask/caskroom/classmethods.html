This method is part of a private API. This method may only be used in the Homebrew/brew repository. Third parties should avoid using this method if possible, as it may be removed or changed without warning.

Unlike macOS (which uses the admin group), Homebrew on Linux is run in a variety of distributions, so use the current user's primary group as the group of the Caskroom directory. This avoids a sudo prompt to chgrp the directory after creation.

def expected_caskroom_group
  @expected_caskroom_group ||= T.let(
    begin
      Etc.getgrgid(Process.egid)&.name || "root"
    rescue ArgumentError
      "root"
    end,
    T.nilable(String),
  )
end
