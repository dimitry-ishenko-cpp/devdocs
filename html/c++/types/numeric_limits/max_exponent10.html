std::numeric_limits<T>::max_exponent10

static const int max_exponent10;
(until C++11) 
static constexpr int max_exponent10;
(since C++11)

The value of std::numeric_limits<T>::max_exponent10 is the largest positive number n such that \(\scriptsize 10^n\)10n is a representable finite value of the floating-point type T.

Example

Demonstrates the relationships of max_exponent, max_exponent10, and max() for the type float:

#include <iostream>
#include <limits>

int main()
{
    std::cout << "max() = " << std::numeric_limits<float>::max() << '\n'
              << "max_exponent10 = " << std::numeric_limits<float>::max_exponent10 << '\n'
              << std::hexfloat << '\n'
              << "max() = " << std::numeric_limits<float>::max() << '\n'
              << "max_exponent = " << std::numeric_limits<float>::max_exponent << '\n';
}

Output:

max() = 3.40282e+38
max_exponent10 = 38

max() = 0x1.fffffep+127
max_exponent = 128
