std::meta::is_class_template

Defined in header <meta> 
consteval bool is_class_template( std::meta::info r );
(since C++26)

Returns true if r represents a class template. Otherwise returns false.

Parameters

r - a reflection value

Return value

true if r represents a class template; otherwise false.

Notes

A class template specialization is not a template. For example,

  • std::meta::is_class_template(^^std::list) is true but
  • std::meta::is_class_template(^^std::list<short>) is false.

Example

#include <meta>

// class
struct S1;
static_assert(!std::meta::is_class_template(^^S1));

// class template
template<class T>
union S2;
static_assert(std::meta::is_class_template(^^S2));

int main() {}
