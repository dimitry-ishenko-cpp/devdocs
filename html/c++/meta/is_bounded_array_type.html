std::meta::is_bounded_array_type

Defined in header <meta> 
consteval bool is_bounded_array_type( std::meta::info r );
(since C++26)

Returns true if r represents an array type of known bound. Otherwise returns false.

Parameters

r - a reflection value

Return value

true if r represents an array type of known bound; otherwise false.

Exceptions

Throws std::meta::exception if r does not represent a type or type alias.

Example

#include <meta>

class A {};

static_assert(!is_bounded_array_type(^^A));
static_assert(!is_bounded_array_type(^^A[]));
static_assert( is_bounded_array_type(^^A[3]));
static_assert(!is_bounded_array_type(^^float));
static_assert(!is_bounded_array_type(^^int));
static_assert(!is_bounded_array_type(^^int[]));
static_assert( is_bounded_array_type(^^int[3]));

int main() {}
