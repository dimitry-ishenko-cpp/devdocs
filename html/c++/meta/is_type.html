std::meta::is_type

Defined in header <meta> 
consteval bool is_type( std::meta::info r );
(since C++26)

Returns true if r represents an entity whose underlying entity is a type. Otherwise returns false.

Parameters

r - a reflection value

Return value

true if r represents a type; otherwise false.
