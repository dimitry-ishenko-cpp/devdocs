std::meta::is_signed_type

Defined in header <meta> 
consteval bool is_signed_type( std::meta::info r );
(since C++26)

Returns true if r is a reflection of a signed arithmetic type. Otherwise returns false.

Parameters

r - a reflection value

Return value

true if r represents a signed arithmetic type; otherwise false.

Exceptions

Throws std::meta::exception if r does not represent a type or type alias.

Example

#include <meta>

static_assert(""
    and is_signed_type(^^signed) == true
    and is_signed_type(^^unsigned) == false
    and is_signed_type(^^int) == true
    and is_signed_type(^^bool) == false
    and is_signed_type(^^float) == true
);

int main() {}
