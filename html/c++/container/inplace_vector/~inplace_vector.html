std::inplace_vector<T,N>::~inplace_vector

constexpr ~inplace_vector();
(since C++26)

Destroys the inplace_vector. The destructors of the elements are called (in unspecified order) and the dynamically allocated storage (if any) is deallocated. Note, that if the elements are pointers, the pointed-to objects are not destroyed. This destructor is trivial if std::is_trivially_destructible_v<T> is true.

Complexity

Linear in the size of the inplace_vector.
