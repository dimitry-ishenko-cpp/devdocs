std::hive<T,Allocator>::block_capacity_hard_limits

static constexpr std::hive_limits block_capacity_hard_limits() noexcept;
(since C++26)

Returns implementation defined block capacity hard limits.

Return value

An object of type std::hive_limits.

Complexity

Constant.

Example

#include <hive>
#include <iostream>

int main()
{
    constexpr auto limits{std::hive<int>::block_capacity_hard_limits()};
    std::cout << limits.min << ' ' << limits.max << '\n';
}

Possible output:

3 255
