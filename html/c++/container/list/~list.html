std::list<T,Allocator>::~list

~list();
(constexpr since C++26)

Destroys the list. The destructors of the elements are called (in unspecified order) and the dynamically allocated storage (if any) is deallocated. Note, that if the elements are pointers, the pointed-to objects are not destroyed.

Complexity

Linear in the size of the list.
