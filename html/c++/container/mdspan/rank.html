std::mdspan<T,Extents,LayoutPolicy,AccessorPolicy>::rank

static constexpr rank_type rank() noexcept;
(since C++23)

Returns the number of dimensions in a mdspan. Equivalent to return Extents::rank().

Parameters

(none)

Return value

The number of dimensions.
