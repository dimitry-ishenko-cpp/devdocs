std::vector<T,Allocator>::~vector

~vector();
(constexpr since C++20)

Destroys the vector. The destructors of the elements are called (in unspecified order) and the dynamically allocated storage (if any) is deallocated. Note, that if the elements are pointers, the pointed-to objects are not destroyed.

Complexity

Linear in the size of the vector.
