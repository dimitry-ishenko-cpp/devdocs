C++ keyword: auto

Usage

  • Automatic storage duration specifier
 (until C++11)
  • auto placeholder type specifier
  • Function declaration with trailing return type
 (since C++11)
  • Structured binding declaration
 (since C++17)
  • Abbreviated function template
 (since C++20)
  • Explicit cast to a prvalue copy
 (since C++23)

See also

  • decltype (decltype(auto))
(since C++14)
  • register (Automatic storage duration specifier)
(until C++17)
