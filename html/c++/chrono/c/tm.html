std::tm

Defined in header <ctime> 
struct tm;

Structure holding a calendar date and time broken down into its components.

Example

#include <ctime>
#include <iostream>

int main()
{
    std::tm tm{};
    tm.tm_year = 2022 - 1900;
    tm.tm_mday = 1;
    std::mktime(&tm);

    std::cout << std::asctime(&tm); // note implicit trailing '\n'
}

Possible output:

Sat Jan  1 00:00:00 2022
