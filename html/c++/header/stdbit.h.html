Standard library header <stdbit.h> (C++26)

This header was originally in the C standard library (<stdbit.h>).

This header is part of the general utilities library, in particular, it provides several functions and function templates to access and manipulate both individual bits and bit sequences.

It is unspecified whether <stdbit.h> provides any declarations in namespace std.
