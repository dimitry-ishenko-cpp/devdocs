std::swap(std::indirect)

Defined in header <memory> 
constexpr void swap( indirect& lhs, indirect& rhs )
    noexcept(noexcept(lhs.swap(rhs)));
(since C++26)

Overloads the std::swap algorithm for std::indirect. Exchanges the state of lhs with that of rhs. Effectively calls lhs.swap(rhs).

Parameters

lhs, rhs - indirect objects whose states to swap
