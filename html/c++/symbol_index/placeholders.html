std::placeholders Symbol Index (since C++11)

This page lists all the symbols that are available from the standard library in the namespace std::placeholders. The symbols are written as follows:

  • Function names with ().
  • Templates with <>.

_

_ (underscore)

_1, _2, ..., _N (since C++11)
