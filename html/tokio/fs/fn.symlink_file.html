Function symlink_file 

pub async fn symlink_file(
    original: impl AsRef<Path>,
    link: impl AsRef<Path>,
) -> Result<()>
Available on Windows and crate feature fs only.

Creates a new file symbolic link on the filesystem.

The link path will be a file symbolic link pointing to the original path.

This is an async version of std::os::windows::fs::symlink_file
