pub struct Backtrace { /* private fields */ }
Available on tokio_unstable and Linux and crate feature rt and crate feature taskdump and (AArch64 or s390x or x86 or x86-64) only.

A captured backtrace.

This struct provides access to each backtrace frame, similar to backtrace::Backtrace.

Implementations

impl Backtrace

pub fn frames(&self) -> impl Iterator<Item = &BacktraceFrame>

Return the frames in this backtrace, innermost (in a task dump, likely to be a leaf future’s poll function) first.
