Struct Id 

pub struct Id(/* private fields */);
Available on crate feature rt only.

An opaque ID that uniquely identifies a task relative to all other currently running tasks.

A task’s ID may be re-used for another task only once both of the following happen:

  1. The task itself exits.
  2. There is no active JoinHandle associated with this task.

A JoinHandle is considered active in the following situations:

  • You are explicitly holding a JoinHandle, AbortHandle, or tokio_util::task::AbortOnDropHandle.
  • The task is being tracked by a JoinSet or tokio_util::task::JoinMap.

Notes

  • Task IDs are not sequential, and do not indicate the order in which tasks are spawned, what runtime a task is spawned on, or any other data.
  • The task ID of the currently running task can be obtained from inside the task via the task::try_id() and task::id() functions and from outside the task via the JoinHandle::id() function.
