Remultiplot

remultiplot first restores the graphics state saved in $GPAVL_PRE_MULTIPLOT at the start of the previous multiplot. It then re-executes commands from the datablock named $GPVAL_LAST_MULTIPLOT. The result should reproduce the figure generated by the original multiplot. Remultiplot is different from replot, which does not start by restoring the initial graphics state. See new multiplots.
