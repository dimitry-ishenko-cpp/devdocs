Example

See also C++ compatibility note regarding spaces before format macros used in this example.

#include <inttypes.h>
#include <stdio.h>

int main(void)
{
    printf("%zu\n", sizeof(int64_t));
    printf("%s\n", PRId64);
    printf("%+" PRId64 "\n", INT64_MIN);
    printf("%+" PRId64 "\n", INT64_MAX);
    
    int64_t n = 7;
    printf("%+" PRId64 "\n", n);
}

Possible output:

8
lld
-9223372036854775808
+9223372036854775807
+7
