hoursPerDay constant

int const hoursPerDay

The number of hours per day.

Notice that some calendar days may differ in length because of time zone changes due to daylight saving. The Duration class is calendar and time zone agnostic and considers all days to have 24 hours.

Implementation

static const int hoursPerDay = 24;
