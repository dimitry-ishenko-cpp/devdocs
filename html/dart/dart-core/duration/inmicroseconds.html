dart:core

inMicroseconds property

int inMicroseconds
final

The time offset of this duration in microseconds.

The value can be greater than 999999. For example, a duration of nine seconds, 123 milliseconds and 678 microseconds has 9123678 microseconds.

const duration = Duration(seconds: 9, milliseconds: 123,
    microseconds: 567);
print(duration.inMicroseconds); // 9123678
