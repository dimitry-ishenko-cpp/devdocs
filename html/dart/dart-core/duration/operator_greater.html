operator > method

bool operator >(
  1. Duration other
)

Whether this duration's offset is greater than that of other.

A negative duration's offset is always smaller than a positive one's. Equivalent to comparing inMicroseconds

Implementation

bool operator >(Duration other) => this.inMicroseconds > other.inMicroseconds;
