Socket toSocket()

Extracts opened socket from resource handle.

Since the ResourceHandle represents a single OS resource, none of toFile, toSocket, toRawSocket, or toRawDatagramSocket, toReadPipe, toWritePipe, can be called after a call to this method. If this resource handle is not a socket handle, the behavior of the returned Socket is completely unspecified. Be very careful to avoid using a handle incorrectly.
