Format a date according to RFC-1123, e.g. Thu, 1 Jan 1970 00:00:00 GMT.

Implementation

static String format(DateTime date) {
  StringBuffer sb = StringBuffer();
  _formatTo(date, sb);
  return sb.toString();
}
