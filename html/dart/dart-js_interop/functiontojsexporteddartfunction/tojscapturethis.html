  1. @Since.new('3.6')
JSExportedDartFunction<T> get toJSCaptureThis

A JavaScript function that captures the this value when called and forwards to the T-typed Function.

Identical to toJS, except the resulting JSExportedDartFunction will pass this from JavaScript as the first argument to the converted Function. Any Function that is converted with this member should take in an extra parameter at the beginning of the parameter list to handle the this value.
