dart:js_interop

JSExportedDartFunction<T extends Function> extension type

A JavaScript function created from a Dart function.

The type parameter T should be the Dart function's type.

See FunctionToJSExportedDartFunction.toJS or FunctionToJSExportedDartFunction.toJSCaptureThis for more details on how to convert a Dart function.
