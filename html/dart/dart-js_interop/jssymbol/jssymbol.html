Creates a new, unique JavaScript Symbol.

If description is provided, it's used for debugging but not to access the symbol itself.

Implementation

@Since('3.11')
JSSymbol([String? description])
  : _jsSymbol =
        (description == null
                ? _constructSymbol()
                : _constructSymbol(description))
            ._jsSymbol;
