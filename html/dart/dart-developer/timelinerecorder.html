Values

perfetto → const TimelineRecorder

Perfetto's protobuf based format.

Supports both profiling and tracing data.

Scheme is available in Perfetto docs.

chrome → const TimelineRecorder

Chrome's JSON based format viewable by Catapult.

Supports only tracing data.

Scheme is described in here.

systrace → const TimelineRecorder

Emits platform specific timeline events.

  • On Linux and Android this means writing events into ftrace buffer.
  • On Mac OS X this uses signposts.
  • On Fuchsia it uses Fuchsia tracing system.
  • Not supported on Windows.
