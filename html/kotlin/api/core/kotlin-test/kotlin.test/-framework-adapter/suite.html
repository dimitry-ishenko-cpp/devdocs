suite

kotlin-test/kotlin.test/FrameworkAdapter/suite

Platform and version requirements: JS (1.1), Wasm-JS (1.8), Wasm-WASI (1.8)

abstract fun suite(name: String, ignored: Boolean, suiteFn: () -> Unit)

Declares a test suite.

Parameters

name

the name of the test suite, e.g. a class name

ignored

whether the test suite is ignored, e.g. marked with Ignore annotation

suiteFn

defines nested suites by calling kotlin.test.suite and tests by calling kotlin.test.test
