immutableBlobOf

kotlin-stdlib/kotlin.native/immutableBlobOf

Since Kotlin: 1.3

external fun immutableBlobOf(vararg elements: Short): ImmutableBlob

Deprecated

Warning since 1.9

Error since 2.1

ImmutableBlob is deprecated. Use ByteArray instead.

Replace with

byteArrayOf(*elements)

Creates ImmutableBlob out of compile-time constant data.

This method accepts values of Short type in range 0x00..0xff, other values are prohibited.

One element still represent one byte in the output data. This is the only way to create ImmutableBlob for now.
