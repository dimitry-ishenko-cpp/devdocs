isFreezingEnabled

kotlin-stdlib/kotlin.native/Platform/isFreezingEnabled

Since Kotlin: 1.3

val isFreezingEnabled: Boolean

Deprecated

Error since 2.1

Support for the legacy memory manager has been completely removed. Consequently, this property is always `false`.

Replace with

false

If freezing is enabled. Always false
