subSequence

kotlin-stdlib/kotlin.text/subSequence

Since Kotlin: 1.0

fun CharSequence.subSequence(range: IntRange): CharSequence

Returns a subsequence of this char sequence specified by the given range of indices.

inline fun String.subSequence(start: Int, end: Int): CharSequence

Deprecated

Warning since 1.0

Error since 2.3

Use parameters named startIndex and endIndex.

Replace with

subSequence(startIndex = start, endIndex = end)

Returns a subsequence of this char sequence.

This extension is chosen only for invocation with old-named parameters. Replace parameter names with the same as those of CharSequence.subSequence.
