foldRight

kotlin-stdlib/kotlin.text/foldRight

Since Kotlin: 1.0

inline fun <R> CharSequence.foldRight(initial: R, operation: (Char, acc: R) -> R): R

Accumulates value starting with initial value and applying operation from right to left to each character and current accumulator value.

Returns the specified initial value if the char sequence is empty.

Parameters

operation

function that takes a character and current accumulator value, and calculates the next accumulator value.
