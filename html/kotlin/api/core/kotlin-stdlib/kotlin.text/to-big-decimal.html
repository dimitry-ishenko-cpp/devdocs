toBigDecimal

kotlin-stdlib/kotlin.text/toBigDecimal

Since Kotlin: 1.2

inline fun String.toBigDecimal(): BigDecimal

Parses the string as a java.math.BigDecimal number and returns the result.

Throws

NumberFormatException

if the string is not a valid representation of a number.

inline fun String.toBigDecimal(mathContext: MathContext): BigDecimal

Parses the string as a java.math.BigDecimal number and returns the result.

Parameters

mathContext

specifies the precision and the rounding mode.

Throws

NumberFormatException

if the string is not a valid representation of a number.

ArithmeticException

if the rounding is needed, but the rounding mode is java.math.RoundingMode.UNNECESSARY.
