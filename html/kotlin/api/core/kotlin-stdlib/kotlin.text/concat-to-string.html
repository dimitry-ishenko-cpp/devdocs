concatToString

kotlin-stdlib/kotlin.text/concatToString

Platform and version requirements: Common (1.4), JS (1.4), JVM (1.4), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun CharArray.concatToString(): String

Concatenates characters in this CharArray into a String.

expect fun CharArray.concatToString(startIndex: Int = 0, endIndex: Int = this.size): String

Concatenates characters in this CharArray or its subrange into a String.

Parameters

startIndex

the beginning (inclusive) of the subrange of characters, 0 by default.

endIndex

the end (exclusive) of the subrange of characters, size of this array by default.

Throws

IndexOutOfBoundsException

if startIndex is less than zero or endIndex is greater than the size of this array.

IllegalArgumentException

if startIndex is greater than endIndex.
