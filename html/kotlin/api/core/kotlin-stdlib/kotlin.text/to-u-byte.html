toUByte

kotlin-stdlib/kotlin.text/toUByte

Since Kotlin: 1.5

fun String.toUByte(): UByte

Parses the string as a signed UByte number and returns the result.

Throws

NumberFormatException

if the string is not a valid representation of a number.

fun String.toUByte(radix: Int): UByte

Parses the string as a signed UByte number and returns the result.

Throws

NumberFormatException

if the string is not a valid representation of a number.

IllegalArgumentException

when radix is not a valid radix for string to number conversion.
