toULong

kotlin-stdlib/kotlin.text/toULong

Since Kotlin: 1.5

fun String.toULong(): ULong

Parses the string as a ULong number and returns the result.

Throws

NumberFormatException

if the string is not a valid representation of a number.

fun String.toULong(radix: Int): ULong

Parses the string as a ULong number and returns the result.

Throws

NumberFormatException

if the string is not a valid representation of a number.

IllegalArgumentException

when radix is not a valid radix for string to number conversion.
