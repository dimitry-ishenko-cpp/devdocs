regionMatches

kotlin-stdlib/kotlin.text/regionMatches

Platform and version requirements: Common (1.0), JS (1.1), JVM (1.0), Native (1.3)

expect fun CharSequence.regionMatches(thisOffset: Int, other: CharSequence, otherOffset: Int, length: Int, ignoreCase: Boolean = false): Boolean

Returns true if the specified range in this char sequence is equal to the specified range in another char sequence.

Parameters

thisOffset

the start offset in this char sequence of the substring to compare.

other

the string against a substring of which the comparison is performed.

otherOffset

the start offset in the other char sequence of the substring to compare.

length

the length of the substring to compare.
