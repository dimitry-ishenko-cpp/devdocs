findAll

kotlin-stdlib/kotlin.text/Regex/findAll

Platform and version requirements: Common (1.0), JS (1.1), JVM (1.0), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun findAll(input: CharSequence, startIndex: Int = 0): Sequence<MatchResult>

Returns a sequence of all occurrences of a regular expression within the input string, beginning at the specified startIndex.

Throws

IndexOutOfBoundsException

if startIndex is less than zero or greater than the length of the input char sequence.

Samples

import kotlin.test.*

fun main() { 
   //sampleStart 
   val text = "Hello Alice. Hello Bob. Hello Eve."
val regex = Regex("Hello (.*?)[.]")
val matches = regex.findAll(text)
val names = matches.map { it.groupValues[1] }.joinToString()
println(names) // Alice, Bob, Eve 
   //sampleEnd
}
