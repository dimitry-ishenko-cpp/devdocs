sumBy

kotlin-stdlib/kotlin.text/sumBy

Since Kotlin: 1.0

inline fun CharSequence.sumBy(selector: (Char) -> Int): Int

Deprecated

Warning since 1.5

Use sumOf instead.

Replace with

this.sumOf(selector)

Returns the sum of all values produced by selector function applied to each character in the char sequence.
