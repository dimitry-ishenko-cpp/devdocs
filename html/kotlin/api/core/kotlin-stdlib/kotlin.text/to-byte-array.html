toByteArray

kotlin-stdlib/kotlin.text/toByteArray

Since Kotlin: 1.0

inline fun String.toByteArray(charset: Charset = Charsets.UTF_8): ByteArray

Encodes the contents of this string using the specified character set and returns the resulting byte array.

Samples

import kotlin.test.*

fun main() { 
   //sampleStart 
   val charset = Charsets.UTF_8
val byteArray = "Hello".toByteArray(charset)
println(byteArray.contentToString()) // [72, 101, 108, 108, 111]
println(byteArray.toString(charset)) // Hello 
   //sampleEnd
}
