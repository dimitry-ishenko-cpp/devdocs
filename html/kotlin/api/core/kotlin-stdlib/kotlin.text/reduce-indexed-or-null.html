reduceIndexedOrNull

kotlin-stdlib/kotlin.text/reduceIndexedOrNull

Since Kotlin: 1.4

inline fun CharSequence.reduceIndexedOrNull(operation: (index: Int, acc: Char, Char) -> Char): Char?

Accumulates value starting with the first character and applying operation from left to right to current accumulator value and each character with its index in the original char sequence.

Returns null if the char sequence is empty.

Parameters

operation

function that takes the index of a character, current accumulator value and the character itself, and calculates the next accumulator value.

Samples

import kotlin.math.*
import kotlin.test.*

fun main() { 
   //sampleStart 
   val strings = listOf("a", "b", "c", "d")
println(strings.reduceOrNull { acc, string -> acc + string }) // abcd
println(strings.reduceIndexedOrNull { index, acc, string -> acc + string + index }) // ab1c2d3

println(emptyList<String>().reduceOrNull { _, _ -> "" }) // null 
   //sampleEnd
}
