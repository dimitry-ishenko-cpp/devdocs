toBoolean

kotlin-stdlib/kotlin.text/toBoolean

Platform and version requirements: Common (1.4), JS (1.4), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun String?.toBoolean(): Boolean

Returns true if this string is not null and its content is equal to the word "true", ignoring case, and false otherwise.

There are also strict versions of the function available on non-nullable String, toBooleanStrict and toBooleanStrictOrNull.

Platform and version requirements: JVM (1.4), Native (1.4)
