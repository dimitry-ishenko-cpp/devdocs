clear

kotlin-stdlib/kotlin.text/clear

Platform and version requirements: Common (1.3), JVM (1.3), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)


@IgnorableReturnValue

expect fun StringBuilder.clear(): StringBuilder

Clears the content of this string builder making it empty and returns this instance.

Samples

import kotlin.test.*

fun main() { 
   //sampleStart 
   val builder = StringBuilder()
builder.append("content").append(1)
println(builder) // content1

builder.clear()
println(builder) // 
   //sampleEnd
}
