ExperimentalWasmInterop

kotlin-stdlib/kotlin.wasm/ExperimentalWasmInterop

Since Kotlin: 2.2


@RequiresOptIn(level = RequiresOptIn.Level.WARNING)

annotation class ExperimentalWasmInterop

Marks API related to interoperability with the Wasm platform as experimental.

Note that the behavior of annotated API may likely be changed in the future.

Usages of such API will be reported as warnings unless an explicit opt-in with the OptIn annotation, e.g. @OptIn(ExperimentalWasmInterop::class), or with the -opt-in=kotlin.js.ExperimentalWasmInterop compiler option is given.
