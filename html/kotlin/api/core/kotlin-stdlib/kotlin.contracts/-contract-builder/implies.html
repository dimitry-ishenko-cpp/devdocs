implies

kotlin-stdlib/kotlin.contracts/ContractBuilder/implies

Since Kotlin: 2.2


@ExperimentalExtendedContracts

abstract infix fun Boolean.implies(value: ReturnsNotNull)

Specifies the effect that will be observed if the condition passed as a receiver argument holds.

Only ReturnsNotNull effect is supported for now.

Note: the receiver can accept only a subset of boolean expressions, where a function parameter or receiver (this) undergoes

  • null-checks (== null, != null);

  • instance-checks (is, !is);
