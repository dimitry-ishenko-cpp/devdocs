ConditionalEffect

kotlin-stdlib/kotlin.contracts/ConditionalEffect

Since Kotlin: 1.3


@ExperimentalContracts

interface ConditionalEffect : Effect

An effect of some condition being true after observing another effect of a function.

This effect is specified in the contract { } block by attaching a boolean expression to another SimpleEffect effect with the function SimpleEffect.implies.
