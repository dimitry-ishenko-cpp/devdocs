indexOf

kotlin-stdlib/kotlin.sequences/indexOf

Since Kotlin: 1.0

fun <T> Sequence<T>.indexOf(element: T): Int

Returns first index of element, or -1 if the sequence does not contain element.

The operation is terminal.
