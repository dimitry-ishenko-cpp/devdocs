dropWhile

kotlin-stdlib/kotlin.sequences/dropWhile

Since Kotlin: 1.0

fun <T> Sequence<T>.dropWhile(predicate: (T) -> Boolean): Sequence<T>

Returns a sequence containing all elements except first elements that satisfy the given predicate.

The operation is intermediate and stateless.

Samples

import kotlin.math.*
import kotlin.test.*

fun main() { 
   //sampleStart 
   val chars = ('a'..'z').toList()
println(chars.drop(23)) // [x, y, z]
println(chars.dropLast(23)) // [a, b, c]
println(chars.dropWhile { it < 'x' }) // [x, y, z]
println(chars.dropLastWhile { it > 'c' }) // [a, b, c] 
   //sampleEnd
}
