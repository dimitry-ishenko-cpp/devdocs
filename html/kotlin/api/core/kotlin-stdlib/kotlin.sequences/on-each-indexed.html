onEachIndexed

kotlin-stdlib/kotlin.sequences/onEachIndexed

Since Kotlin: 1.4

fun <T> Sequence<T>.onEachIndexed(action: (index: Int, T) -> Unit): Sequence<T>

Returns a sequence which performs the given action on each element of the original sequence as they pass through it.

Parameters

action

function that takes the index of an element and the element itself and performs the action on the element.

The operation is intermediate and stateless.
