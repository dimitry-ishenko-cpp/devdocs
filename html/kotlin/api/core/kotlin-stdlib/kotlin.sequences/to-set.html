toSet

kotlin-stdlib/kotlin.sequences/toSet

Since Kotlin: 1.0

fun <T> Sequence<T>.toSet(): Set<T>

Returns a Set of all elements.

The returned set preserves the element iteration order of the original sequence.

The operation is terminal.
