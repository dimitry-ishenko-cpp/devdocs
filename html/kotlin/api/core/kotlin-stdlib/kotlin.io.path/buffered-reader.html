bufferedReader

kotlin-stdlib/kotlin.io.path/bufferedReader

Since Kotlin: 1.5

inline fun Path.bufferedReader(charset: Charset = Charsets.UTF_8, bufferSize: Int = DEFAULT_BUFFER_SIZE, vararg options: OpenOption): BufferedReader

Returns a new BufferedReader for reading the content of this file.

Refer to BufferedReader documentation for details about buffering behavior.

Parameters

charset

character set to use for reading text, UTF-8 by default.

bufferSize

necessary size of the buffer.

options

options to determine how the file is opened.
