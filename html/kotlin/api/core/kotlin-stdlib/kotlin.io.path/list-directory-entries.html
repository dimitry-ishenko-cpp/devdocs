listDirectoryEntries

kotlin-stdlib/kotlin.io.path/listDirectoryEntries

Since Kotlin: 1.5

fun Path.listDirectoryEntries(glob: String = "*"): List<Path>

Returns a list of the entries in this directory optionally filtered by matching against the specified glob pattern.

Parameters

glob

the globbing pattern. The syntax is specified by the FileSystem.getPathMatcher method.

See also

Files.newDirectoryStream

Throws

java.util.regex.PatternSyntaxException

if the glob pattern is invalid.

NotDirectoryException

If this path does not refer to a directory.

IOException

If an I/O error occurs.
