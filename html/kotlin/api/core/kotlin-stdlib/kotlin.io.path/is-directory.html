isDirectory

kotlin-stdlib/kotlin.io.path/isDirectory

Since Kotlin: 1.5

inline fun Path.isDirectory(vararg options: LinkOption): Boolean

Checks if the file located by this path is a directory.

By default, symbolic links in the path are followed.

Parameters

options

options to control how symbolic links are handled.
