fileSize

kotlin-stdlib/kotlin.io.path/fileSize

Since Kotlin: 1.5

inline fun Path.fileSize(): Long

Returns the size of a regular file as a Long value of bytes or throws an exception if the file doesn't exist.

See also

Files.size

Throws

IOException

if an I/O error occurred.
