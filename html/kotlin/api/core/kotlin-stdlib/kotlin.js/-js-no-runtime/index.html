JsNoRuntime

kotlin-stdlib/kotlin.js/JsNoRuntime

Since Kotlin: 2.4




@ExperimentalJsNoRuntime




@Target(allowedTargets = [AnnotationTarget.CLASS])



expect annotation class JsNoRuntime

Marks an interface that is not going to be used at runtime on the JS platform.

Interfaces annotated with @JsNoRuntime cannot be used in is checks, as casts, or with class references on the JS platform. Such interfaces can be actualized on JS as external interface.

This annotation is available in common code and is JS-specific via OptionalExpectation.
