JsStatic

kotlin-stdlib/kotlin.js/JsStatic

Since Kotlin: 2.0




@ExperimentalJsStatic




@Target(allowedTargets = [AnnotationTarget.FUNCTION, AnnotationTarget.PROPERTY, AnnotationTarget.PROPERTY_GETTER, AnnotationTarget.PROPERTY_SETTER])



expect annotation class JsStatic

Specifies that an additional static method is generated from the annotated companion object member if it's a function. If the member is a property, additional static getter/setter methods are generated.
