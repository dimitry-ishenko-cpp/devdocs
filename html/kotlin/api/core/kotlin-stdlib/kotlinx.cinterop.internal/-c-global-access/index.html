CGlobalAccess

kotlin-stdlib/kotlinx.cinterop.internal/CGlobalAccess

Since Kotlin: 1.3


@Target(allowedTargets = [AnnotationTarget.PROPERTY_GETTER, AnnotationTarget.PROPERTY_SETTER])

annotation class CGlobalAccess(val name: String)

Indicates that the annotated property getter or setter accesses a C global with the provided linkage name.

Types

Pointer

Since Kotlin: 1.3


@Target(allowedTargets = [AnnotationTarget.PROPERTY_GETTER, AnnotationTarget.PROPERTY_SETTER])

annotation class Pointer

For a @CGlobalAccess property getter, indicates that it returns not a value of that global, but a pointer to the global.
