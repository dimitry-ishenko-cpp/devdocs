qualifiedName

kotlin-stdlib/kotlin.reflect/KClass/qualifiedName

Platform and version requirements: Common (1.0)

expect abstract val qualifiedName: String?

The fully qualified dot-separated name of the class, or null if the class is local or a class of an anonymous object.

This property is currently not supported in Kotlin/JS and Kotlin/Wasm. In Kotlin/Wasm, however, it could be enabled using compiler options. Please refer to the documentation for these targets for more details.

Platform and version requirements: JS (1.1)

actual abstract val qualifiedName: String?

The fully qualified dot-separated name of the class, or null if the class is local or a class of an anonymous object.

This property is currently not supported in Kotlin/JS.

Platform and version requirements: JVM (1.0), Native (1.3)

actual abstract val qualifiedName: String?

The fully qualified dot-separated name of the class, or null if the class is local or a class of an anonymous object.

Platform and version requirements: Wasm-JS (1.8), Wasm-WASI (1.8)

actual abstract val qualifiedName: String?

The fully qualified dot-separated name of the class, or null if the class is local or a class of an anonymous object.

By default, this property is not supported in Kotlin/Wasm and using it will result in a compilation error. To enable fully qualified names, -Xwasm-kclass-fqn compiler flag should be specified. That, however, may increase the size of the linked executable.
