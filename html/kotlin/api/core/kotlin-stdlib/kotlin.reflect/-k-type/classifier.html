classifier

kotlin-stdlib/kotlin.reflect/KType/classifier

Platform and version requirements: Common (1.1), JS (1.1), JVM (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect abstract val classifier: KClassifier?

The declaration of the classifier used in this type. For example, in the type List<String> the classifier would be the KClass instance for List.

Returns null if this type is not denotable in Kotlin, for example if it is an intersection type.
