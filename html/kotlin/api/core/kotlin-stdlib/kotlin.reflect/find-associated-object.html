findAssociatedObject

kotlin-stdlib/kotlin.reflect/findAssociatedObject

Platform and version requirements: JS (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

actual inline fun <T : Annotation> KClass<*>.findAssociatedObject(): Any?

If T is an @AssociatedObjectKey-annotated annotation class and this class is annotated with @T (S::class), returns object S.

Otherwise returns null.
