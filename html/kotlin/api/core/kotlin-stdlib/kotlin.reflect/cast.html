cast

kotlin-stdlib/kotlin.reflect/cast

Since Kotlin: 1.4

fun <T : Any> KClass<T>.cast(value: Any?): T

Casts the given value to the class represented by this KClass object. Throws an exception if the value is null or if it is not an instance of this class.

This is an experimental function that behaves as a similar function from kotlin.reflect.full on JVM.
