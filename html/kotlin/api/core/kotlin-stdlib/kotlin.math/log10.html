log10

kotlin-stdlib/kotlin.math/log10

Platform and version requirements: Common (1.2), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun log10(x: Double): Double

Computes the common logarithm (base 10) of the value x.

See also

ln

function for special cases.

Samples

import kotlin.math.*
import kotlin.test.*

fun main() { 
   //sampleStart 
   println(log10(10.0)) // 1.0
println(log10(1.0)) // 0.0
println(log10(1000.0)) // 3.0

// Special cases
println(log10(Double.NaN)) // NaN
println(log10(-1.0)) // NaN
println(log10(0.0)) // -Infinity
println(log10(Double.POSITIVE_INFINITY)) // Infinity 
   //sampleEnd
}
