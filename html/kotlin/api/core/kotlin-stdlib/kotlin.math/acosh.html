acosh

kotlin-stdlib/kotlin.math/acosh

Platform and version requirements: Common (1.2), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun acosh(x: Double): Double
expect fun acosh(x: Float): Float

Computes the inverse hyperbolic cosine of the value x.

The returned value is positive y such that cosh(y) == x.

Special cases:

  • acosh(NaN) is NaN

  • acosh(x) is NaN when x < 1

  • acosh(+Inf) is +Inf

Platform and version requirements: JS (1.2)
