tanh

kotlin-stdlib/kotlin.math/tanh

Platform and version requirements: Common (1.2), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun tanh(x: Double): Double
expect fun tanh(x: Float): Float

Computes the hyperbolic tangent of the value x.

Special cases:

  • tanh(NaN) is NaN

  • tanh(+Inf) is 1.0

  • tanh(-Inf) is -1.0

Platform and version requirements: JS (1.2), JVM (1.2)
