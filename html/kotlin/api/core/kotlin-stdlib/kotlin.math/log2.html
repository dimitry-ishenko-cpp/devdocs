log2

kotlin-stdlib/kotlin.math/log2

Platform and version requirements: Common (1.2), JVM (1.2), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun log2(x: Double): Double

Computes the binary logarithm (base 2) of the value x.

See also

ln

function for special cases.

Samples

import kotlin.math.*
import kotlin.test.*

fun main() { 
   //sampleStart 
   println(log2(2.0)) // 1.0
println(log2(1.0)) // 0.0
println(log2(8.0)) // 3.0

// Special cases
println(log2(Double.NaN)) // NaN
println(log2(-1.0)) // NaN
println(log2(0.0)) // -Infinity
println(log2(Double.POSITIVE_INFINITY)) // Infinity 
   //sampleEnd
}
