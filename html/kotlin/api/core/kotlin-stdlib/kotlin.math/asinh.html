asinh

kotlin-stdlib/kotlin.math/asinh

Platform and version requirements: Common (1.2), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun asinh(x: Double): Double
expect fun asinh(x: Float): Float

Computes the inverse hyperbolic sine of the value x.

The returned value is y such that sinh(y) == x.

Special cases:

  • asinh(NaN) is NaN

  • asinh(+Inf) is +Inf

  • asinh(-Inf) is -Inf

Platform and version requirements: JS (1.2)
