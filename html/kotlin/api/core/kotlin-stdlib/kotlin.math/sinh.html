sinh

kotlin-stdlib/kotlin.math/sinh

Platform and version requirements: Common (1.2), Wasm-JS (1.8), Wasm-WASI (1.8)

expect fun sinh(x: Double): Double
expect fun sinh(x: Float): Float

Computes the hyperbolic sine of the value x.

Special cases:

  • sinh(NaN) is NaN

  • sinh(+Inf) is +Inf

  • sinh(-Inf) is -Inf

Platform and version requirements: JS (1.2), JVM (1.2)
