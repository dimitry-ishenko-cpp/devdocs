atanh

kotlin-stdlib/kotlin.math/atanh

Platform and version requirements: Common (1.2)

expect fun atanh(x: Double): Double
expect fun atanh(x: Float): Float

Computes the inverse hyperbolic tangent of the value x.

The returned value is y such that tanh(y) == x.

Special cases:

  • tanh(NaN) is NaN

  • tanh(x) is NaN when x > 1 or x < -1

  • tanh(1.0) is +Inf

  • tanh(-1.0) is -Inf
