Int

kotlin-stdlib/kotlin/Int

Platform and version requirements: Common (1.0), JS (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect class Int : Number, Comparable<Int>

Represents a 32-bit signed integer.

Platform and version requirements: JVM (1.0)

actual class Int : Number, Comparable<Int>

Represents a 32-bit signed integer. On the JVM, non-nullable values of this type are represented as values of the primitive type int.
