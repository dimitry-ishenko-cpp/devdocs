toLong

kotlin-stdlib/kotlin/UShort/toLong

Since Kotlin: 1.5

inline fun toLong(): Long

Converts this UShort value to Long.

The resulting Long value represents the same numerical value as this UShort.

The least significant 16 bits of the resulting Long value are the same as the bits of this UShort value, whereas the most significant 48 bits are filled with zeros.
