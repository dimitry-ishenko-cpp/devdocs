set

kotlin-stdlib/kotlin.concurrent.atomics/AtomicLongArray/set

Since Kotlin: 2.1

operator fun set(index: Int, newValue: Long)

Deprecated (with error)

Use storeAt(index: Int, newValue: Long) instead.

Replace with

this.storeAt(index, newValue)

Atomically sets the value of the element at the given index to the new value.

Provides sequential consistent ordering guarantees.

Throws

IndexOutOfBoundsException

if the index is out of bounds of this array.
