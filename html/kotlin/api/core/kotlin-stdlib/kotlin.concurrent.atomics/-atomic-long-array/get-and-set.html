getAndSet

kotlin-stdlib/kotlin.concurrent.atomics/AtomicLongArray/getAndSet

Since Kotlin: 2.1

fun getAndSet(index: Int, newValue: Long): Long

Deprecated (with error)

Use exchangeAt(index: Int, newValue: Long) instead.

Replace with

this.exchangeAt(index, newValue)

Atomically sets the value of the element at the given index to the new value and returns the old value of the element.

Provides sequential consistent ordering guarantees.

Throws

IndexOutOfBoundsException

if the index is out of bounds of this array.
