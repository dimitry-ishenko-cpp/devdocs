AtomicLongArray

kotlin-stdlib/kotlin.concurrent.atomics/AtomicLongArray/AtomicLongArray

Platform and version requirements: Common, Native

expect constructor(size: Int)

Creates a new AtomicLongArray of the specified size, with all elements initialized to zero.

Throws

RuntimeException

if the specified size is negative.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.atomics.AtomicArray
import kotlin.test.assertFailsWith

fun main() { 
   //sampleStart 
   val a = AtomicLongArray(5)
println(a.toString()) // [0, 0, 0, 0, 0] 
   //sampleEnd
}
expect constructor(array: LongArray)

Creates a new AtomicLongArray filled with elements of the given array.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.atomics.AtomicArray
import kotlin.test.assertFailsWith

fun main() { 
   //sampleStart 
   val a = AtomicLongArray(longArrayOf(1, 2, 3))
println(a.toString()) // [1, 2, 3] 
   //sampleEnd
}
