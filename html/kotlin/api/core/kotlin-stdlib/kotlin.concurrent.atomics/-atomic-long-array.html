AtomicLongArray

kotlin-stdlib/kotlin.concurrent.atomics/AtomicLongArray

Since Kotlin: 2.1


@ExperimentalAtomicApi

inline fun AtomicLongArray(size: Int, init: (Int) -> Long): AtomicLongArray

Creates a new AtomicLongArray of the given size, where each element is initialized by calling the given init function.

The function init is called for each array element sequentially starting from the first one. It should return the value for an array element given its index.

Throws

RuntimeException

if the specified size is negative.
