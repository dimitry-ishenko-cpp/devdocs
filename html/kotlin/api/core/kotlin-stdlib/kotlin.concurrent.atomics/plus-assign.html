plusAssign

kotlin-stdlib/kotlin.concurrent.atomics/plusAssign

Since Kotlin: 2.1


@ExperimentalAtomicApi

operator fun AtomicInt.plusAssign(delta: Int)

Atomically adds the given value to the current value of this AtomicInt.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val counter = AtomicInt(7)
counter += 10
println(counter.load()) // 17 
   //sampleEnd
}
