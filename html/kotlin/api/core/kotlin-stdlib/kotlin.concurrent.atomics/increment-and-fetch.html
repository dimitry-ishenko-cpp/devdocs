incrementAndFetch

kotlin-stdlib/kotlin.concurrent.atomics/incrementAndFetch

Since Kotlin: 2.1


@ExperimentalAtomicApi

fun AtomicInt.incrementAndFetch(): Int

Atomically increments the current value of this AtomicInt by one and returns the new value.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicInt(7)
println(a.incrementAndFetch()) // 8
println(a.load()) // 8 
   //sampleEnd
}
