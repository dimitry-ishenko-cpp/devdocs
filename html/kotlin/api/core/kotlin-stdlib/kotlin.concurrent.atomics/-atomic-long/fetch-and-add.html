fetchAndAdd

kotlin-stdlib/kotlin.concurrent.atomics/AtomicLong/fetchAndAdd

Platform and version requirements: Common (2.1), JS (2.1), Native (2.1), Wasm-JS (2.1), Wasm-WASI (2.1)

expect fun fetchAndAdd(delta: Long): Long

Atomically adds the given value to the current value of this AtomicLong and returns the old value.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicLong(7)
// Returns the old value before the addition.
println(a.fetchAndAdd(10)) // 7
println(a.load()) // 17 
   //sampleEnd
}

Platform and version requirements: JVM (2.1)

actual fun fetchAndAdd(delta: Long): Long

Atomically adds the given value to the current value of this AtomicLong and returns the old value.

Has the same memory effects as java.util.concurrent.atomic.AtomicLong.getAndAdd.
