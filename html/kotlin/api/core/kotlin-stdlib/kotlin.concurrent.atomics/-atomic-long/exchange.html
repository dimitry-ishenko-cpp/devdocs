exchange

kotlin-stdlib/kotlin.concurrent.atomics/AtomicLong/exchange

Platform and version requirements: Common (2.1), JS (2.1)

expect fun exchange(newValue: Long): Long

Atomically stores the given new value into this AtomicLong. and returns the old value.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicLong(7)
println(a.exchange(10)) // 7
println(a.load()) // 10 
   //sampleEnd
}

Platform and version requirements: JVM (2.1)

actual fun exchange(newValue: Long): Long
