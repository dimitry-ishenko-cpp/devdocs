store

kotlin-stdlib/kotlin.concurrent.atomics/AtomicBoolean/store

Platform and version requirements: Common (2.1), JS (2.1), Native (2.1), Wasm-JS (2.1), Wasm-WASI (2.1)

expect fun store(newValue: Boolean)

Atomically stores the new value into this AtomicBoolean.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicBoolean(true)
a.store(false)
println(a.load()) // false 
   //sampleEnd
}

Platform and version requirements: JVM (2.1)

actual fun store(newValue: Boolean)
