exchange

kotlin-stdlib/kotlin.concurrent.atomics/AtomicBoolean/exchange

Platform and version requirements: Common (2.1), JS (2.1), Native (2.1), Wasm-JS (2.1), Wasm-WASI (2.1)

expect fun exchange(newValue: Boolean): Boolean

Atomically stores the given new value into this AtomicBoolean and returns the old value.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicBoolean(true)
println(a.exchange(false)) // true
println(a.load()) // false 
   //sampleEnd
}

Platform and version requirements: JVM (2.1)

actual fun exchange(newValue: Boolean): Boolean

Atomically stores the given new value into this AtomicBoolean and returns the old value.

Has the same memory effects as java.util.concurrent.atomic.AtomicBoolean.getAndSet.
