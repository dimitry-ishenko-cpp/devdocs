load

kotlin-stdlib/kotlin.concurrent.atomics/AtomicBoolean/load

Platform and version requirements: Common (2.1), JS (2.1), Native (2.1), Wasm-JS (2.1), Wasm-WASI (2.1)

expect fun load(): Boolean

Atomically loads the value from this AtomicBoolean.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicBoolean(true)
println(a.load()) // true 
   //sampleEnd
}

Platform and version requirements: JVM (2.1)

actual fun load(): Boolean

Atomically loads the value from this AtomicBoolean.

Has the same memory effects as java.util.concurrent.atomic.AtomicBoolean.get.
