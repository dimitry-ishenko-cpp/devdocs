decrementAndFetchAt

kotlin-stdlib/kotlin.concurrent.atomics/decrementAndFetchAt

Since Kotlin: 2.1


@ExperimentalAtomicApi

fun AtomicIntArray.decrementAndFetchAt(index: Int): Int

Atomically decrements the element of this AtomicIntArray at the given index by one and returns the new value of the element.

Throws

IndexOutOfBoundsException

if the index is out of bounds of this array.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.atomics.AtomicArray
import kotlin.test.assertFailsWith

fun main() { 
   //sampleStart 
   val a = AtomicIntArray(intArrayOf(1, 2, 3))
println(a.decrementAndFetchAt(1)) // 1
println(a.loadAt(1)) // 1
println(a.toString()) // [1, 1, 3] 
   //sampleEnd
}
