asJavaAtomicArray

Since Kotlin: 2.1


@ExperimentalAtomicApi

fun AtomicIntArray.asJavaAtomicArray(): AtomicIntegerArray

Casts the given AtomicIntArray instance to java.util.concurrent.atomic.AtomicIntegerArray.


@ExperimentalAtomicApi

fun AtomicLongArray.asJavaAtomicArray(): AtomicLongArray

Casts the given AtomicLongArray instance to java.util.concurrent.atomic.AtomicLongArray.


@ExperimentalAtomicApi

fun <T> AtomicArray<T>.asJavaAtomicArray(): AtomicReferenceArray<T>

Casts the given AtomicArray instance to java.util.concurrent.atomic.AtomicReferenceArray.
