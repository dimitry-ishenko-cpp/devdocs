decrementAndGet

kotlin-stdlib/kotlin.concurrent.atomics/AtomicIntArray/decrementAndGet

Since Kotlin: 2.1

fun decrementAndGet(index: Int): Int

Deprecated (with error)

Use decrementAndFetchAt(index: Int) instead.

Replace with

this.decrementAndFetchAt(index)

Atomically decrements the element at the given index by one and returns the new value of the element.

Provides sequential consistent ordering guarantees.

Throws

IndexOutOfBoundsException

if the index is out of bounds of this array.
