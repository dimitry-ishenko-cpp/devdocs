exchange

kotlin-stdlib/kotlin.concurrent.atomics/AtomicReference/exchange

Platform and version requirements: Common (2.1)

expect fun exchange(newValue: T): T

Atomically stores the given new value into this AtomicReference. and returns the old value.

Samples

import kotlin.concurrent.atomics.*
import kotlin.concurrent.thread

fun main() { 
   //sampleStart 
   val a = AtomicReference("aaa")
println(a.exchange("bbb")) // aaa
println(a.load()) // bbb 
   //sampleEnd
}
