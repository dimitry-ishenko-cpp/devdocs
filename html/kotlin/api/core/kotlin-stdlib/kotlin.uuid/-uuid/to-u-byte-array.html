toUByteArray

kotlin-stdlib/kotlin.uuid/Uuid/toUByteArray

Since Kotlin: 2.4


@ExperimentalUnsignedTypes

fun toUByteArray(): UByteArray

Returns an unsigned byte array representation of this uuid.

The returned array contains 16 unsigned bytes. Each byte in the array sequentially represents the next 8 bits of the uuid, starting from the most significant 8 bits in the first byte to the least significant 8 bits in the last byte.

See also

Uuid.fromUByteArray
