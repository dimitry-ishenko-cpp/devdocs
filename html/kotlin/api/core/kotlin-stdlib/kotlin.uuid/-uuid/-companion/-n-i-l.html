kotlin-stdlib/kotlin.uuid/Uuid/Companion/NIL

Since Kotlin: 2.4

val NIL: Uuid

The uuid with all bits set to zero.

This uuid can be used as a special value, for instance, as a placeholder for a non-null but not yet initialized variable.
