encode

kotlin-stdlib/kotlin.io.encoding/Base64/encode

Since Kotlin: 2.2

fun encode(source: ByteArray, startIndex: Int = 0, endIndex: Int = source.size): String

Encodes bytes from the specified source array or its subrange. Returns a string with the resulting symbols.

Whether the encoding result is padded with '=' depends on the PaddingOption set for this Base64 instance.

Use encodeToByteArray to get the output in ByteArray form.

Return

a string with the resulting symbols.

Parameters

source

the array to encode bytes from.

startIndex

the beginning (inclusive) of the subrange to encode, 0 by default.

endIndex

the end (exclusive) of the subrange to encode, size of the source array by default.

Throws

IndexOutOfBoundsException

when startIndex or endIndex is out of range of source array indices.

IllegalArgumentException

when startIndex > endIndex.

import kotlin.test.*
