clear

kotlin-stdlib/kotlin.collections/HashMap/clear

Platform and version requirements: Common (1.0), JS (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect open override fun clear()

Removes all elements from this map.

Samples

import kotlin.test.*
import java.util.*

fun main() { 
   //sampleStart 
   val map = mutableMapOf(1 to "one", 2 to "two")
println(map) // {1=one, 2=two}

map.clear()
println(map) // {} 
   //sampleEnd
}
