get

kotlin-stdlib/kotlin.collections/LinkedHashMap/get

Since Kotlin: 1.0

expect open operator override fun get(key: K): V?

Returns the value corresponding to the given key, or null if such a key is not present in the map.

Note that for maps supporting null values, the returned null value associated with the key is indistinguishable from the missing key, so containsKey should be used to check if the map actually contains the key.

Samples

import kotlin.test.*
import java.util.*

fun main() { 
   //sampleStart 
   val map = mapOf(1 to "one", 2 to "two")

println(map[2]) // two
println("map[3] == null is ${map[3] == null}") // true 
   //sampleEnd
}
