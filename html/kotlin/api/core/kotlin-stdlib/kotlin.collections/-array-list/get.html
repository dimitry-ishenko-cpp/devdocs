kotlin-stdlib/kotlin.collections/ArrayList/get

Platform and version requirements: Common (1.0), JS (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect open operator override fun get(index: Int): E

Returns the element at the specified index in the list.

Throws

IndexOutOfBoundsException

if index is less than zero or greater than or equal to size of this list.

Samples

import kotlin.math.*
import kotlin.test.*

fun main() { 
   //sampleStart 
   val list = listOf(1, 2, 3)

println(list[0]) // 1
println(list[2]) // 3
// list[3] // will fail with IndexOutOfBoundsException 
   //sampleEnd
}
