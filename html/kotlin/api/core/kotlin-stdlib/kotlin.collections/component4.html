Returns 4th element from the array.

If the size of this array is less than 4, throws an IndexOutOfBoundsException except in Kotlin/JS where the behavior is unspecified, and in Kotlin/Wasm where a trap will be raised instead, unless -Xwasm-enable-array-range-checks compiler flag was specified when linking an executable.

inline operator fun <T> List<T>.component4(): T

Returns 4th element from the list.

Throws an IndexOutOfBoundsException if the size of this list is less than 4.
