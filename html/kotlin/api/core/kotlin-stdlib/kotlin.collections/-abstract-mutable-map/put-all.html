putAll

kotlin-stdlib/kotlin.collections/AbstractMutableMap/putAll

Platform and version requirements: Common (1.3), JS (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect open override fun putAll(from: Map<out K, V>)

Updates this map with key/value pairs from the specified map from.

Samples

import kotlin.test.*
import java.util.*

fun main() { 
   //sampleStart 
   val map = mutableMapOf(1 to "one", 2 to "two")
map.putAll(mapOf(3 to "three", 4 to "four", 1 to "_ONE_"))

println(map) // {1=_ONE_, 2=two, 3=three, 4=four} 
   //sampleEnd
}
