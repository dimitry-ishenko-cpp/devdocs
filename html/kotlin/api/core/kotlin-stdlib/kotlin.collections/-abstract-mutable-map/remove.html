remove

kotlin-stdlib/kotlin.collections/AbstractMutableMap/remove

Platform and version requirements: Common (1.3), JS (1.1), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)


@IgnorableReturnValue

expect open override fun remove(key: K): V?

Removes the specified key and its corresponding value from this map.

Return

the previous value associated with the key, or null if the key was not present in the map.

Samples

import kotlin.test.*
import java.util.*

fun main() { 
   //sampleStart 
   val map = mutableMapOf(1 to "one", 2 to "two")

println(map.remove(1)) // one
println(map) // {2=two}

// There's no value for key=1 anymore
println("map.remove(1) == null is ${map.remove(1) == null}") // true 
   //sampleEnd
}
