mapIndexedNotNull

kotlin-stdlib/kotlin.collections/mapIndexedNotNull

Since Kotlin: 1.0

inline fun <T, R : Any> Array<out T>.mapIndexedNotNull(transform: (index: Int, T) -> R?): List<R>

Returns a list containing only the non-null results of applying the given transform function to each element and its index in the original array.

Parameters

transform

function that takes the index of an element and the element itself and returns the result of the transform applied to the element.
