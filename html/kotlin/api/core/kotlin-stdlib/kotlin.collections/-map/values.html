values

kotlin-stdlib/kotlin.collections/Map/values

Platform and version requirements: Common (1.0), JS (1.1), JVM (1.0), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect abstract val values: Collection<V>

Returns a read-only Collection of all values in this map. Note that this collection may contain duplicate values.

Samples

import kotlin.test.*
import java.util.*

fun main() { 
   //sampleStart 
   val map = mapOf(1 to "one", 2 to "two", -2 to "two")
val values = map.values
println(values) // [one, two, two] 
   //sampleEnd
}
