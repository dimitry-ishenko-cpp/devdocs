entries

kotlin-stdlib/kotlin.collections/Map/entries

Platform and version requirements: Common (1.0), JS (1.1), JVM (1.0), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect abstract val entries: Set<Map.Entry<K, V>>

Returns a read-only Set of all key/value pairs in this map.

Samples

import kotlin.test.*
import java.util.*

fun main() { 
   //sampleStart 
   val map = mapOf(1 to "one", 2 to "two")
println(map.entries) // [1=one, 2=two] 
   //sampleEnd
}
