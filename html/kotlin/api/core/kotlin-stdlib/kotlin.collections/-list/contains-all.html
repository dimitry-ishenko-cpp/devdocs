containsAll

kotlin-stdlib/kotlin.collections/List/containsAll

Platform and version requirements: Common (1.0), JS (1.1), JVM (1.0), Native (1.3), Wasm-JS (1.8), Wasm-WASI (1.8)

expect abstract override fun containsAll(elements: Collection<E>): Boolean

Checks if all elements in the specified collection are contained in this collection.

Samples

import kotlin.math.*
import kotlin.test.*

fun main() { 
   //sampleStart 
   val collection = mutableListOf('a', 'b')

println("collection.containsAll(test) is ${collection.containsAll(test)}") // false

collection.add('c')
println("collection.containsAll(test) is ${collection.containsAll(test)}") // true 
   //sampleEnd
}
