kotlin-stdlib/kotlin.collections/AbstractSet/equals

Since Kotlin: 1.1

open operator override fun equals(other: Any?): Boolean

Compares this set with other set instance with the unordered structural equality.

Return

true, if other instance is a Set of the same size, all elements of which are contained in this set.
