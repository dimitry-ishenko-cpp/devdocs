sortedArrayWith

kotlin-stdlib/kotlin.collections/sortedArrayWith

Since Kotlin: 1.0

fun <T> Array<out T>.sortedArrayWith(comparator: Comparator<in T>): Array<out T>

Returns an array with all elements of this array sorted according to the specified comparator.

Use sortedWith if you need to get the result in a list.

The sort is stable. It means that equal elements preserve their order relative to each other after sorting.
