equals

kotlin-stdlib/kotlin.collections/AbstractMap/equals

Since Kotlin: 1.1

open operator override fun equals(other: Any?): Boolean

Compares this map with other instance with the ordered structural equality.

Return

true, if other instance is a Map of the same size, all entries of which are contained in the entries set of this map.
