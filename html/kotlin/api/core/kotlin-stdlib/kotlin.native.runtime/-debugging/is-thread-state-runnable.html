isThreadStateRunnable

kotlin-stdlib/kotlin.native.runtime/Debugging/isThreadStateRunnable

Since Kotlin: 1.9

val isThreadStateRunnable: Boolean

Whether the current thread's state allows running Kotlin code.

Used by Kotlin/Native internal tests. If it returns false, it's a bug.
