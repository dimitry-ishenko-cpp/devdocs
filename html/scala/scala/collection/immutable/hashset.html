Class scala.collection.immutable.HashSet

scala.collection.immutable.HashSet
See theHashSet companion object

final class HashSet[A] extends AbstractSet[A], StrictOptimizedSetOps[A, HashSet, HashSet[A]], IterableFactoryDefaults[A, HashSet], DefaultSerializable

This class implements immutable sets using a Compressed Hash-Array Mapped Prefix-tree. See paper https://michael.steindorfer.name/publications/oopsla15.pdf for more details.

Type parameters

A

the type of the elements contained in this hash set.
