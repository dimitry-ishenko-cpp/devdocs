scala.collection.mutable.ArraySeq

sealed abstract class ArraySeq[T] extends AbstractSeq[T], IndexedSeq[T], IndexedSeqOps[T, ArraySeq, ArraySeq[T]], StrictOptimizedSeqOps[T, ArraySeq, ArraySeq[T]], Serializable

A collection representing Array[T]. Unlike ArrayBuffer it is always backed by the same underlying Array, therefore it is not growable or shrinkable.
