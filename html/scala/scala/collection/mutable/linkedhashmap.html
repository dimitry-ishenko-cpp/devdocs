class LinkedHashMap[K, V] extends AbstractMap[K, V], SeqMap[K, V], MapOps[K, V, LinkedHashMap, LinkedHashMap[K, V]], StrictOptimizedIterableOps[(K, V), Iterable, LinkedHashMap[K, V]], StrictOptimizedMapOps[K, V, LinkedHashMap, LinkedHashMap[K, V]], MapFactoryDefaults[K, V, LinkedHashMap, Iterable], DefaultSerializable

This class implements mutable maps using a hashtable. The iterator and all traversal methods of this class visit elements in the order they were inserted.

Type parameters

K

the type of the keys contained in this hash map.
V

the type of the values assigned to keys in this hash map.
