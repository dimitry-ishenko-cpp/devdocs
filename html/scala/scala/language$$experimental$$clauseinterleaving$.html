Object experimental.clauseInterleaving

scala.language.experimental.clauseInterleaving

object clauseInterleaving

Adds support for clause interleaving: Methods can now have as many type clauses as they like, this allows to have type bounds depend on terms: def f(x: Int)[A &lt;: x.type]: A
