1.2 Simple Examples

The following chapters describe all of Octave’s features in detail, but before doing that, it might be helpful to give a sampling of some of its capabilities.

If you are new to Octave, we recommend that you try these examples to begin learning Octave by using it. Lines marked like so, ‘octave:13>’ or ‘>> ’, are lines you type, ending each with a carriage return. (Don’t type the text ‘octave:13>’ itself! That is only the Octave prompt, which also looks like >> in the GUI. Octave will respond to your commands with an answer, or by displaying a graph.
