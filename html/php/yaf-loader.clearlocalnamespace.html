Yaf_Loader::clearLocalNamespace

(Yaf >=1.0.0)

Yaf_Loader::clearLocalNamespace — Clear registered namespaces

Description

public function Yaf_Loader::clearLocalNamespace(): bool

Clear all registered local namespaces.

Parameters

This function has no parameters.

Return Values

Returns true on success.

Examples

Example #1 Yaf_Loader::clearLocalNamespace() example

<?php
$app    = new Yaf_Application(__DIR__ . "/conf/application.ini");
$loader = Yaf_Loader::getInstance();

$loader->registerLocalNamespace(array("Models", "Services"));
var_dump(count($loader->getLocalNamespace()));

$loader->clearLocalNamespace();
var_dump(count($loader->getLocalNamespace()));
?>

The above example will output something similar to:

int(2)
int(0)
