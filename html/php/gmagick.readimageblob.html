Gmagick::readimageblob

(PECL gmagick >= Unknown)

Gmagick::readimageblob — Reads image from a binary string

Description

public function Gmagick::readimageblob(string $imageContents, string $filename = ?): Gmagick

Reads image from a binary string.

Parameters

imageContents

Content of image.

filename

The image filename.

Return Values

The Gmagick object.

Errors/Exceptions

Throws an GmagickException on error.
