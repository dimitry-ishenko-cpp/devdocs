Yaf_Request_Abstract::isRouted

(Yaf >=1.0.0)

Yaf_Request_Abstract::isRouted — Determine if the request has been routed

Description

public function Yaf_Request_Abstract::isRouted(): bool

Determine whether the request has been routed.

Parameters

This function has no parameters.

Return Values

Returns true if the request has been routed, false otherwise.

Examples

Example #1 Yaf_Request_Abstract::isRouted() example

<?php
class ApiRouter extends Yaf_Route_Interface
{
    public function route(Yaf_Request_Abstract $request)
    {
        // Skip if another router already routed this request
        if ($request->isRouted()) {
            return false;
        }

        if (0 === strpos($request->getRequestUri(), "/api/")) {
            $request->setControllerName("Api")
                    ->setActionName("handle");
            return true;
        }

        return false;
    }

    public function assemble(array $info, array $query = null) {}
}
?>
