Yaf_Request_Abstract::clearParams

(Yaf >=3.2.0)

Yaf_Request_Abstract::clearParams — Remove all parameters

Description

public function Yaf_Request_Abstract::clearParams(): ?Yaf_Request_Abstract

Remove all parameters set by the router, or by Yaf_Request_Abstract::setParam().

Parameters

This function has no parameters.

Return Values

Returns the request object itself.

Examples

Example #1 Yaf_Request_Abstract::clearParams() example

<?php
class IndexController extends Yaf_Controller_Abstract
{
    public function indexAction()
    {
        $request = $this->getRequest();

        $request->setParam("referrer", "newsletter");
        var_dump($request->getParam("referrer"));

        $request->clearParams();
        var_dump($request->getParam("referrer"));
    }
}
?>

The above example will output something similar to:

string(10) "newsletter"
NULL
