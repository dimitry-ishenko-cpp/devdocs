Yaf_Request_Abstract::getParam

(Yaf >=1.0.0)

Yaf_Request_Abstract::getParam — Retrieve a parameter

Description

public function Yaf_Request_Abstract::getParam(string $name, mixed $default = ?): mixed

Retrieves a parameter (a named routing/action parameter) from the request.

Parameters

name

The parameter name.

default

The value to return if the parameter is not set.

Return Values

The parameter value, or default if it was provided, null otherwise.

Examples

Example #1 Yaf_Request_Abstract::getParam() example

<?php
class ProductController extends Yaf_Controller_Abstract
{
    public function viewAction()
    {
        $request = $this->getRequest();

        // Assuming the request is /product/view/id/17
        $id       = (int) $request->getParam("id");
        $referrer = $request->getParam("referrer", "direct");

        var_dump($id, $referrer);
    }
}
?>

The above example will output something similar to:

int(17)
string(6) "direct"
