pcntl_getcpu

(PHP 8 >= 8.4.0)

pcntl_getcpu — Get the CPU number on which the calling process last executed

Description

function pcntl_getcpu(): int

pcntl_getcpu() returns the number of the CPU on which the calling process was last executed. This function uses the sched_getcpu(3) system call available on Linux.

Parameters

This function has no parameters.

Return Values

Returns the CPU number as an int.

See Also

  • pcntl_getcpuaffinity() - Get the cpu affinity of a process
  • pcntl_setcpuaffinity() - Set the cpu affinity of a process
