Yaf_Config_Ini::toArray

(Yaf >=1.0.0)

Yaf_Config_Ini::toArray — Export configuration as array

Description

public function Yaf_Config_Ini::toArray(): array

Returns the entire configuration as a plain PHP array.

Parameters

This function has no parameters.

Return Values

The configuration data as an array.

Examples

Example #1 Yaf_Config_Ini::toArray() example

<?php
/**
 * Assume /etc/myapp/application.ini contains:
 * [common]
 * application.name = "MyApp"
 * database.host    = "localhost"
 * database.port    = 3306
 */
$config = new Yaf_Config_Ini('/etc/myapp/application.ini', 'common');

print_r($config->toArray());
?>

The above example will output something similar to:

Array
(
    [application] => Array
        (
            [name] => MyApp
        )

    [database] => Array
        (
            [host] => localhost
            [port] => 3306
        )

)
