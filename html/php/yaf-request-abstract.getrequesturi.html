Yaf_Request_Abstract::getRequestUri

(Yaf >=1.0.0)

Yaf_Request_Abstract::getRequestUri — Retrieve the request URI

Description

public function Yaf_Request_Abstract::getRequestUri(): ?string

Retrieve the request URI

Parameters

This function has no parameters.

Return Values

The request URI, or an empty string if not set.

Examples

Example #1 Yaf_Request_Abstract::getRequestUri() example

<?php
class IndexController extends Yaf_Controller_Abstract
{
    public function indexAction()
    {
        // Assuming the request is /product/view/id/17
        var_dump($this->getRequest()->getRequestUri());
    }
}
?>

The above example will output something similar to:

string(19) "/product/view/id/17"
