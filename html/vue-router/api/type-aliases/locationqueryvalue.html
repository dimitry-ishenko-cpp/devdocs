LocationQueryValue 

type LocationQueryValue = string | null;

Internal

Possible values in normalized LocationQuery. null renders the query param but without an =.

Example 

?isNull&isEmpty=&other=other
gives
`{ isNull: null, isEmpty: '', other: 'other' }`.
