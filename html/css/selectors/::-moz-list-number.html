The ::-moz-list-number CSS pseudo-element is a Mozilla extension that represents the marker (typically a number) of a list item (<li>) in an ordered list (<ol>).

Syntax

li::-moz-list-number {
  /* ... */
}

Examples

HTML

<ol>
  <li>First item</li>
  <li>Second item</li>
  <li>Third item</li>
</ol>

CSS

li::-moz-list-number {
  font-style: italic;
  font-weight: bold;
}

Result

Specifications

Not part of any standard.
