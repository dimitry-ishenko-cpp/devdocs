pandas.Period.is_leap_year

Period.is_leap_year

Return True if the period’s year is in a leap year.

Examples

>>> period = pd.Period('2022-01', 'M')
>>> period.is_leap_year
False

>>> period = pd.Period('2020-01', 'M')
>>> period.is_leap_year
True
