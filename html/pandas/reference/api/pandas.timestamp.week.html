pandas.Timestamp.week

Timestamp.week

Return the week number of the year.

Returns:
int

See also

Timestamp.weekday

Return the day of the week.

Timestamp.quarter

Return the quarter of the year.

Examples

>>> ts = pd.Timestamp(2020, 3, 14)
>>> ts.week
11
