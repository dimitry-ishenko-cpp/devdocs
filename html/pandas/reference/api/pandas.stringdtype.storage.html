pandas.StringDtype.storage

propertyStringDtype.storage[source]

The storage backend for this dtype.

Can be either “pyarrow” or “python”.

See also

StringDtype.na_value

The missing value for this dtype.

Examples

>>> ser = pd.Series(["a", "b"])
>>> ser.dtype
<StringDtype(na_value=nan)>
>>> ser.dtype.storage
'pyarrow'
