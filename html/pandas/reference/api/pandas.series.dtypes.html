pandas.Series.dtypes

propertySeries.dtypes[source]

Return the dtype object of the underlying data.

See also

DataFrame.dtypes

Return the dtypes in the DataFrame.

Examples

>>> s = pd.Series([1, 2, 3])
>>> s.dtypes
dtype('int64')
