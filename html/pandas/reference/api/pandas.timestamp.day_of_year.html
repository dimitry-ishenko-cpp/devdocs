pandas.Timestamp.day_of_year

Timestamp.day_of_year

Return the day of the year.

Returns:
int

See also

Timestamp.day_of_week

Return day of the week.

Examples

>>> ts = pd.Timestamp(2020, 3, 14)
>>> ts.day_of_year
74
