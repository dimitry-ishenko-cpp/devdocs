pandas.Series.str.encode

Series.str.encode(encoding, errors='strict')[source]

Encode character string in the Series/Index using indicated encoding.

Equivalent to str.encode().

Parameters:
encoding:str

Specifies the encoding to be used.

errors:str, optional

Specifies the error handling scheme. Possible values are those supported by str.encode().

Returns:
Series/Index of objects

A Series or Index with strings encoded into bytes.

See also

Series.str.decode

Decodes bytes into strings in a Series/Index.

Examples

>>> ser = pd.Series(["cow", "123", "()"])
>>> ser.str.encode(encoding="ascii")
0     b'cow'
1     b'123'
2      b'()'
dtype: object
