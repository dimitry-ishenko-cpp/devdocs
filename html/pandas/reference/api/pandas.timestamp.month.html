pandas.Timestamp.month

Timestamp.month

Return the month of the Timestamp.

Returns:
int

The month of the Timestamp.

See also

Timestamp.day

Return the day of the Timestamp.

Timestamp.year

Return the year of the Timestamp.

Examples

>>> ts = pd.Timestamp("2024-08-31 16:16:30")
>>> ts.month
8
