Copy a file to another location

Use Bun.write() to copy a file to another location on disk. The first argument is a destination, like an absolute path or BunFile instance. The second argument is the data to write.

const file = Bun.file("/path/to/original.txt");
await Bun.write("/path/to/copy.txt", file);

See Bun.write().
