Add an optional dependency

To add an npm package as an optional dependency, use the --optional flag.

terminal
bun add zod --optional

This adds the package to optionalDependencies in package.json.

package.json
{
  "optionalDependencies": {
    "zod": "^4.0.0" 
  }
}

See bun install.
