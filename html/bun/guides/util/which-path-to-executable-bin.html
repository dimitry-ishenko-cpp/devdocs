Get the path to an executable bin file

Bun.which finds the absolute path of an executable file, like the which command on Unix-like systems.

foo.ts
Bun.which("sh"); // => "/bin/sh"
Bun.which("notfound"); // => null
Bun.which("bun"); // => "/home/user/.bun/bin/bun"

See Bun.which.
