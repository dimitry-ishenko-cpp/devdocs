Get the absolute path to the current entrypoint

The Bun.main property contains the absolute path to the current entrypoint.

foo.ts

console.log(Bun.main);

index.ts

import "./foo.ts";

The printed path is the file executed with bun run.

terminal
bun run index.ts
/path/to/index.ts
terminal
bun run foo.ts
/path/to/foo.ts
