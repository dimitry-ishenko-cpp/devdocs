Build an app with Qwik and Bun

Initialize a new Qwik app with bunx create-qwik.

The create-qwik package detects when you are using bunx and installs dependencies with bun.

terminal
bun create qwik

Run bun run dev to start the development server.

terminal
bun run dev
$ vite --mode ssr

VITE v7.3.1   ssr   ready in 433 ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
➜  press h + enter to show help

Open http://localhost:5173 in your browser to see the result. Qwik hot-reloads your app as you edit your source files.

See the Qwik docs to learn more.
