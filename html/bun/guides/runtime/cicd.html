Install and run Bun in GitHub Actions

Use the official setup-bun GitHub Action to install bun in your GitHub Actions runner.

workflow.yml
name: my-workflow
jobs:
  my-job:
    name: my-job
    runs-on: ubuntu-latest
    steps:
      # ...
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2 

      # run any `bun` or `bunx` command
      - run: bun install 
      - run: bun index.ts 
      - run: bun run build

To specify a version of Bun to install:

workflow.yml
name: my-workflow
jobs:
  my-job:
    name: my-job
    runs-on: ubuntu-latest
    steps:
      # ...
      - uses: oven-sh/setup-bun@v2
        with: 
          bun-version: 1.3.3 # or "latest", "canary", "1.3.x"

See the setup-bun README for all options.
