numpy.dtype.base

attribute

dtype.base

Returns dtype for the base element of the subarrays, regardless of their dimension or shape.

See also

dtype.subdtype

Examples

>>> import numpy as np
>>> x = np.dtype('8f')
>>> x.base
dtype('float32')

>>> x =  np.dtype('i2')
>>> x.base
dtype('int16')
