numpy.get_printoptions

numpy.get_printoptions()[source]

Return the current print options.

Returns:
print_optsdict

Dictionary of current print options with keys

  • precision : int
  • threshold : int
  • edgeitems : int
  • linewidth : int
  • suppress : bool
  • nanstr : str
  • infstr : str
  • sign : str
  • formatter : dict of callables
  • floatmode : str
  • legacy : str or False

For a full description of these options, see set_printoptions.

See also

set_printoptions, printoptions

Notes

These print options apply only to NumPy ndarrays, not to scalars.

Concurrency note: see Text formatting options

Examples

>>> import numpy as np

>>> np.get_printoptions()
{'edgeitems': 3, 'threshold': 1000, ..., 'override_repr': None}

>>> np.get_printoptions()['linewidth']
75
>>> np.set_printoptions(linewidth=100)
>>> np.get_printoptions()['linewidth']
100
