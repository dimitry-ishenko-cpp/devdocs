numpy.getbufsize

numpy.getbufsize()[source]

Return the size of the buffer used in ufuncs.

Returns:
getbufsizeint

Size of ufunc buffer in bytes.

Notes

Concurrency note: see Floating point error handling

Examples

>>> import numpy as np
>>> np.getbufsize()
8192
