numpy.polynomial.chebyshev.chebweight

polynomial.chebyshev.chebweight(x)[source]

The weight function of the Chebyshev polynomials.

The weight function is 1/1−x21/\sqrt{1 - x^2} and the interval of integration is [−1,1][-1, 1]. The Chebyshev polynomials are orthogonal, but not normalized, with respect to this weight function.

Parameters:
xarray_like

Values at which the weight function will be computed.

Returns:
wndarray

The weight function at x.
