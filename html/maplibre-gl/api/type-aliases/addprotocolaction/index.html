AddProtocolAction

AddProtocolAction = (requestParameters: RequestParameters, abortController: AbortController) => Promise<GetResourceResponse<any>>

This method type is used to register a protocol handler. Use the abort controller for aborting requests. Return a promise with the relevant resource response.

Parameters

Parameter Type
requestParameters RequestParameters
abortController AbortController

Returns

Promise<GetResourceResponse<any>>
