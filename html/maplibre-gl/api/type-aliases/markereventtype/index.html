MarkerEventType

MarkerEventType = object

MarkerEventType - a mapping between the marker event name and the event value. These events are used with the Marker.on method.

Properties

click

click: MarkerClickEvent

Fired when the marker is clicked.

drag

drag: MarkerDragEvent

Fired while dragging.

dragend

dragend: MarkerDragEvent

Fired when the marker is finished being dragged.

dragstart

dragstart: MarkerDragEvent

Fired when dragging starts.
