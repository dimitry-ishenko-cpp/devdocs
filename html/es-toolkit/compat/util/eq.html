eq

::: info This function is only available in es-toolkit/compat for compatibility reasons. It either has alternative native JavaScript APIs or isn’t fully optimized yet.

When imported from es-toolkit/compat, it behaves exactly like lodash and provides the same functionalities, as detailed here. :::

Performs a SameValueZero comparison between two values to determine if they are equivalent.

Signature

function eq(value?: unknown, other?: unknown): boolean;

Parameters

  • value (unknown): The value to compare.
  • other (unknown): The other value to compare.

Returns

(boolean): Returns true if the values are equivalent, else false.

Examples

eq(1, 1); // true
eq(0, -0); // true
eq(NaN, NaN); // true
eq('a', Object('a')); // false
