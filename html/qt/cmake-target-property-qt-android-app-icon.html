QT_ANDROID_APP_ICON

The Android app's icon resource name.

This property was introduced in Qt 6.9.

Note: This property is used only if targeting the Android platform.

Specifies the app's icon name as an Android drawable or mipmap reference. This only works if the AndroidManifest.xml file contains the placeholder or when the AndroidManifest.xml is managed by Qt.

<application
    ...
    android:icon="-- %%INSERT_APP_ICON%% --"
    ...
>

You can use this property as follows:

set_target_properties(${target} PROPERTIES
    QT_ANDROID_APP_ICON "@mipmap/ic_launcher"
)

Or using drawables:

set_target_properties(${target} PROPERTIES
    QT_ANDROID_APP_ICON "@drawable/ic_launcher"
)

See also qt_android_generate_deployment_settings().
