CMake Variables in Qt6 Test

The following CMake variables are defined when Qt6::Test is loaded, for instance with

find_package(Qt6 REQUIRED COMPONENTS Test)

See also CMake Variable Reference.

QT_SKIP_DEFAULT_TESTCASE_DIRS

Disables the test case directory definitions for the Qt Test targets.
