QT_QML_SKIP_CACHEGEN

Excludes a file from being compiled to byte code.

This property was introduced in Qt 6.2.

Set this property to TRUE to prevent the .qml file from being compiled to byte code. The file will still be added to the target as a resource in uncompiled form (see Caching compiled QML sources).

See also qt_target_qml_sources.
