QT_ANDROID_SYSTEM_LIBS_PREFIX

Specifies the location of Qt libraries on the target device.

This property was introduced in Qt 6.4.

Note: This property is used only if targeting the Android platform.

This property can be set to provide a path to Qt libraries on the target device, when those libraries are installed outside app's native (JNI) library directory.
