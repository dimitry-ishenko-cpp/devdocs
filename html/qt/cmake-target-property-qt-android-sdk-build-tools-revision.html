QT_ANDROID_SDK_BUILD_TOOLS_REVISION

Revision of Android build tools to use.

This property was introduced in Qt 6.0.

Note: This property is used only if targeting the Android platform.

Specifies the Android SDK build tools revision to use. If this is not set then CMake will attempt to use the latest installed version.

See also qt_android_generate_deployment_settings().
