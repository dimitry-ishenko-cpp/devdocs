QT_QML_SOURCE_VERSIONS

Specifies a custom set of versions for a type.

This property was introduced in Qt 6.2.

When the file needs to provide type entries for a custom set of versions, for example when the QML types were first introduced in a minor patch version after the .0 release, specify those versions using this property.

See also qt_target_qml_sources.
