Qt Qml Core

Application Permissions

The module exposes the Qt C++ Application Permissions functionality to QML via a set of permission types that can be used to check or request permission in a cross platform manner. See QML Application Permissions for more details.

QML Types

BluetoothPermission

Access to the user's Bluetooth peripherals

CalendarPermission

Access to the user's calendar

CameraPermission

Access to the user's camera

ContactsPermission

Access to the user's contacts

LocationPermission

Access to the user's location

MicrophonePermission

Access to the user's microphone

Settings

Provides persistent platform-independent application settings

StandardPaths

Provides access to the standard system paths

SystemInformation

Provides information about the system
