QT_ANDROID_APP_NAME

The Android app's name.

This property was introduced in Qt 6.9.

Note: This property is used only if targeting the Android platform.

Specifies the app's name that's shown in the launcher. This is human readable name of the app, and it is different from the package name of the app. This doesn't do anything if the name is set explicitly in the AndroidManifest.xml.

set_target_properties(${target} PROPERTIES
    QT_ANDROID_APP_NAME "Gallery"
)

See also qt_android_generate_deployment_settings() and QT_ANDROID_PACKAGE_NAME.
