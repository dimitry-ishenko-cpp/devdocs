Qt Graphs C++ Classes for Widgets

The Qt Graphs for 3D widget functionality can be accessed via these C++ classes.

Q3DBarsWidgetItem

Methods for rendering 3D bar graphs

Q3DGraphsWidgetItem

Window and render loop for graphs

Q3DScatterWidgetItem

Methods for rendering 3D scatter graphs

Q3DSurfaceWidgetItem

Methods for rendering 3D surface plots
