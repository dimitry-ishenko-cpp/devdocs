QT_ANDROID_COMPILE_SDK_VERSION

Android target SDK version.

This property was introduced in Qt 6.9.

Note: This property is used only if targeting the Android platform.

Specifies the version of the Android SDK against which your application is compiled. This is propagated to build.gradle as compileSdkVersion. This value can be provided via androiddeployqt's --android-platform parameter which takes precedence over this CMake property.

set_target_properties(${target} PROPERTIES
    QT_ANDROID_COMPILE_SDK_VERSION 35
)

The following format also works:

set_target_properties(${target} PROPERTIES
 QT_ANDROID_COMPILE_SDK_VERSION "android-35"
)

See also qt_android_generate_deployment_settings() and QT_ANDROID_TARGET_SDK_VERSION.
