CMake Target Properties in Qt6 LinguistTools

CMake Commands know about the following CMake target properties:

See also CMake Property Reference.

QT_EXCLUDE_FROM_TRANSLATION

Marks the target as excluded from translation

QT_EXCLUDE_SOURCES_FROM_TRANSLATION

List of source file paths that shall be excluded from translation
