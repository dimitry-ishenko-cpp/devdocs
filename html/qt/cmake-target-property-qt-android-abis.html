QT_ANDROID_ABIS

List of ABIs that packages of a single target are built for.

This property was introduced in Qt 6.3.

Note: This property is used only if targeting the Android platform.

By setting the QT_ANDROID_ABIS property for a target, it's possible to control the list of ABIs that the single target packages are supposed to be built for. The supported ABIs are armeabi-v7a, arm64-v8a, x86, x86_64. The property only affects targets created with qt_add_executable().

See also QT_ANDROID_ABIS and QT_ANDROID_BUILD_ALL_ABIS.
