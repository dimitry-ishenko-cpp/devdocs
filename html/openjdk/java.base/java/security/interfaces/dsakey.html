Interface DSAKey

All Known Subinterfaces:
DSAPrivateKey, DSAPublicKey
public interface DSAKey
The interface to a DSA public or private key. DSA (Digital Signature Algorithm) is defined in NIST's FIPS-186.
Since:
1.1
