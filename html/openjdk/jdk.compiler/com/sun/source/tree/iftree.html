Interface IfTree

All Superinterfaces:
StatementTree, Tree
public interface IfTree extends StatementTree
A tree node for an if statement. For example: 
  if ( condition )
     thenStatement

  if ( condition )
      thenStatement
  else
      elseStatement
See Java Language Specification:
14.9 The if Statement

1.6
