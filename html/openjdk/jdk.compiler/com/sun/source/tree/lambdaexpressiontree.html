Interface LambdaExpressionTree

All Superinterfaces:
ExpressionTree, Tree
public interface LambdaExpressionTree extends ExpressionTree
A tree node for a lambda expression. For example: 
  ()->{}
  (List<String> ls)->ls.size()
  (x,y)-> { return x + y; }
