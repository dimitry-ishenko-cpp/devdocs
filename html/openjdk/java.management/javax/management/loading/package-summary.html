Package javax.management.loading

package javax.management.loading

Provides the classes which implement advanced dynamic loading. See the chapter Advanced Dynamic Loading in the JMX Specification.

An MBean that is of a subclass of ClassLoader can be used as a class loader to create other MBeans via the method MBeanServer.createMBean(String, ObjectName, ObjectName, Object[], String[]), and to instantiate arbitrary objects via the method MBeanServer.instantiate(String, ObjectName, Object[], String[]).

Every MBean Server has a class loader repository containing all MBeans registered in that MBean Server that are of a subclass of ClassLoader. The class loader repository is used by the forms of the createMBean and instantiate methods in the MBeanServer interface that do not have an explicit loader parameter.

If an MBean implements the interface PrivateClassLoader, then it is not added to the class loader repository.

Class Description
ClassLoaderRepository
Instances of this interface are used to keep the list of ClassLoaders registered in an MBean Server.
DefaultLoaderRepository Deprecated.
Use MBeanServer.getClassLoaderRepository() instead.
PrivateClassLoader
Marker interface indicating that a ClassLoader should not be added to the ClassLoaderRepository.
