CMD_POLICY

Added in version 4.4.

Command Line:

-W[no-][error=]policy

Presets:

warnings.policy, errors.policy

Default:

Warn

Parent:

CMD_AUTHOR

Warn if a build system potentially depends on the OLD behavior of a CMake Policy. See the cmake_policy() command for more details. Setting a policy to OLD will also disable warnings for that specific policy.
