SOURCE_SET_<NAME>

Added in version 4.4.

Semicolon-separated list of files in the target's <NAME> source set, which has the set type SOURCES. If any of the paths are relative, they are computed relative to the target's source directory. The property supports generator expressions.

This property is normally only set by target_sources(FILE_SET) rather than being manipulated directly.

See SOURCE_SET for the list of files in the default source set. See SOURCE_SETS for the file set names of all source sets.
