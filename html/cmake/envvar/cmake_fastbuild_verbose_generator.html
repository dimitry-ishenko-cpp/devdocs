CMAKE_FASTBUILD_VERBOSE_GENERATOR

Added in version 4.2.

This is a CMake Environment Variable. Its initial value is taken from the calling process environment.

The CMAKE_FASTBUILD_VERBOSE_GENERATOR environment variable specifies a custom default value for the CMAKE_FASTBUILD_VERBOSE_GENERATOR variable in place of the default values specified by CMake itself.
