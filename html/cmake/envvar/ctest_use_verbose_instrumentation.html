CTEST_USE_VERBOSE_INSTRUMENTATION

Added in version 4.3.

This is a CMake Environment Variable. Its initial value is taken from the calling process environment.

Setting this environment variable to 1, True, or ON causes CTest to report the full command line (including arguments) to CDash for each instrumented command. By default, CTest truncates the command line at the first space.

See also CTEST_USE_INSTRUMENTATION
