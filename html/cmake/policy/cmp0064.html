CMP0064

Warning

The OLD behavior of this policy was removed in CMake version 4.0. This policy must be set to NEW by a call to cmake_minimum_required() or cmake_policy().

Added in version 3.4.

Recognize TEST as a operator for the if() command.

The TEST operator was added to the if() command to determine if a given test name was created by the add_test() command.

The OLD behavior for this policy is to ignore the TEST operator. The NEW behavior is to interpret the TEST operator.

This policy was introduced in CMake version 3.4. Prior to removal in CMake version 4.0, it could be set by cmake_policy() or cmake_minimum_required(). If it was not set, CMake warned, and used OLD behavior.
