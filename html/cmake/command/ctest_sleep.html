ctest_sleep

Sleep for some amount of time.

ctest_sleep(<seconds>)

Sleep for <seconds> seconds.

ctest_sleep(<time1><duration><time2>)

Sleep for <time1> + <duration> - <time2> seconds, if this sum is greater than zero.
