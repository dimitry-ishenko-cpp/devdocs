CMAKE_FASTBUILD_COMPILER_EXTRA_FILES

Added in version 4.2.

Specifies a semicolon-separated list of additional files (usually DLLs) to include in the FASTBuild Compiler() node.

See the FASTBuild Compiler() documentation for more information.
