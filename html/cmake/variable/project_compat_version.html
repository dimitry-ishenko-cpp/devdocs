PROJECT_COMPAT_VERSION

Added in version 4.3.

Value given to the COMPAT_VERSION option of the most recent call to the project() command, if any. To obtain the compatibility version of the top level project, see the CMAKE_PROJECT_COMPAT_VERSION variable.
