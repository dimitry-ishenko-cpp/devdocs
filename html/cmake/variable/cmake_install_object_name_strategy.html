CMAKE_INSTALL_OBJECT_NAME_STRATEGY

Added in version 4.2.

Strategy to use for naming installed object files.

CMAKE_INSTALL_OBJECT_NAME_STRATEGY is used to initialize the INSTALL_OBJECT_NAME_STRATEGY property on all targets. See that target property for more information.
