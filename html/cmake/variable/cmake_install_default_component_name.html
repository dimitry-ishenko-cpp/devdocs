CMAKE_INSTALL_DEFAULT_COMPONENT_NAME

Default component used in install() commands.

If an install() command is used without the COMPONENT argument, these files will be grouped into a default component. The name of this default install component will be taken from this variable. It defaults to Unspecified.

There is a special component name:

<PROJECT_NAME>

Added in version 4.4.

This literal placeholder will expand to the contents of the PROJECT_NAME variable when the install() command is evaluated. If no project() command has been called it defaults to Unspecified.
