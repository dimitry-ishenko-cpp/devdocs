CMAKE_FASTBUILD_CACHE_PATH

Added in version 4.2.

Specifies the directory for the FASTBuild artifact cache in the generated file.

If not set, FASTBuild will use the FASTBUILD_CACHE_PATH environment variable at build time.

See the FASTBuild caching documentation for more information.
