CTEST_CONFIGURE_PRESET

Added in version 4.4.

Specify the PRESET option for the ctest_configure() command in a ctest(1) Dashboard Client script, or on the ctest command line via the -D option.

See also CTEST_PRESET and CTEST_PRESETS_FILE.
