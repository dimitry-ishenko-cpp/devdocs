CMAKE_<LANG>_LINKER_LAUNCHER

Added in version 3.21.

Default value for <LANG>_LINKER_LAUNCHER target property. This variable is used to initialize the property on each target as it is created. This is done only when <LANG> is one of:

  • C
  • CXX

  • CUDA

    Added in version 4.1.

  • OBJC
  • OBJCXX

  • Fortran

    Added in version 4.1.

  • HIP

    Added in version 4.1.

This variable is initialized to the CMAKE_<LANG>_LINKER_LAUNCHER environment variable if it is set.
