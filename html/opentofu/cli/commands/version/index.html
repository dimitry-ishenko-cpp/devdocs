Command: version

The tofu version displays the current version of OpenTofu and all installed plugins.

Usage​

Usage: tofu version [options]

With no additional arguments, version will display the version of OpenTofu, the platform it's installed on, and installed providers.

This command has one optional flag:

  • -json - If specified, the version information is formatted as a JSON object, and no upgrade or security information is included. This command follows the raw json specification.
