Format Parameters

The following table lists recommended names and functionality for parameters that are used to format or to generate data.

Parameter Functionality
As
Data type: Keyword		 Implement this parameter to specify the cmdlet output format. For example, possible values could be Text or Script.
Binary
Data type: SwitchParameter		 Implement this parameter to indicate that the cmdlet handles binary values.
Encoding
Data type: Keyword		 Implement this parameter to specify the type of encoding that is supported. For example, possible values could be ASCII, UTF8, Unicode, UTF7, BigEndianUnicode, Byte, and String.
NewLine
Data type: SwitchParameter		 Implement this parameter so that the newline characters are supported when the parameter is specified.
ShortName
Data type: SwitchParameter		 Implement this parameter so that short names are supported when the parameter is specified.
Width
Data type: Int32		 Implement this parameter so that the user can specify the width of the output device.
Wrap
Data type: SwitchParameter		 Implement this parameter so that text wrapping is supported when the parameter is specified.
