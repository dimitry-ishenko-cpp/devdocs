function Deno.exit

#exit(code?: number): never

Exit the Deno process with optional exit code.

If no exit code is supplied then Deno will exit with return code of 0.

In worker contexts this is an alias to self.close();.

Deno.exit(5);

Parameters #

#code: number
optional

Return Type #

never
