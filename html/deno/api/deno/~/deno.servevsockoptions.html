interface Deno.ServeVsockOptions

extends ServeOptions<Deno.VsockAddr>
unstable

Options that can be passed to Deno.serve to create a server listening on a VSOCK socket.

Properties #

#transport: "vsock"
optional

The transport to use.

#cid: number

The context identifier to use.

#port: number

The port to use.
