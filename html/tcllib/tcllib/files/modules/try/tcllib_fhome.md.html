file::home

NAME

file::home - file home - Return home directory of current or other user

Table Of Contents

  • Table Of Contents

  • Synopsis

  • Description

  • Bugs, Ideas, Feedback

  • Category

  • Copyright

SYNOPSIS

package require Tcl 8.x
package require fhome ?1?

file home ?user?

DESCRIPTION

This package provides a forward-compatibility implementation of Tcl 9's file home command (TIP 602), for Tcl 8.x.

  • file home ?user?

    Without argument, return the home directory of the current user.

    With argument, return the home directory of the specified user.
