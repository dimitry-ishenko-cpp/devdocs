CSS

Sass utilities API

Line height utilities are declared in our utilities API in scss/_utilities.scss. Learn how to use the utilities API.

"line-height": (
  property: line-height,
  class: lh,
  values: (
    1: 1,
    sm: var(--line-height-sm),
    md: var(--line-height-md),
    lg: var(--line-height-lg),
  )
),
