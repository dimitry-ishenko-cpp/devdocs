Directories

builtin package builtin provides documentation for Odin's predeclared identifiers.
intrinsics package intrinsics provides documentation for Odin's compiler-level intrinsics.
runtime package runtime provides all of the declarations needed by all Odin code-bases.
sanitizer package sanitizer implements various procedures for interacting with sanitizers from user code.
