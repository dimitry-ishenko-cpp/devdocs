WP_Recovery_Mode_Key_Service::get_keys(): array

Gets the recovery key records.

Return

array Associative array of token => data pairs, where the data is an associative array of information about the key.
  • ...$0 array
    Information about the key.
    • hashed_key string
      The hashed value of the key.
    • created_at int
      The timestamp when the key was created.
