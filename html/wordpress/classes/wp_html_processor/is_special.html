WP_HTML_Processor::is_special( WP_HTML_Token|string $tag_name ): bool

Returns whether an element of a given name is in the HTML special category.

Description

See also

  • https://html.spec.whatwg.org/#special

Parameters

$tag_nameWP_HTML_Token|stringrequired
Node to check, or only its name if in the HTML namespace.

Return

bool Whether the element of the given name is in the special category.

Source

public static function is_special( $tag_name ): bool {
	if ( is_string( $tag_name ) ) {
		$tag_name = strtoupper( $tag_name );
	} else {
		$tag_name = 'html' === $tag_name->namespace
			? strtoupper( $tag_name->node_name )
			: "{$tag_name->namespace} {$tag_name->node_name}";
	}

	return (
		'ADDRESS' === $tag_name ||
		'APPLET' === $tag_name ||
		'AREA' === $tag_name ||

		'COL' === $tag_name ||
		'COLGROUP' === $tag_name ||
		'DD' === $tag_name ||
		'DETAILS' === $tag_name ||
		'DIR' === $tag_name ||
		'DIV' === $tag_name ||
		'DL' === $tag_name ||
		'DT' === $tag_name ||
		'EMBED' === $tag_name ||
