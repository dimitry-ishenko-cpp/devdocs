apply_filters( ‘rest_revision_query’, array $args, WP_REST_Request $request )

Filters WP_Query arguments when querying revisions via the REST API.

Description

Serves the same purpose as the ‘rest_{$this->post_type_query’} filter in WP_REST_Posts_Controller, but for the standalone WP_REST_Revisions_Controller.

Parameters

$argsarray
Array of arguments for WP_Query.
$requestWP_REST_Request
The REST API request.
