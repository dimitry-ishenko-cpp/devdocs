apply_filters( ‘wp_mediaelement_fallback’, string $output, string $url )

Filters the MediaElement fallback output for no-JS.

Parameters

$outputstring
Fallback output for no-JS.
$urlstring
Media file URL.

Source

return apply_filters( 'wp_mediaelement_fallback', sprintf( '<a href="%1$s.html">%1$s</a>', esc_url( $url ) ), $url );
