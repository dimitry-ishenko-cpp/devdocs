RTCAudioSourceStats: trackIdentifier property

Baseline 2023
Newly available

Since May 2023, this feature works across the latest devices and browser versions. This feature might not work in older devices or browsers.

  • Learn more
  • See full compatibility
  • Report feedback

The trackIdentifier property of the RTCAudioSourceStats dictionary contains the id attribute of the associated MediaStreamTrack.

Value

A string containing the value of the associated MediaStreamTrack.id.
