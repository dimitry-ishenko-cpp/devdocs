URLPattern: password property

Baseline Newly available

This feature works across the latest devices and browser versions. This feature might not work in older devices or browser versions. It's been available across browsers since September 2025.

Note: This feature is available in Web Workers.

The password read-only property of the URLPattern interface is a string containing the pattern used to match the password part of a URL.

This is the normalized value of the password pattern passed to the constructor or the default value ("*"), which matches any password.

Value

A string.

Examples

Basic usage

The following example creates a URLPattern object with correct-horse-battery{-staple}? for the password part and logs the property. This pattern matches the passwords correct-horse-battery and correct-horse-battery-staple.

const pattern = new URLPattern({ password: "correct-horse-battery{-staple}?" });
console.log(pattern.password); // 'correct-horse-battery{-staple}?'
console.log(pattern.test("https://user:correct-horse-battery@example.com")); // true
