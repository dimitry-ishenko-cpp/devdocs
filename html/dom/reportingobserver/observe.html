ReportingObserver: observe() method

Baseline Newly available

This feature works across the latest devices and browser versions. This feature might not work in older devices or browser versions. It's been available across browsers since March 2026.

Note: This feature is available in Web Workers.

The observe() method of the ReportingObserver interface instructs a reporting observer to start collecting reports in its report queue.

Syntax

observe()

Parameters

None.

Return value

None (undefined).

Examples

Basic usage

const options = {
  types: ["deprecation"],
  buffered: true,
};

const observer = new ReportingObserver((reports, observer) => {
  reportBtn.onclick = () => displayReports(reports);
}, options);

observer.observe();
