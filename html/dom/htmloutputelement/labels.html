HTMLOutputElement: labels property

Baseline Widely available

This feature is well established and works across many devices and browser versions. It's been available across browsers since October 2018.

The HTMLOutputElement.labels read-only property returns a NodeList of the <label> elements associated with the <output> element.

Value

A NodeList containing the <label> elements associated with the <output> element.

Examples

HTML

<label id="label1" for="test">Label 1</label>
<output id="test">Output</output>
<label id="label2" for="test">Label 2</label>

JavaScript

const output = document.getElementById("test");
for (const label of output.labels) {
  console.log(label.textContent); // "Label 1" and "Label 2"
}
