CSSSkewX: CSSSkewX() constructor

Baseline Limited availability

This feature is not Baseline because it does not work in some of the most widely-used browsers.

Note: This feature is available in Web Workers.

The CSSSkewX() constructor creates a new CSSSkewX object that represents the skewX() value of the individual transform property in CSS.

Syntax

new CSSSkewX(ax)

Parameters

ax
A value for the ax angle of the CSSSkewX object to be constructed. This must be a CSSNumericValue.
