CustomStateSet: clear() method

Baseline Newly available

This feature works across the latest devices and browser versions. This feature might not work in older devices or browser versions. It's been available across browsers since May 2024.

The clear() method of the CustomStateSet interface removes all elements from the CustomStateSet object.

Syntax

clear()

Parameters

None.

Return value

Undefined.
