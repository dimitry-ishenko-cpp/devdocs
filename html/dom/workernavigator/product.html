WorkerNavigator: product property

Baseline Widely available

This feature is well established and works across many devices and browser versions. It's been available across browsers since September 2016.

Note: This feature is only available in Web Workers.

The value of the WorkerNavigator.product property is always "Gecko", in any browser. This property is kept only for compatibility purposes.

Note: Do not rely on this property to return a real product name. All browsers return "Gecko" as the value of this property.

Value

The string "Gecko".
