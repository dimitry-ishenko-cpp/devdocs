TrustedScript: toJSON() method

Baseline Newly available

This feature works across the latest devices and browser versions. This feature might not work in older devices or browser versions. It's been available across browsers since February 2026.

Note: This feature is available in Web Workers.

The toJSON() method of the TrustedScript interface returns a JSON representation of the stored data.

Syntax

toJSON()

Parameters

None.

Return value

A string containing a JSON representation of the stored data.

Examples

The constant sanitized is an object created via a Trusted Types policy. The toString() method returns a string to safely execute as a script.

const sanitized = scriptPolicy.createScript("eval('2 + 2')");
console.log(sanitized.toJSON());
