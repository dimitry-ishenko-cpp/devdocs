NAME

Test2::Require::ExtendedTesting - Only run a test when the EXTENDED_TESTING environment variable is set.

DESCRIPTION

It is common practice to write tests that are only run when the EXTENDED_TESTING environment variable is set. This module automates the (admittedly trivial) work of creating such a test.

SYNOPSIS

use Test2::Require::ExtendedTesting;

...

done_testing;
