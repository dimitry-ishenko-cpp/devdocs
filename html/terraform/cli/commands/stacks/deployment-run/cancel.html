terraform stacks deployment-run cancel reference

UUse the terraform stacks deployment-run cancel command to cancel a deployment run in progress.

Usage

$ terraform stacks <global-stacks-flags> deployment-run cancel -deployment-run-id <value>

Description

The terraform stacks deployment-run cancel command cancels a deployment run that is currently in progress. This command requires the ID of the deployment run you want to cancel.

Options

  • : The ID of the deployment run to cancel.
    • Required.
    • String.
    • No default value.

Examples

The following command cancels a deployment run with ID run-abc123:

$ terraform stacks deployment-run cancel -deployment-run-id run-abc123
