terraform workspace select command

The terraform workspace select selects a different workspace to use for further operations.

Usage

Usage: terraform workspace select NAME

This command will select another workspace. The named workspace must already exist.

The supported flags are:

  • - If the workspace that is being selected does not exist, create it. Default is false.

Example

$ terraform workspace list
  default
* development
  jsmith-test
 
$ terraform workspace select default
Switched to workspace "default".
