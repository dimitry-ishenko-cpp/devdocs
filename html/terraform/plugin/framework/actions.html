Actions

Actions are an abstraction that allow providers to expose side-effects that interact with remote systems. Practitioners can use actions to express workflows that don't strictly fit into typical CRUD resource management, such as disaster recovery or ad-hoc maintenance. Actions can be invoked directly with the Terraform CLI or with a trigger in a plan/apply workflow.

Actions are currently not able to modify resource state, but future work is planned to support this.
