tfpolicy version

The tfpolicy version command prints out the version of the tfpolicy CLI.

Note

This functionality is in beta. Do not use beta features in production environments.

Usage

$ tfpolicy version

Description

The tfpolicy version command identifies the version of the Terraform policy you have installed.

Available options

The tfpolicy version command does not support any options.

Examples

The following examples demonstrate the tfpolicy version command.

Basic usage

$ tfpolicy version
1.0.0
