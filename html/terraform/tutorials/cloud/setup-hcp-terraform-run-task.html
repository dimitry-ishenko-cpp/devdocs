Set up HCP Terraform run task for HCP Packer

  • 4min
  • |
  • HCP
  • Packer
  • Terraform

After you build your artifact with Packer and push its metadata to HCP Packer, you can reference the artifact in your Terraform configuration to deploy it. HCP Packer has an HCP Terraform run task integration, which validates that the artifacts in your Terraform configuration are not revoked for being insecure or outdated.

In this tutorial, you will retrieve the endpoint URL and HMAC key from HCP Packer and create a run task in HCP Terraform.

Run task features

The HCP Terraform run task for HCP Packer can perform the following actions:

  1. The data source artifact validation scans your Terraform resources for references to hcp_packer_version and hcp_packer_artifact data sources. It will warn you if any referenced data source is associated with a revoked artifact version.

  2. The resource artifact validation scans your Terraform configuration for resources that use hard-coded machine image IDs and checks if the artifact is tracked by HCP Packer. If the artifact is associated with an artifact version, the run task will warn users if it is a revoked version. It will also prompt users to use the HCP Packer data sources instead of hard-coded image IDs to better track and manage artifacts.

Refer to Supported resource types for the HCP Terraform run task for a list of supported resources.

The HCP Packer Essentials tier only supports data source artifact validation. The HCP Packer Standard tier supports both data source and resource artifact validation.

The run task configuration instructions are the same for both Essentials and Standard tiers. The HCP Packer plans determine which validations the run task will run.

Prerequisites

To follow along with this tutorial, you will need:

  • An HCP account with an HCP Packer registry
  • An HCP Terraform account

Note

HCP Terraform Free Edition includes one run task integration that you can apply to up to ten workspaces. Refer to HCP Terraform pricing for details.

You will also need organization owner permissions in HCP Terraform to create a run task.

Retrieve HCP Packer information

Log into HashiCorp Cloud Platform, then choose Packer from ther Services menu.

On the HCP Packer page, open the Integrate with HCP Terraform drop-down menu.

This displays information for you to use to configure your HCP Terraform run task.

  1. The Endpoint URL is a unique HCP Packer URL, specific to your HCP organization and HCP Packer registry. The HCP Terraform run task will send a payload to this URL for artifact validation.

  2. The HMAC Key is a secret key that lets HCP Packer verify the run task request.

    Warning

    Do not share these values. If your HMAC key is compromised, regenerate it and update your HCP Terraform run task to use the new value.

Set up run task in HCP Terraform

Log into the HCP Terraform dashboard. Choose Settings, then Run tasks in the left sidebar.

Click on Create run task. On the Create a Run Task page:

  1. Verify Enabled is checked.

  2. Set Name to HCP-Packer.

  3. Set Endpoint URL to the endpoint URL you retrieved in the previous step.

  4. Set HMAC key to the HMAC key you retrieved in the previous step.

    Note

    Although labeled as optional in the UI, you must enter the HMAC key provided by HCP Packer. The HCP Packer integration requires an HMAC key to authenticate the requests.

  5. Use the default settings under Scope of run task. You can temporarily enable the Global option to review the available settings. Note that the HCP Packer run task expects a Terraform plan, so if you want to change scope settings in the future, do not enable the Pre-plan run stage setting. Refer to Run states and stages for additional information about these settings.

  6. Verify that the Global option is disabled and then click Create run task.

The Run Tasks page shows the HCP-Packer run task.
