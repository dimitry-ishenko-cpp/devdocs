TimeoutCallback

type TimeoutCallback = (_: void) => void;

Defined in: packages/query-core/src/timeoutManager.ts:9

TimeoutManager does not support passing arguments to the callback.

(_: void) is the argument type inferred by TypeScript's default typings for setTimeout(cb, number). If we don't accept a single void argument, then new Promise(resolve => timeoutManager.setTimeout(resolve, N)) is a type error.
