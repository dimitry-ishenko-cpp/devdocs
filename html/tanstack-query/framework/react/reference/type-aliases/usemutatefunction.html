UseMutateFunction

type UseMutateFunction<TData, TError, TVariables, TOnMutateResult> = (...args: Parameters<MutateFunction<TData, TError, TVariables, TOnMutateResult>>) => void;

Defined in: packages/react-query/src/types.ts:417

The type of mutate, as returned by useMutation. Forwards the variables (and an optional per-call onSuccess/onError/onSettled) to the underlying mutate call. Fire-and-forget — errors are surfaced through the mutation result instead of being thrown by mutate, unless throwOnError makes useMutation rethrow them.
