DataTag

type DataTag<TType, TValue, TError> = TType extends AnyDataTag ? TType : TType & object;

Defined in: packages/query-core/src/types.ts:137

Tags TType (usually a query key) with a data type and an optional error type, so that APIs that receive it, like queryClient.getQueryData, can infer them. A type that is already tagged is returned as is.
