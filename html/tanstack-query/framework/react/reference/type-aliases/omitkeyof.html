OmitKeyof

type OmitKeyof<TObject, TKey, TStrictly> = Omit<TObject, TKey>;

Defined in: packages/query-core/src/types.ts:30

Like Omit, but by default ('strictly') TKey must be a key of TObject, so omitting a key that doesn't exist is a type error. Pass 'safely' to allow other keys too.
