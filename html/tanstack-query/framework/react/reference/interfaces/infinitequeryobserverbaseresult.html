InfiniteQueryObserverBaseResult

Defined in: packages/query-core/src/types.ts:1409

The properties shared by every state of an infinite query result: those of QueryObserverBaseResult, plus fetchNextPage, fetchPreviousPage, and the flags about them, like hasNextPage and isFetchingNextPage.
