FetchPreviousPageOptions

Defined in: packages/query-core/src/types.ts:941

Options of fetchPreviousPage on an infinite query result.

Extends

  • ResultOptions

Properties

Property Type Default value Description
cancelRefetch? boolean true If set to true, calling fetchPreviousPage repeatedly will invoke queryFn every time, whether the previous invocation has resolved or not. Also, the result from previous invocations will be ignored. If set to false, calling fetchPreviousPage repeatedly won't have any effect until the first invocation has resolved.
throwOnError? boolean false If set to true, the method throws if any of the underlying query refetch tasks fail. If set to false, failed refetches are swallowed and not surfaced to the caller.
