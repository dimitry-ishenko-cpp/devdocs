InfiniteData

Defined in: packages/query-core/src/types.ts:315

The data shape of an infinite query: every page fetched so far, plus the page param each one was fetched with. pages and pageParams are index-aligned — pageParams[i] is the param that produced pages[i].

Type Parameters

TData

TData

TPageParam

TPageParam = unknown

Properties

Property Type Description
pageParams TPageParam[] The page param each page was fetched with, aligned by index with pages.
pages TData[] The data of every page fetched so far, in order.
