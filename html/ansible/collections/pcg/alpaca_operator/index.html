Description

This collection contains Ansible modules for managing the ALPACA Operator, developed by Public Cloud Group GmbH (pcg.io).

Author:

  • Public Cloud Group GmbH (pcg.io)

Supported ansible-core versions:

  • 2.12 or newer
  • Issue Tracker
  • Repository (Sources)

Plugin Index

These are the plugins in the pcg.alpaca_operator collection:

Modules

  • alpaca_agent module – Manage ALPACA Operator agents via REST API
  • alpaca_command module – Manage a single ALPACA Operator command via REST API
  • alpaca_command_set module – Manage all ALPACA Operator commands of a specific system via REST API
  • alpaca_group module – Manage ALPACA Operator groups via REST API
  • alpaca_system module – Manage ALPACA Operator systems via REST API
