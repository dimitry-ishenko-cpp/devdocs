Plugin Index

These are the plugins in the graphiant.naas collection:

Modules

  • graphiant_bgp module – Manage Graphiant BGP peering and routing policies
  • graphiant_data_exchange module – Manage Graphiant Data Exchange services, customers, matches, and invitations
  • graphiant_data_exchange_info module – Query Graphiant Data Exchange services, customers, and health information
  • graphiant_device_config module – Push raw device configurations to Graphiant devices
  • graphiant_device_system module – Configure device name, region, and site (Edge or Core)
  • graphiant_global_config module – Manage Graphiant global configuration objects
  • graphiant_interfaces module – Manage Graphiant interfaces and circuits
  • graphiant_lag_interfaces module – Manage Graphiant LAG (Link Aggregation Group) configuration
  • graphiant_ntp module – Manage device-level NTP objects (edge.ntpGlobalObject)
  • graphiant_site_to_site_vpn module – Manage Graphiant Site-to-Site VPN configuration
  • graphiant_sites module – Manage Graphiant sites and object attachments
  • graphiant_static_routes module – Manage Graphiant static routes (edge.segments.*.staticRoutes)
  • graphiant_vrrp module – Manage Graphiant VRRP (Virtual Router Redundancy Protocol) configuration
