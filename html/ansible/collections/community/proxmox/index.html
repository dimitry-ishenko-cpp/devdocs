Description

Community modules and plugins for Proxmox.

Author:

  • Ansible community (https://github.com/ansible-community)

Supported ansible-core versions:

  • 2.17.0 or newer
  • Issue Tracker
  • Repository (Sources)
  • Report an issue

Communication

  • Forum: Ansible Forum.
  • Matrix room #users:ansible.im: General usage and support questions.

Plugin Index

These are the plugins in the community.proxmox collection:

Modules

  • proxmox module – Management of instances in Proxmox VE cluster
  • proxmox_access_acl module – Manages ACLs on the Proxmox PVE cluster
  • proxmox_backup module – Start a VM backup in Proxmox VE cluster
  • proxmox_backup_info module – Retrieve information on Proxmox scheduled backups
  • proxmox_backup_schedule module – Schedule VM backups and removing them
  • proxmox_ceph_mds module – Add or delete Ceph Mds.
  • proxmox_ceph_mgr module – Add or delete Ceph Manager.
  • proxmox_ceph_mon module – Add or delete Ceph Monitor.
  • proxmox_ceph_osd module – Manage osd.
  • proxmox_cluster module – Create and join Proxmox VE clusters
  • proxmox_cluster_ha_groups module – Management of HA groups in Proxmox VE Cluster
  • proxmox_cluster_ha_resources module – Management of HA groups in Proxmox VE Cluster
  • proxmox_cluster_ha_rules module – Management of HA rules
  • proxmox_cluster_join_info module – Retrieve the join information of the Proxmox VE cluster
  • proxmox_cluster_status_info module – Retrieve Proxmox VE cluster status information
  • proxmox_disk module – Management of a disk of a Qemu(KVM) VM in a Proxmox VE cluster
  • proxmox_domain_info module – Retrieve information about one or more Proxmox VE domains
  • proxmox_firewall module – Manage firewall rules in Proxmox
  • proxmox_firewall_info module – Manage firewall rules in Proxmox
  • proxmox_group module – Group management for Proxmox VE cluster
  • proxmox_group_info module – Retrieve information about one or more Proxmox VE groups
  • proxmox_ipam_info module – Retrieve information about IPAMs.
  • proxmox_kvm module – Management of Qemu(KVM) Virtual Machines in Proxmox VE cluster
  • proxmox_nic module – Management of a NIC of a Qemu(KVM) VM in a Proxmox VE cluster
  • proxmox_node module – Manage Proxmox VE nodes
  • proxmox_node_info module – Retrieve information about one or more Proxmox VE nodes
  • proxmox_node_network module – Manage network interfaces on Proxmox nodes
  • proxmox_node_network_info module – Retrieve information about Proxmox VE node network interfaces
  • proxmox_pool module – Pool management for Proxmox VE cluster
  • proxmox_pool_member module – Add or delete members from Proxmox VE cluster pools
  • proxmox_role module – Role management for Proxmox VE cluster
  • proxmox_sendkey module – Send key presses to a Proxmox VM console
  • proxmox_snap module – Snapshot management of instances in Proxmox VE cluster
  • proxmox_snap_info module – Snapshot management of instances in Proxmox VE cluster
  • proxmox_storage module – Manage storage in PVE clusters and nodes
  • proxmox_storage_contents_info module – List content from a Proxmox VE storage
  • proxmox_storage_info module – Retrieve information about one or more Proxmox VE storages
  • proxmox_subnet module – Create/Update/Delete subnets from SDN
  • proxmox_tasks_info module – Retrieve information about one or more Proxmox VE tasks
  • proxmox_template module – Management of OS templates in Proxmox VE cluster
  • proxmox_user module – User management for Proxmox VE cluster
  • proxmox_user_info module – Retrieve information about one or more Proxmox VE users
  • proxmox_vm_info module – Retrieve information about one or more Proxmox VE virtual machines
  • proxmox_vnet module – Manage virtual networks in Proxmox SDN.
  • proxmox_vnet_info module – Retrieve information about one or more Proxmox VE SDN vnets.
  • proxmox_zone module – Manage Proxmox zone configurations.
  • proxmox_zone_info module – Get Proxmox zone info.

Connection Plugins

  • proxmox_pct_remote connection – Run tasks in Proxmox LXC container instances using pct CLI via SSH

Inventory Plugins

  • proxmox inventory – Proxmox inventory source
