community.general.iocage inventory plugin

The inventory plugin community.general.iocage gets the inventory hosts from the iocage jail manager.

See:

  • iocage - A FreeBSD Jail Manager
  • man iocage
  • Jails and Containers

Note

The output of the examples is YAML formatted. See the option result_format.
