community.network.pn_dscp_map module – CLI command to create/delete dscp-map

Note

This module is part of the community.network collection (version 5.1.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install community.network.

To use it in a playbook, specify: community.network.pn_dscp_map.

Note

The community.network collection has been deprecated and will be removed from Ansible 12. See the discussion thread for more information.

Synopsis

  • This module can be used to create a DSCP priority mapping table.

Aliases: network.netvisor.pn_dscp_map

Parameters

Parameter

Comments

pn_cliswitch

string

Target switch to run the CLI on.

pn_name

string

Name for the DSCP map.

pn_scope

string

Scope for dscp map.

Choices:

  • "local"
  • "fabric"

state

string / required

State the action to perform. Use present to create dscp-map and absent to delete.

Choices:

  • "present"
  • "absent"

Examples

- name: Dscp map create
  community.network.pn_dscp_map:
    pn_cliswitch: "sw01"
    state: "present"
    pn_name: "foo"
    pn_scope: "local"

- name: Dscp map delete
  community.network.pn_dscp_map:
    pn_cliswitch: "sw01"
    state: "absent"
    pn_name: "foo"
