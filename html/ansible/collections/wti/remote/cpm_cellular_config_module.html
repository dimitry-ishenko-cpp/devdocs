wti.remote.cpm_cellular_config module – Set Cellular runtime information and Parameters of the WTI device.

Note

This module is part of the wti.remote collection (version 1.0.11).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install wti.remote.

To use it in a playbook, specify: wti.remote.cpm_cellular_config.

New in wti.remote 2.10.0

Synopsis

  • Set Cellular runtime information and Parameters of the WTI device

Parameters

Parameter

Comments

apn

string

APN for the cellular modem in the WTI device.

cellenable

integer

If the cellular modem is enabled in the WTI device.

Choices:

  • 0
  • 1

cpm_password

string / required

This is the Password of the WTI device to send the module.

cpm_url

string / required

This is the URL of the WTI device to send the module.

cpm_username

string / required

This is the Username of the WTI device to send the module.

ipthru_enabled

integer

Enables/disables the IP Passthrough feature.

Choices:

  • 0
  • 1

ipthru_httpsterm

integer

When IP Passthrough is enabled, the Cellular HTTPS Port will be incremented by 5000.

ipthru_httpstermenable

integer

Enables/disables HTTPS.

ipthru_httpterm

integer

When IP Passthrough is enabled, the Cellular HTTP Port will be incremented by 5000.

ipthru_httptermenable

integer

Enables/disables HTTP.

ipthru_interfacemon

integer

Selects the interface that your downstream device/router will be connected to.

ipthru_mac

string

The MAC address of your downstream device/router.

ipthru_sshterm

integer

When IP Passthrough is enabled, the Cellular SSH Port will be incremented by 5000.

ipthru_sshtermenable

integer

Enables/disables SSH.

use_https

boolean

Designates to use an https connection or http connection.

Choices:

  • false
  • true ← (default)

use_proxy

boolean

Flag to control if the lookup will observe HTTP proxy environment variables when present.

Choices:

  • false ← (default)
  • true

validate_certs

boolean

If false, SSL certificates will not be validated. This should only be used

on personally controlled sites using self-signed certificates.

Choices:

  • false
  • true ← (default)

wof_afppinginter1

integer

Determines how often the Ping command will be sent after a previous Ping command receives no response.

wof_autorecov

integer

When enabled, the cellular modem will automatically be put back into sleep state when failure is resolved.

wof_conscfail1

integer

Determines how many consecutive failures pings must be detected in order to initiate a Wakeup on Failure..

wof_enabled

integer

Enables/disables the Wakeup on Failure feature.

Choices:

  • 0
  • 1

wof_gatewayaddr

string

When the cellular modem is defined as the default gateway, this determines which interface will be the default gateway.

wof_gatewayport

integer

The Ethernet port that will be used as the default gateway when the cellular modem is in the sleep state.

wof_host1

string

Selects the primary host that will be pinged in order to test for failures.

wof_host2

string

Selects the secondary host that will be pinged in order to test for failures.

wof_interfacemon

integer

Selects the Ethernet interface(s) that will be monitored for failed ping responses.

wof_pinginter1

integer

Determines how often the selected IP Address will be pinged.

wof_singlepingaddfail

integer

After an Ethernet failure has triggered a Wakeup, this feature is used to manually re-enable Wakeup On Failure.

wof_sleepmode

integer

Determines whether the cell modem will be attached or detached from the cell tower when sleep mode is active.

Notes

Note

  • Use groups/cpm in module_defaults to set common options used between CPM modules.

Examples

# Set a static time/date and timezone of a WTI device
- name: Set APN and enable cellular modem in a WTI device
  cpm_time_config:
    cpm_url: "nonexist.wti.com"
    cpm_username: "super"
    cpm_password: "super"
    use_https: true
    validate_certs: false
    apn: "vzwent.south"
    cellenable: "1"
