hitachivantara.vspone_block.sds_block.hv_sds_block_storage_node_network_settings_facts module – Get storage node network settings from VSP One SDS Block and Cloud systems.

Note

This module is part of the hitachivantara.vspone_block collection (version 4.8.1).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install hitachivantara.vspone_block. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: hitachivantara.vspone_block.sds_block.hv_sds_block_storage_node_network_settings_facts.

New in hitachivantara.vspone_block 4.1.0

Synopsis

  • Get storage node network settings from the storage system.
  • For examples go to URL https://github.com/hitachi-vantara/vspone-block-ansible/blob/main/playbooks/sds_block_direct/storage_node_facts.yml

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.9

Parameters

Parameter

Comments

Choices:

  • "direct" ← (default)

Specification for retrieving job information.

Filter control port by storage node name.

Examples

- name: Retrieve information about all storage_node_network_settings
  hitachivantara.vspone_block.sds_block.hv_sds_block_storage_node_network_settings_facts:
    connection_info:
      address: sdsb.company.com
      username: "admin"
      password: "password"

- name: Retrieve information about storage_node_network_settings by specifying id
  hitachivantara.vspone_block.sds_block.hv_sds_block_storage_node_network_settings_facts:
    connection_info:
      address: sdsb.company.com
      username: "admin"
      password: "password"
    spec:
      id: "126f360e-c79e-4e75-8f7c-7d91bfd2f0b8"

Returned Facts

Facts returned by this module are added/updated in the hostvars host facts and can be referenced by name just like any other host fact. They do not need to be registered in order to use them.

Key

Description

storage_node_network_settings

dictionary

Storage node network settings facts.

Returned: success

data

list / elements=dictionary

List of storage node network setting entries.

Returned: success

id

string

Unique identifier for the storage node network setting.

Returned: success

Sample: "1a21c76d-614a-45e1-bd02-6bd2c18dddd7"

ipv4_route

list / elements=dictionary

List of IPv4 route entries configured on the storage node.

Returned: success

destination

string

Destination network for the route.

Returned: success

Sample: "default"

gateway

string

Returned: success

interface

string

Network interface name used for the route.

Returned: success
