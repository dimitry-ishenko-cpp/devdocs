hitachivantara.vspone_block.sds_block.hv_sds_block_encryption_environment_settings module – Manages encryption environment settings on VSP One SDS Block and Cloud systems.

Note

This module is part of the hitachivantara.vspone_block collection (version 4.8.1).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install hitachivantara.vspone_block. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: hitachivantara.vspone_block.sds_block.hv_sds_block_encryption_environment_settings.

Synopsis

  • This module manages encryption environment configuration settings on Hitachi SDS Block storage systems.
  • Enables or disables encryption functionality for the storage environment.
  • Utilizes the Hitachi Vantara SDS Block API for encryption environment configuration management.
  • For usage examples, visit https://github.com/hitachi-vantara/vspone-block-ansible/blob/main/playbooks/sds_block_direct/encryption_environment_settings.yml

Requirements

The below requirements are needed on the host that executes this module.

Examples

- name: Enable encryption environment
  hitachivantara.vspone_block.sds_block.hv_sds_block_encryption_environment_settings:
    connection_info:
      address: sdsb.company.com
      username: "admin"
      password: "password"
    spec:
      is_encryption_enabled: true

- name: Disable encryption environment
  hitachivantara.vspone_block.sds_block.hv_sds_block_encryption_environment_settings:
    connection_info:
      address: sdsb.company.com
      username: "admin"
      password: "password"
    spec:
      is_encryption_enabled: false
