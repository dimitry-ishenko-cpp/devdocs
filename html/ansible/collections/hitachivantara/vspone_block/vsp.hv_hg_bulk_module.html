hitachivantara.vspone_block.vsp.hv_hg_bulk module – Manages host groups in bulk on VSP block storage system with parallel processing.

Note

This module is part of the hitachivantara.vspone_block collection (version 4.8.1).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install hitachivantara.vspone_block. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: hitachivantara.vspone_block.vsp.hv_hg_bulk.

Synopsis

  • This module provides bulk host group management operations with multithreading support for parallel processing across multiple ports.
  • Operations on multiple ports are executed concurrently using a thread pool (up to 10 concurrent threads) for improved performance.
  • Supported operations include
    1. create host group on multiple ports in parallel.
    1. delete host group from multiple ports in parallel.
    1. add logical unit to host group across multiple ports.
    1. remove logical unit from host group across multiple ports.
    1. add host WWN to host group across multiple ports.
    1. remove host WWN from host group across multiple ports.
    1. set host mode across multiple ports.
    1. add host mode option to host group across multiple ports.
    1. remove host mode option from host group across multiple ports.
  • Thread-safe result aggregation ensures accurate reporting of changes, comments, and errors from all parallel operations. https://github.com/hitachi-vantara/vspone-block-ansible/blob/main/playbooks/vsp_direct/hostgroup_bulk.yml

Examples

- name: Create host group on multiple ports in parallel
  hitachivantara.vspone_block.vsp.hv_hg_bulk:
    state: present
    connection_info:
      address: storage1.company.com
      username: "dummy_user"
      password: "dummy_password"
    spec:
      name: 'bulk_hg_test'
      port_ids: ['CL1-A', 'CL1-B', 'CL2-A', 'CL2-B']
      host_mode: 'VMWARE_EXTENSION'
      host_mode_options: [40, 63]
      wwns:
        - wwn: '100000109B583B2D'
          nickname: 'server1_hba1'
        - wwn: '100000109B583B2C'
          nickname: 'server1_hba2'
      lun_paths:
        - ldev: '1024'
          lun: '0'
        - ldev: '1025'
          lun: '1'

- name: Delete host group from multiple ports in parallel
  hitachivantara.vspone_block.vsp.hv_hg_bulk:
    state: absent
    connection_info:
      address: storage1.company.com
      username: "dummy_user"
      password: "dummy_password"
    spec:
      name: 'bulk_hg_test'
      port_ids: ['CL1-A', 'CL1-B', 'CL2-A', 'CL2-B']
      should_delete_all_volumes: true

- name: Add WWNs to host groups across multiple ports in parallel
  hitachivantara.vspone_block.vsp.hv_hg_bulk:
    state: added
    connection_info:
      address: storage1.company.com
      username: "dummy_user"
      password: "dummy_password"
    spec:
      name: 'existing_hg'
      port_ids: ['CL1-A', 'CL1-B', 'CL2-A']
      wwns:
        - wwn: '200000109B3C0FD3'
          nickname: 'new_server_hba1'
        - wwn: '200000109B3C0FD4'
          nickname: 'new_server_hba2'

- name: Remove WWNs from host groups across multiple ports in parallel
  hitachivantara.vspone_block.vsp.hv_hg_bulk:
    state: removed
    connection_info:
      address: storage1.company.com
      username: "dummy_user"
      password: "dummy_password"
    spec:
      name: 'existing_hg'
      port_ids: ['CL1-A', 'CL1-B', 'CL2-A']
      wwns:
        - wwn: '200000109B3C0FD3'
        - wwn: '200000109B3C0FD4'

- name: Update host mode on multiple ports in parallel
  hitachivantara.vspone_block.vsp.hv_hg_bulk:
    state: updated
    connection_info:
      address: storage1.company.com
      username: "dummy_user"
      password: "dummy_password"
    spec:
      name: 'existing_hg'
      port_ids: ['CL1-A', 'CL1-B', 'CL2-A', 'CL2-B']
      host_mode: 'LINUX'
      host_mode_options: [54, 63, 68]

- name: Add LUN paths to host groups across multiple ports in parallel
  hitachivantara.vspone_block.vsp.hv_hg_bulk:
    state: added
    connection_info:
      address: storage1.company.com
      username: "dummy_user"
      password: "dummy_password"
    spec:
      name: 'existing_hg'
      port_ids: ['CL1-A', 'CL1-B']
      lun_paths:
        - ldev: '2048'
          lun: '10'
        - ldev: '2049'
          lun: '11'
