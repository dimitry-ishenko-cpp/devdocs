hitachivantara.vspone_block.vsp.hv_storage_system_monitor_facts module – Retrieves alerts, hardware installed, and channel boards information from VSP block storage systems.

Note

This module is part of the hitachivantara.vspone_block collection (version 4.8.1).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install hitachivantara.vspone_block. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: hitachivantara.vspone_block.vsp.hv_storage_system_monitor_facts.

New in hitachivantara.vspone_block 4.0.0

Synopsis

  • This module retrieves information about Storage System Monitor information from VSP block storage systems.
  • For examples, go to URL https://github.com/hitachi-vantara/vspone-block-ansible/blob/main/playbooks/vsp_direct/storage_system_monitor_facts.yml

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.9

Parameters

Parameter

Comments

connection_info

dictionary / required

Information required to establish a connection to the storage system.

address

string / required

IP address or hostname of the storage system.

api_token

string

This field is used to pass the value of the lock token to operate on locked resources.

connection_type

string

Type of connection to the storage system.

Choices:

  • "direct" ← (default)

password

string

Password for authentication. This is a required field if api_token is not provided.

username

string

Username for authentication. This is a required field if api_token is not provided.

spec

dictionary / required

Specification for the Storage System Monitor facts to be gathered.

alert_count

integer

This field is valid when query field is alerts. Then this field is optional. Numbrt of alerts to be retrieved. If you specified DKC for the alert_type parameter, specify a value in the range from 1 to 10240. If you specified CTL1 or CTL2 for the alert_type parameter, specify a value in the range from 1 to 256. If this parameter is omitted, 10 alerts will be obtained. Required for the Get alerts information task.

alert_start_number

integer

This field is valid when query field is alerts. Then this field is optional. Alerts are sorted by date and time in descending order. Specify the number of the alert from which you want to start obtaining information. If you specified DKC for the alert_type parameter, specify a value in the range from 1 to 10240. If you specified CTL1 or CTL2 for the alert_type parameter, specify a value in the range from 1 to 256. If this parameter is omitted, alert information will be obtained starting from the first alert. Required for the Get alerts information task.

alert_type

string

Type of the alerts. This field is valid when query field is alerts. Then this field is required. Possible value is one of, DKC, CTL1, CTL2 Required for the Get alerts information task.

Choices:

  • "DKC"
  • "CTL1"
  • "CTL2"

include_component_option

boolean

This field is valid when query field is hardware_installed. Then this field is optional. If set to true, it will bring the information about the components, otherwise not. Required for the Get Hardware Installed information task.

Choices:

  • false
  • true

query

string / required

Specify the component for which you want the monitor information from the storage system. Possible value is one of, alerts, hardware_installed, channel_boards. Required for the Get alerts information /Get Hardware Installed information /Get Channel Boards information tasks.

Choices:

  • "alerts"
  • "hardware_installed"
  • "channel_boards"

Examples

- name: Get alerts information
  hitachivantara.vspone_block.vsp.hv_storage_system_monitor_facts:
    connection_info:
      address: storage1.company.com
      username: "admin"
      password: "secret"
    spec:
      alert_type: "CTL1"
      alert_start_number: 1
      alert_count: 2
      query: "alerts"

- name: Get Hardware Installed information
  hitachivantara.vspone_block.vsp.hv_storage_system_monitor_facts:
    connection_info:
      address: storage1.company.com
      username: "admin"
      password: "secret"
    spec:
      query: "hardware_installed"
      include_component_option: false

- name: Get Channel Boards information
  hitachivantara.vspone_block.vsp.hv_storage_system_monitor_facts:
    connection_info:
      address: storage1.company.com
      username: "admin"
      password: "secret"
    spec:
      query: "channel_boards"
