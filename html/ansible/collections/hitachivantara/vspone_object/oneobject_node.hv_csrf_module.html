hitachivantara.vspone_object.oneobject_node.hv_csrf module – Fetch CSRF tokens from Hitachi VSP One Object

Note

This module is part of the hitachivantara.vspone_object collection (version 1.1.1).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install hitachivantara.vspone_object. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: hitachivantara.vspone_object.oneobject_node.hv_csrf.

New in hitachivantara.vspone_object 1.0.0

Synopsis

  • This module fetches XSRF-TOKEN and vertx-web.session from Hitachi VSP One Object.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.7

Examples

- name: Request CSRF token for VSP One Object.
  hitachivantara.vspone_object.oneobject_node.hv_csrf:
    connection_info:
      http_request_timeout: 300
      http_request_retry_times: 3
      http_request_retry_interval_seconds: 5
      cluster_name: "your_cluster_name"
      region: "your_region"
      oneobject_node_username: "your_username"
      oneobject_node_userpass: "your_password"
      oneobject_node_client_id: "vsp-object-external-client"
