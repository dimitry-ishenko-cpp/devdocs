cisco.dnac.assurance_device_health_score_settings_workflow_manager module – Resource module for managing assurance Health score settings in Cisco Catalyst Center.

Note

This module is part of the cisco.dnac collection (version 6.48.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install cisco.dnac. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: cisco.dnac.assurance_device_health_score_settings_workflow_manager.

Synopsis

  • Manages assurance Health score settings in Cisco Catalyst Center.
  • It supports updating configurations for Health score settings functionalities.
  • This module interacts with Cisco Catalyst Center’s Assurance settings to configure thresholds, rules, KPIs, and more for health score monitoring.
  • The health score can be customized based on device type.
  • The network device’s health score is determined by the lowest score among all included KPIs.
  • To disable a KPI from impacting the overall device health, you can exclude it from the health score calculation.
  • Health score setting is not applicable for Third Party Devices.

Requirements

The below requirements are needed on the host that executes this module.

  • dnacentersdk >= 2.8.6
  • python >= 3.9

Notes

Note

  • SDK Method used are devices.AssuranceSettings.get_all_health_score_definitions_for_given_filters, devices.AssuranceSettings.update_health_score_definitions
  • Paths used are post /dna/intent/api/v1/health_scoreDefinitions/${id}, post /dna/intent/api/v1/health_scoreDefinitions/bulkUpdate
  • Does not support check_mode
  • The plugin runs on the control node and does not use any ansible connection plugins instead embedded connection manager from Cisco Catalyst Center SDK
  • The parameters starting with dnac_ are used by the Cisco Catalyst Center Python SDK to establish the connection
