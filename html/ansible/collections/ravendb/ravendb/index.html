Description

An Ansible collection for deploying, configuring, and managing RavenDB clusters on Linux-based environments.

Authors:

  • Grzegorz Lachowski <gregolsky@ravendb.net>
  • Omer Ratsaby <omer.ratsaby@ravendb.net>

Supported ansible-core versions:

Plugin Index

These are the plugins in the ravendb.ravendb collection:

Modules

  • connection_string module – Manage RavenDB connection strings
  • database module – Manage RavenDB databases
  • healthcheck module – Perform RavenDB node and cluster health checks
  • index module – Manage RavenDB indexes
  • node module – Add a RavenDB node to an existing cluster
