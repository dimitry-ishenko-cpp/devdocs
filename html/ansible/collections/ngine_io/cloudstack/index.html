Plugin Index

These are the plugins in the ngine_io.cloudstack collection:

Modules

  • account module – Manages accounts on Apache CloudStack based clouds.
  • affinity_group module – Manages affinity groups on Apache CloudStack based clouds.
  • cluster module – Manages host clusters on Apache CloudStack based clouds.
  • configuration module – Manages configuration on Apache CloudStack based clouds.
  • configuration_info module – Gathering information about configurations from Apache CloudStack based clouds.
  • disk_offering module – Manages disk offerings on Apache CloudStack based clouds.
  • domain module – Manages domains on Apache CloudStack based clouds.
  • firewall module – Manages firewall rules on Apache CloudStack based clouds.
  • host module – Manages hosts on Apache CloudStack based clouds.
  • image_store module – Manages CloudStack Image Stores.
  • instance module – Manages instances and virtual machines on Apache CloudStack based clouds.
  • instance_group module – Manages instance groups on Apache CloudStack based clouds.
  • instance_info module – Gathering information from the API of instances from Apache CloudStack based clouds.
  • instance_nic module – Manages NICs of an instance on Apache CloudStack based clouds.
  • instance_nic_secondaryip module – Manages secondary IPs of an instance on Apache CloudStack based clouds.
  • instance_password_reset module – Allows resetting VM the default passwords on Apache CloudStack based clouds.
  • instance_snapshot module – Manages instance snapshots on Apache CloudStack based clouds.
  • ip_address module – Manages public IP address associations on Apache CloudStack based clouds.
  • iso module – Manages ISO images on Apache CloudStack based clouds.
  • lb_rule module – Manages load balancer rules on Apache CloudStack based clouds.
  • lb_rule_member module – Manages load balancer rule members on Apache CloudStack based clouds.
  • metadata_facts module – Gather facts on instances of Apache CloudStack based clouds.
  • network module – Manages networks on Apache CloudStack based clouds.
  • network_acl module – Manages network access control lists (ACL) on Apache CloudStack based clouds.
  • network_acl_rule module – Manages network access control list (ACL) rules on Apache CloudStack based clouds.
  • network_offering module – Manages network offerings on Apache CloudStack based clouds.
  • physical_network module – Manages physical networks on Apache CloudStack based clouds.
  • pod module – Manages pods on Apache CloudStack based clouds.
  • portforward module – Manages port forwarding rules on Apache CloudStack based clouds.
  • project module – Manages projects on Apache CloudStack based clouds.
  • region module – Manages regions on Apache CloudStack based clouds.
  • resource_limit module – Manages resource limits on Apache CloudStack based clouds.
  • role module – Manages user roles on Apache CloudStack based clouds.
  • role_permission module – Manages role permissions on Apache CloudStack based clouds.
  • router module – Manages routers on Apache CloudStack based clouds.
  • security_group module – Manages security groups on Apache CloudStack based clouds.
  • security_group_rule module – Manages security group rules on Apache CloudStack based clouds.
  • service_offering module – Manages service offerings on Apache CloudStack based clouds.
  • ssh_key module – Manages SSH keys on Apache CloudStack based clouds.
  • static_nat module – Manages static NATs on Apache CloudStack based clouds.
  • storage_pool module – Manages Primary Storage Pools on Apache CloudStack based clouds.
  • template module – Manages templates on Apache CloudStack based clouds.
  • traffic_type module – Manages traffic types on CloudStack Physical Networks
  • user module – Manages users on Apache CloudStack based clouds.
  • vlan_ip_range module – Manages VLAN IP ranges on Apache CloudStack based clouds.
  • volume module – Manages volumes on Apache CloudStack based clouds.
  • volume_snapshot_policy module – Manages volume snapshot policies on Apache CloudStack based clouds.
  • vpc module – Manages VPCs on Apache CloudStack based clouds.
  • vpc_offering module – Manages vpc offerings on Apache CloudStack based clouds.
  • vpn_connection module – Manages site-to-site VPN connections on Apache CloudStack based clouds.
  • vpn_customer_gateway module – Manages site-to-site VPN customer gateway configurations on Apache CloudStack based clouds.
  • vpn_gateway module – Manages site-to-site VPN gateways on Apache CloudStack based clouds.
  • zone module – Manages zones on Apache CloudStack based clouds.
  • zone_info module – Gathering information about zones from Apache CloudStack based clouds.
