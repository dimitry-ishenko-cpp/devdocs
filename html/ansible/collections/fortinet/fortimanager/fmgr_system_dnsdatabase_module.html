fortinet.fortimanager.fmgr_system_dnsdatabase module – Configure DNS databases.

Note

This module is part of the fortinet.fortimanager collection (version 2.14.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install fortinet.fortimanager.

To use it in a playbook, specify: fortinet.fortimanager.fmgr_system_dnsdatabase.

New in fortinet.fortimanager 2.12.0
