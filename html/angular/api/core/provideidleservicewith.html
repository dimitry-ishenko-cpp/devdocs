provideIdleServiceWith

Configures Angular to use the given DI token as its IdleService.

Customizing idle behavior

API

function provideIdleServiceWith(
  useExisting: AbstractType<IdleService> | InjectionToken<IdleService>,
): EnvironmentProviders;
@paramuseExistingAbstractType<IdleService> | InjectionToken<IdleService>
@returnsEnvironmentProviders

Description

Configures Angular to use the given DI token as its IdleService.

The given token must be available for injection from the root injector, and the injected value must implement the IdleService interface.
