IdleService

Service which configures custom 'on idle' behavior for Angular features like @defer.

Customizing idle behavior

API

interface IdleService {
  requestOnIdle(callback: (deadline?: IdleDeadline | undefined) => void, options?: IdleRequestOptions | undefined): number;
  cancelOnIdle(id: number): void;
}

requestOnIdle

number

Schedule callback to be executed when the current application or browser is considered idle.

@paramcallback(deadline?: IdleDeadline | undefined) => void
@paramoptionsIdleRequestOptions | undefined
@returnsnumber
