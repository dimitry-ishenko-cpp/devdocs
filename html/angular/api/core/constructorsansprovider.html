ConstructorSansProvider

Configures the Injector to return an instance of a token.

API

interface ConstructorSansProvider {
  deps?: any[] | undefined;
}

deps

any[] | undefined

A list of tokens to be resolved by the injector.

Usage Notes

@Injectable(SomeModule, {deps: []})
class MyService {}
