ComboboxPopup

A structural directive that marks the ng-template to be used as the popup for a combobox. This content is conditionally rendered.

API

class ComboboxPopup implements OnInit ,OnDestroy {
  readonly @Input() combobox: InputSignal<Combobox>;
  readonly controlTarget: Signal<HTMLElement | undefined>;
  readonly popupId: Signal<string | undefined>;
  readonly activeDescendant: Signal<string | undefined>;
  readonly @Input() popupType: InputSignal<"listbox" | "tree" | "grid" | "dialog">;
}

The ID of the popup.

Description

A structural directive that marks the ng-template to be used as the popup for a combobox. This content is conditionally rendered.

The content of the popup can be any element with the ngComboboxWidget directive.

<ng-template ngComboboxPopup>
  <div ngComboboxWidget>
    <!-- ... options ... -->
  </div>
</ng-template>
