LimitSelectionKey

Used to select a LimitKey.

API

type LimitSelectionKey = MetadataKey<
  Signal<LimitKey<unknown> | undefined>,
  LimitKey<unknown>,
  LimitKey<unknown> | undefined
> & {
  [LIMIT_SELECTION_KEY]: true;
}

Description

Used to select a LimitKey.

This indirection allows rules to bind a LimitKey of a specific limit type (e.g. number or Date) matching the field's type to a generic MetadataKey.
