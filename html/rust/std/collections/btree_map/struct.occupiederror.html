Struct OccupiedError 

#[non_exhaustive]pub struct OccupiedError<'a, K, V, A = Global>where
    K: 'a,
    V: 'a,
    A: Allocator + Clone,{
    pub entry: OccupiedEntry<'a, K, V, A>,
    pub key: K,
    pub value: V,
}
🔬This is a nightly-only experimental API. (map_try_insert #82766)

The error returned by try_insert when the key already exists.

Contains the occupied entry, key, and the value that was not inserted.
