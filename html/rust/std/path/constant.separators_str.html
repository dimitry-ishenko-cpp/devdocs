Constant SEPARATORS_STR 

pub const SEPARATORS_STR: &[&str];
🔬This is a nightly-only experimental API. (const_path_separators #153106)

All path separators recognized on the current platform, represented as &strs; for example, this is &["/"][..] on Unix and &["\\", "/"][..] on Windows. The primary separator is always element 0 of the slice.
