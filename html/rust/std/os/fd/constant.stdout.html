Constant STDOUT 

pub const STDOUT: BorrowedFd<'static>;
🔬This is a nightly-only experimental API. (stdio_fd_consts #150836)
Available on Unix or Hermit or Trusty or WASI or Motor OS only.

The file descriptor for the standard output stream of the current process.

See io::stdout() for the higher level handle, which should be preferred whenever possible. See STDERR for why the file descriptor might be required and caveats. In addition to the issues discussed there, note that Stdout is buffered by default, and writing to the file descriptor will bypass this buffer.
